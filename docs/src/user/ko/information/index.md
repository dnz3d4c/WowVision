# 필요할 때 듣는 정보

WowVision에는 화면을 보지 않고도 게임 정보를 확인할 수 있는 여러 방법이 있습니다.

- [버퍼](buffers.md)는 원할 때마다 읽는 목록입니다. 생명력, 마나, 골드, 경험치, 빈 가방 칸, 대상에게 걸린 오라, 대화 탭의 메시지 등 많은 정보를 담고 있습니다. 게임 어디에서나 Alt와 화살표 키로 하나씩 넘겨 가며 읽습니다.
- [모니터](monitors.md)는 무언가를 대신 지켜보다가 그것이 변경되면 알려 줍니다. 예를 들어 대상에게서 약화 효과가 사라질 때, 재사용 대기가 끝나 사용할 수 있게 될 때, 효과가 발동할 때 알려 줍니다. 모니터는 자동으로 말하거나 소리를 냅니다.
- [파티 및 공격대 생명력 모니터](group-health.md)는 파티원이나 공격대원 중 누가 얼마나 다쳤는지 숫자와 음 높이로 알려 줍니다(Retail과 WoW: Forever 전용).

간단한 기준은 이렇습니다. 직접 확인하고 싶은 정보는 버퍼로 읽고, 알림으로 듣고 싶은 정보는 모니터로 받으십시오.
