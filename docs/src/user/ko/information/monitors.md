# 모니터

모니터는 게임을 대신 감시하다가 무언가 변경되면 말하거나 소리를 냅니다. 내가 건 약화 효과가 곧 끝나거나, 재사용 대기가 끝나 다시 사용할 수 있거나, 주문 발동을 알리는 빛이 켜질 때입니다. [버퍼](buffers.md)는 물어볼 때 답하지만, 모니터는 묻지 않아도 알려 줍니다.

어떤 모니터가 있는지는 게임 버전에 따라 다릅니다. Classic Era, 불타는 성전, 판다리아의 안개에는 오라 모니터와 재사용 대기 모니터가 있습니다. Retail과 WoW: Forever에는 재사용 대기시간 관리자 오라와 주문 재사용 대기가 있습니다. 이 버전들에서는 전투 중에 게임이 애드온에게 오라와 재사용 대기 수치를 숨기기 때문입니다. 재사용 대기시간 관리자 오라는 블리자드의 재사용 대기시간 관리자를 읽습니다. 주문 재사용 대기는 게임이 아직 알려 주는 몇 가지 정보를 이용하고, 고를 주문 목록을 만들 때만 재사용 대기시간 관리자를 빌려 사용합니다.

## 모니터의 작동 방식

모니터에는 규칙이 하나 이상 있습니다. 규칙 하나는 한 가지, 보통 주문 하나를 감시하며 "효과 적용", "확산", "만료 임박", "없음" 같은 상태를 오갑니다. 상태마다 알림이 있고, 알림마다 출력이 두 개 있습니다. 소리와 음성 메시지입니다. 어느 상태에서 어떻게 알릴지는 직접 정합니다.

요약하면 다음과 같습니다.

- 모니터는 무엇을 어느 유닛에서 감시할지 정합니다(예: 대상에 걸린 오라).
- 그 안의 규칙은 각각 주문 하나를 지정합니다.
- 규칙의 상태마다 알림이 있고, 알림에는 소리 알림과 TTS 알림 출력이 있습니다.

출력을 켜기 전에는 아무것도 말하지 않습니다. 규칙을 만들면 모든 출력이 꺼져 있습니다.

### 알림이 울리는 조건

규칙은 계속 말하지 않고 상태가 변경될 때 말합니다. 규칙이 시작된 뒤 처음 보는 상태는 조용히 정해집니다. 그래서 달빛섬광이 이미 걸려 있는 상태로 로그인해도 알림이 나오지 않습니다. 그다음부터는 다른 상태로 변경될 때마다 새 상태의 출력이 울립니다.

설정을 변경했을 때 일어나는 일은 모니터 종류마다 다릅니다.

- 오라 모니터와 재사용 대기 모니터(Classic Era, TBC, 판다리아의 안개)는 추적하는 것을 변경할 때마다 처음부터 다시 시작합니다. 규칙의 "주문"(또는 "내가 적용함"), 모니터의 "유닛"을 변경하거나 규칙을 추가하거나 제거할 때입니다. 다시 시작하면 그 모니터의 모든 규칙이 초기화되고, 각 규칙은 찾은 상태의 출력이 켜져 있으면 그 상태를 한 번 알립니다. 예를 들어 두 번째 규칙을 추가하면 첫 번째 규칙이 "달빛섬광 효과 적용"이나 "달빛섬광 없음"을 다시 알릴 수 있습니다.
- 주문 재사용 대기(Retail, WoW: Forever)는 조용히 다시 시작합니다. 변경한 뒤에 모든 규칙이 말하지 않고 현재 상태만 받아들입니다.
- 재사용 대기시간 관리자 오라(Retail, WoW: Forever)는 다시 시작하지 않습니다. 변경한 규칙은 지금 찾은 상태가 이전 상태와 다를 때만 말합니다.

규칙이 이미 어떤 상태에 있을 때 그 상태의 출력을 켜면 규칙이 다음에 확인할 때 바로 말하거나 소리를 냅니다. 달빛섬광이 걸려 있을 때 효과 적용 소리를 켜고 바로 소리가 들려도 놀라지 마십시오.

### 상태 사이의 대체

어떤 상태는 다른 상태의 "더 나빠진 형태"입니다. 오라에서 "확산"은 "효과 적용"으로, "만료 임박"은 "확산"으로 대체됩니다. 규칙은 이렇습니다. 어떤 상태에 켜진 출력이 없으면 그 상태를 대신하는 대체 상태의 출력을 사용하고, 한 상태에서 다음 상태로 넘어갈 때 출력이 변경되지 않으면 반복하지 않습니다.

실제로는 다음과 같습니다.

- "효과 적용"에만 소리를 켜면 오라가 생길 때 한 번 들립니다. 오라가 확산 구간에 들어가거나 만료가 임박해도 다시 들리지 않습니다.
- "만료 임박"에 다른 소리를 켜면 오라가 걸릴 때 "효과 적용" 소리가, 곧 사라질 때 "만료 임박" 소리가 들립니다.
- "없음" 상태에는 대체가 없습니다. 자기 출력이 켜져 있을 때만 울립니다.

재사용 대기 상태(준비 완료, 충전 중, 대기 중)는 대체가 없습니다. 각 상태는 자기 출력만 재생합니다.

## 모니터 설정하기

1. Shift+F1을 누르거나 `/wv`를 입력해 WowVision 메뉴를 열고, 모니터로 이동해 Enter를 누릅니다.
2. 화면에 사용함과, 모니터 수가 붙은 모니터 버튼이 나옵니다. 예를 들면 "모니터 (0)"입니다. 모니터 버튼에서 Enter를 누릅니다.
3. 추가에서 Enter를 누릅니다. 종류 선택 화면에 게임 버전에서 사용할 수 있는 모니터 종류가 나옵니다. 하나를 고릅니다.
4. 새 모니터가 열립니다. 이름에는 "신규" 뒤에 종류가 붙습니다. 예를 들면 "신규 Aura"(또는 "신규 주문 재사용 대기")입니다. 표시 이름을 "대상 지속 피해"처럼 알아보기 쉬운 이름으로 변경합니다.
5. 모니터 자체 설정(유닛 등)을 정합니다. 모니터 화면에서 규칙 버튼 뒤에 있습니다.
6. 규칙 버튼("규칙 (0)")에서 Enter를 누르고, 추가를 누른 뒤 규칙 종류를 고릅니다.
7. 새 규칙이 열립니다. 주문을 정하고, 규칙에 기준값이 있으면 기준값도 정합니다.
8. 원하는 상태(효과 적용, 없음, 준비 완료 등)를 열고, 소리 알림이나 TTS 알림을 열어 켭니다. 아래 [알림](#상태-알림과-출력)을 보십시오.

Escape를 누르면 이전 화면으로 돌아갑니다. 모니터나 규칙을 지우려면 열어서 맨 아래의 제거에서 Enter를 누릅니다. 확인을 묻지 않습니다.

메뉴는 [WowVision 메뉴와 설정](../basics/menu-and-settings.md)에서 설명합니다. 알림의 일반 개념은 [알림](../basics/alerts.md)에 있습니다.

### 계정 전체 또는 캐릭터별

추가한 모니터는 기본적으로 계정 전체에 저장되므로 모든 캐릭터가 공유합니다. 하지만 모든 캐릭터가 공유하는 것이 늘 바람직하지는 않습니다. 드루이드의 달빛섬광 모니터는 전사에게 아무 의미가 없습니다.

- 모니터 하나를 한 캐릭터에만 두려면 모니터 목록에서 그 모니터로 이동해 Shift+F10(상황별 메뉴)을 누르고, 범위를 고른 뒤 캐릭터 이름을 고릅니다. 다시 공유하려면 전역을 고릅니다.
- 모든 모니터를 한꺼번에 전환하려면 WowVision 메뉴를 열고 모니터로 이동해 Shift+F10을 누른 뒤 범위를 고르고, 전역이나 캐릭터 이름을 고릅니다.

범위를 변경해도 지워지는 것은 없습니다.

### 모든 모니터와 규칙에 있는 설정

| 설정 | 기본값 | 하는 일 |
|---|---|---|
| 사용함(모니터) | 켬 | 꺼진 모니터는 아무것도 하지 않음 |
| 표시 이름(모니터) | "신규 ..."에 종류가 붙음 | 모니터 목록에 보이는 이름. 비우면 목록에 종류가 나옴. 예: "오라 모니터 (target)" |
| 규칙 | 없음 | 규칙 목록(메뉴에 개수가 나옴) |
| 사용함(규칙) | 켬 | 꺼진 규칙은 무시됨 |
| 표시 이름(규칙) | "신규 ..."에 규칙 종류가 붙음 | 규칙 목록에 보이는 이름. 주문을 정한 뒤에도 계속 "신규 ..."라고 나오므로 이름을 변경하십시오. 비우면 목록에 주문이 나옴. 예: "달빛섬광 (8921)" |

### 상태 알림과 출력

규칙의 각 상태는 규칙 화면에 상태 이름의 버튼으로 나옵니다. 예를 들면 효과 적용입니다. 상태 버튼에서 Enter를 누르면 그 상태의 알림이 열립니다. 알림에는 다음이 있습니다.

| 설정 | 기본값 | 하는 일 |
|---|---|---|
| 사용함 | 켬 | 상태 자체의 스위치. 표 아래 설명 참고 |
| 소리 알림 | 끔 | 소리를 재생. 별도 화면이 열림 |
| TTS 알림 | 끔 | 메시지를 말함. 별도 화면이 열림 |

원하는 출력을 켜고, 상태 자체의 사용함은 켠 채로 둡니다. 지금은 어느 규칙의 상태에서도 이 스위치가 아무 일도 하지 않습니다. 무언가가 재생될지는 안에 있는 소리 알림이나 TTS 알림의 사용함 스위치만 정합니다. 상태 자체의 사용함을 따르는 알림은 재사용 대기 상태 규칙의 사용 횟수 부여와 사용 횟수 감소뿐입니다.

소리 알림 화면에는 다음이 있습니다.

| 설정 | 기본값 | 하는 일 |
|---|---|---|
| 사용함 | 끔 | 소리를 켬 |
| 소리 | 선택 안 함 | 소리 탐색기를 엶. 목록을 이동하면 각 소리를 미리 들을 수 있고, Enter를 눌러 고름. 고르기 전에는 소리가 나지 않음 |

TTS 알림 화면에는 다음이 있습니다.

| 설정 | 기본값 | 하는 일 |
|---|---|---|
| 사용함 | 끔 | 음성을 켬 |
| 우선 메시지 (현재 음성 중단) | 끔 | 켜면 차례를 기다리지 않고 지금 말하고 있는 것을 끊고 메시지를 말함 |
| 음성 | 음성 종류 설정을 따름 | 이 알림을 다른 목소리로 말함. [음성](../basics/speech.md) 참고 |
| 메시지 | 비어 있음 | 말할 문구. 비어 있으면 WowVision이 기본 메시지를 말함 |

기본 메시지는 모든 모니터에서 주문 이름과 상태입니다. "달빛섬광 효과 적용", "달빛섬광 만료 임박", "환생 대기 중", "환생 사용 횟수 부여", "나무껍질 준비 완료", "별빛쇄도 발동". 주문이 없는 규칙은 대신 표시 이름을 사용합니다. "달빛섬광 꺼짐"처럼 메시지를 직접 입력하면 기본 메시지 전체를 대체합니다.

## 오라 모니터

(Classic Era, 불타는 성전, 판다리아의 안개)

유닛 하나에 걸린 강화 효과와 약화 효과를 감시합니다.

| 설정 | 기본값 | 하는 일 |
|---|---|---|
| 유닛 | target | 감시할 유닛. 글자로 입력: `target`, `player`, `focus`, `pet`, `mouseover`, `party1` 등 |
| 대상 변경 시 알림 | 끔 | 대상을 변경하면(또는 유닛이 변경되면) 모든 규칙이 새 유닛에서 찾은 상태를 알림. "없음" 상태도 포함 |

규칙 종류: 오라 상태 규칙. 주문 하나가 유닛에 걸렸다가 사라질 때까지 따라갑니다.

| 설정 | 기본값 | 하는 일 |
|---|---|---|
| 주문 | 없음 | 감시할 오라. [주문 고르기](#주문-고르기) 참고 |
| 내가 적용함 | 켬 | 내가(또는 내 소환수가) 건 오라만 셈 |
| 확산 구간 (%) | 30 | 전체 지속시간 중 이 비율 이하가 남으면 오라가 확산 상태가 됨 |
| 만료 임박 기준 (초) | 5 | 확산 구간 안에서 남은 시간이 설정한 초 이하가 되면 오라가 만료 임박 상태가 됨 |

상태와 울리는 때:

| 상태 | 때 |
|---|---|
| 효과 적용 | 오라가 유닛에 걸려 있고 시간이 넉넉히 남음(또는 지속시간이 없음) |
| 확산 | 오라가 확산 구간 안에 있음. 지금 갱신하면 효과가 가장 좋음 |
| 만료 임박 | 오라가 확산 구간 안에 있고 만료 임박 기준 이하임 |
| 없음 | 유닛에 걸려 있던 오라가 사라짐 |

알아 두면 좋은 점:

- "만료 임박"은 두 조건이 모두 필요합니다. 확산 구간 안이면서 만료 임박 기준 이하여야 합니다. 짧은 오라(예: 6초)는 확산 구간이 너무 짧아서 "효과 적용"에서 바로 "만료 임박"으로 넘어갑니다.
- 지속시간이 없는 오라는 "효과 적용"에 머뭅니다.
- 조건에 맞는 오라가 여러 개 있으면("내가 적용함"이 꺼져 있고 여러 사람이 걸었을 때) 규칙은 가장 상태가 좋은 것을 알립니다.
- 추적하던 오라가 사라지면 "없음"을 말합니다. 모니터가 시작될 때(예: 로그인할 때) 오라가 처음부터 없었다면 "없음"을 말하지 않습니다. 새 대상을 잡을 때마다 "달빛섬광 없음"이나 "달빛섬광 효과 적용"을 듣고 싶으면 "대상 변경 시 알림"을 사용하십시오.
- "대상 변경 시 알림"을 꺼 두어도, 새 대상의 상태가 규칙이 가지고 있던 상태와 다르면(예: "효과 적용"에서 "없음"으로) 대상을 변경할 때 말합니다.
- 시전자가 없는 효과(많은 장신구 발동 효과 등)에는 "내가 적용함"을 꺼야 합니다.
- 규칙은 오라 자체의 주문 번호로 오라를 찾습니다. 시전한 주문과 그 주문이 대상에 거는 오라의 번호가 다르면(클래식 버전에서는 주문 등급에 따라 다를 수 있습니다) 이름을 입력하지 말고 빠른 선택에서 오라를 고르십시오. 모니터가 유닛에서 그 오라를 한 번 보면 빠른 선택에 나옵니다.

## 재사용 대기 모니터

(Classic Era, 불타는 성전, 판다리아의 안개)

내 주문의 재사용 대기를 감시합니다. 공통 설정 말고는 설정이 없고, 주문은 규칙에서 정합니다.

규칙 종류: 재사용 대기 상태 규칙.

| 설정 | 기본값 | 하는 일 |
|---|---|---|
| 주문 | 없음 | 재사용 대기를 감시할 주문 |

상태:

| 상태 | 때 |
|---|---|
| 준비 완료 | 주문의 재사용 대기가 끝남. 사용 횟수가 있는 주문은 모든 횟수를 사용할 수 있음 |
| 충전 중 | 사용 횟수가 있는 주문이고, 사용 횟수가 전부는 아니지만 하나 이상 남음 |
| 대기 중 | 주문이 재사용 대기 중임. 사용 횟수가 있는 주문은 사용할 수 있는 횟수가 없음 |

사용 횟수가 있는 주문에는 상태와 상관없이 울리는 알림이 두 개 더 있습니다.

| 알림 | 때 |
|---|---|
| 사용 횟수 부여 | 사용 횟수가 하나 돌아옴 |
| 사용 횟수 감소 | 사용 횟수를 하나 씀 |

전역 재사용 대기는 재사용 대기로 간주하지 않습니다. 규칙이 처음 보는 상태(예: 로그인할 때)는 조용히 지나갑니다.

## 재사용 대기시간 관리자 오라

(Retail과 WoW: Forever)

Retail에서는 전투 중과 인스턴스 안에서 게임이 애드온에게 오라 정보를 숨기므로, 일반 오라 함수로는 그곳에서 내가 건 약화 효과를 볼 수 없습니다. 블리자드의 재사용 대기시간 관리자는 볼 수 있고, 이 모니터는 관리자가 보여 주는 것을 읽습니다. 재사용 대기시간 관리자의 추적 중인 강화 효과와 추적 중인 막대에 있는 오라마다, 그 오라가 유닛에 걸려 있는지와 확산 구간 안에 있는지를 알려 줍니다.

사용하기 전에 오라가 재사용 대기시간 관리자의 추적 중인 강화 효과나 추적 중인 막대에 들어 있어야 합니다.

- 추적 중인 강화 효과와 추적 중인 막대 범주에 있는 오라만 감시할 수 있습니다. 핵심 능력과 보조 능력 범주에는 오라가 아니라 주문이 들어 있습니다.
- 감시할 수 있는 유닛은 대상과 플레이어 두 개뿐입니다. 재사용 대기시간 관리자가 따라가는 두 유닛입니다.
- 재사용 대기시간 관리자가 감시할 오라를 표시하고 있어야 합니다. 숨겨 두었거나 전투 중에만 나오게 설정한 재사용 대기시간 관리자 줄은 숨겨진 동안 비어 있는 것으로 읽히고, 규칙은 "없음" 상태를 알립니다. 알림이 엉뚱한 때 울리면 줄이 표시되어 있는지 확인하십시오.

재사용 대기시간 관리자는 설정 창에서 정리합니다. WowVision이 이 창을 키보드와 스크린리더로 사용할 수 있게 해 줍니다. `/cdm`으로 엽니다. 창에는 주문, 오라, 파티 강화 효과 탭, 검색 상자, 설정 메뉴, 각 범주와 그 안의 항목, 구성 드롭다운, 되돌리기 버튼이 있습니다. 항목에서 Enter를 누르면 집어 들고, 다른 항목이나 범주의 빈 칸에서 Enter를 누르면 그곳에 내려놓습니다. 항목에서 Backspace를 누르면 항목 메뉴(알림, 다른 범주로 이동)가 열립니다. 키보드로 변경한 내용은 인터페이스를 다시 불러온 뒤에 적용됩니다. 게임이 그 내용으로 화면의 재사용 대기 데이터를 다시 만들기 때문입니다. 창은 처음 변경할 때 인터페이스를 다시 불러와야 한다고 한 번 알려 주고 창 끝에 UI 재시작 버튼을 둡니다(`/reload`를 입력해도 됩니다). 이렇게 변경한 뒤 창을 닫으면 한 번 더 알려 줍니다. 항목은 이름, 배우지 않은 주문이면 "배우지 않음", 그리고 알림 개수(예: "알림 1개")와 함께 읽힙니다. 범주는 제목에서 Enter를 눌러 접고 펼 수 있습니다. 파티 강화 효과 탭에서는 강화 효과가 파티창 강화 효과 구역과 표시 안됨 구역에 나뉘어 있습니다. Enter를 누르면 강화 효과를 집어 들고, 다른 구역의 강화 효과에서 Enter를 누르면 그쪽으로 옮깁니다. 항목 메뉴에서 알림을 고르면(신규 경보 또는 기존 경보 편집) 게임의 알림 편집기가 별도 창으로 열립니다. 창 이름은 알림 편집기이고, 주문, 선택마다 하나씩 있는 드롭다운, 알림을 추가하거나 저장하는 버튼, 그리고 닫기가 있습니다.

그래도 게임의 알림이 필요한 경우는 드뭅니다. WowVision의 모니터는 게임 알림이 하는 일을 모두 하고, 더 잘합니다. 규칙의 상태마다 고유한 소리와 음성 메시지가 있고, 내 음성 설정으로 말합니다. 둘 다 언제든 변경할 수 있습니다. 주문 재사용 대기는 재사용 대기시간 관리자에 있는 주문뿐 아니라 어떤 주문에도 사용할 수 있습니다. 게임의 알림 편집기는 원하면 사용할 수 있지만, 모니터부터 시작하십시오.

### 모니터 설정

| 설정 | 기본값 | 하는 일 |
|---|---|---|
| 유닛 | 대상 | 대상 또는 플레이어 |
| 대상 변경 시 알림 | 끔 | 대상을 변경하면 모든 규칙이 현재 상태를 알림(유닛이 대상일 때만) |
| 소수점 한 자리 타이머 | 끔 | 추적 중인 아이콘에 그려지는 남은 시간이 10분 미만일 때 0.1초 단위("8.7")로 표시됨. 비장애인 플레이어가 화면에서 보는 표시가 변경되므로 기본값은 끔. 추적 중인 오라 읽기도 이 표시를 따름 |

### 규칙 종류: 재사용 대기시간 관리자 오라 규칙

| 설정 | 기본값 | 하는 일 |
|---|---|---|
| 주문 | 없음 | 감시할 오라 |

주문 선택에는 추적 중인 강화 효과와 추적 중인 막대에 있는 오라가 나옵니다(없으면 "추적 중인 강화 효과 또는 막대 없음"이라고 말합니다). 다른 주문 이름이나 번호를 입력할 수도 있지만, 규칙이 감지하는 것은 이 두 범주에 있는 오라뿐입니다. 규칙은 주문 이름으로 찾으므로 달빛섬광 같은 시전 주문을 고르면 그 주문이 거는 약화 효과를 찾습니다.

상태:

| 상태 | 때 |
|---|---|
| 효과 적용 | 오라가 유닛에 걸려 있음 |
| 확산 | 재사용 대기시간 관리자가 오라를 갱신 구간 안에 있다고 표시함. 확산은 효과 적용으로 대체됨 |
| 없음 | 오라가 유닛에 없음 |

WoW: Forever에는 확산 구간이 없어서 확산 상태가 없고 메뉴에도 나오지 않습니다.

추적 중인 오라가 확산 구간 안에서 끝나면 규칙은 "확산"에서 바로 "없음"으로 넘어가고, 그 사이에 잘못된 "효과 적용"이 끼지 않습니다.

대상을 변경하면 규칙은 게임이 아이콘을 새로 고칠 때까지 잠시(몇 틱) 기다렸다가 읽습니다. 그래서 대상을 변경했을 때 오라가 사라졌다가 다시 생긴 것처럼 들리지 않습니다.

### 추적 중인 오라 읽기

추적 중인 오라 읽기 키는 켜진 재사용 대기시간 관리자 오라 모니터 전체에서 추적 중인 오라를 모두 게임에 보이는 그대로 읽습니다. 오라 이름, 남은 시간, 중첩을 읽고, 확산 상태이면 "확산"을, 오라가 없으면 "없음"을 읽습니다. 예: "달빛섬광, 8.7, 3 중첩, 확산. 갈퀴 발톱, 없음". 추적 중인 것이 없으면 "추적 중인 오라 없음"이라고 들립니다.

이 키는 기본적으로 지정되어 있지 않습니다. 단축키 화면의 모니터 아래에 있습니다. [단축키](../basics/keybindings.md)를 보십시오.

### 진단 명령: /wv cdmlog

알림이 엉뚱한 때 울리면 `/wv cdmlog`가 변경이 있을 때마다 각 규칙이 재사용 대기시간 관리자 프레임에서 본 것을 기록한 로그를 보여 줍니다. 최신 항목이 맨 뒤에 오고, 복사할 수 있는 창에 나오며, 최신 줄을 읽어 줍니다. 버그를 알릴 때 함께 보내십시오.

- `/wv cdmlog clear`는 로그를 비웁니다.
- `/wv cdmlog spells`는 추적 중인 강화 효과와 추적 중인 막대의 모든 항목을 주문 ID와 함께 보여 줍니다.
- `/wv cdmlog cooldowns`는 핵심 능력과 보조 능력 항목을 보여 줍니다.

## 주문 재사용 대기

(Retail과 WoW: Forever)

Retail에서는 전투 중과 인스턴스 안에서 재사용 대기 정보가 숨겨지지만, 게임이 알려 주는 단순한 정보가 몇 가지 남아 있습니다. 재사용 대기가 돌고 있는지, 돌고 있는 재사용 대기가 전역 재사용 대기뿐인지, 사용 횟수가 충전 중인지입니다. 이 모니터는 그 정보만으로 상태를 만들므로 어디서든, 어떤 주문에도 작동합니다. 재사용 대기시간 관리자는 고를 주문 목록을 보여 줄 때만 필요하고, 다른 주문을 직접 입력해도 됩니다. 남은 시간은 게임이 사용하는 형식을 따라 평범한 말로 나오며, 전투 중에도 읽을 수 있습니다.

공통 설정 말고는 자체 설정이 없습니다. 규칙 종류는 두 가지입니다.

### 규칙 종류: 주문 재사용 대기 규칙

| 설정 | 기본값 | 하는 일 |
|---|---|---|
| 주문 | 없음 | 감시할 주문 |

주문 선택에는 재사용 대기시간 관리자의 핵심 능력과 보조 능력 범주에 있는 주문 가운데, 게임 기준으로 알림을 걸 재사용 대기가 있는 주문이 나옵니다(재사용 대기가 없는 태양섬광 같은 즉시 시전 주문은 나오지 않습니다. 해당하는 주문이 하나도 없으면 "재사용 대기가 있는 주문 없음"이라고 말합니다). 일월식이 월식과 일식을 함께 나타내는 것처럼, 여러 주문을 나타내는 항목은 그 주문들로 하나씩 나뉘어 나옵니다. 다른 주문 이름이나 번호를 입력할 수도 있습니다.

상태:

| 상태 | 때 |
|---|---|
| 준비 완료 | 주문의 재사용 대기가 끝났고 사용할 수 있는 사용 횟수가 있음 |
| 충전 중 | 사용 횟수가 충전 중이고, 사용할 수 있는 횟수가 아직 하나 이상 있음 |
| 대기 중 | 주문이 실제 재사용 대기 중이고 남은 사용 횟수가 없음 |

전역 재사용 대기는 재사용 대기로 간주하지 않습니다. 주문이 재사용 대기 중이거나 충전 중인 동안 규칙은 1초에 약 열 번 확인합니다. 재사용 대기가 끝날 때 게임이 이벤트를 보내지 않기 때문입니다.

### 규칙 종류: 주문 발동 규칙

발동 규칙은 주문이 발동할 때 게임이 그 주문 둘레에 그리는 빛을 따라갑니다.

| 설정 | 기본값 | 하는 일 |
|---|---|---|
| 주문 | 없음 | 빛을 감시할 주문 |

발동은 어느 주문에서나 일어날 수 있으므로 선택 목록은 같은 재사용 대기시간 관리자 주문을 거르지 않고 보여 줍니다(없으면 "핵심 능력 또는 보조 능력 없음"이라고 말합니다). 상태마다 자기 알림이 있습니다.

| 상태 | 때 |
|---|---|
| 발동 | 빛이 나타남 |
| 발동 종료 | 빛이 사라짐 |

### 추적 중인 재사용 대기 읽기

추적 중인 재사용 대기 읽기 키는 켜진 주문 재사용 대기 모니터 전체에서 모든 규칙의 상태를 읽습니다. 예: "나무껍질, 대기 중, 49초. 화염 작렬, 충전 중, 1회 사용 가능, 8초. 별빛쇄도, 발동. 급속 성장, 준비 완료". 발동 규칙은 빛이 꺼져 있으면 "발동 없음"이라고 읽습니다. 규칙이 하나도 없으면 "추적 중인 재사용 대기 없음"이라고 들립니다.

이 키는 기본적으로 지정되어 있지 않습니다. 단축키 화면의 모니터 아래에 있습니다.

| 추적 중인 오라 읽기, 추적 중인 재사용 대기 읽기, `/wv cdmlog` | 아니요 | 아니요 | 아니요 | 예 | 예 |

전체 기능표는 [버전](../reference/versions.md)을 보십시오.

## 키

| 동작 | 기본 키 | 하는 일 |
|---|---|---|
| 모든 모니터 켜고 끄기 | 지정 안 됨 | 켜진 모니터가 하나라도 있으면 모든 모니터를 끄고 "모니터 꺼짐"이라고 말함. 모두 꺼져 있으면 모두 켜고 "모니터 켜짐"이라고 말함 |
| 추적 중인 오라 읽기 | 지정 안 됨 | 추적 중인 오라를 모두 읽음(Retail과 WoW: Forever) |
| 추적 중인 재사용 대기 읽기 | 지정 안 됨 | 추적 중인 주문 재사용 대기와 발동을 모두 읽음(Retail과 WoW: Forever) |

단축키 화면에서 지정합니다. [단축키](../basics/keybindings.md)를 보십시오. 모든 모니터 켜고 끄기는 음소거처럼 동작합니다. 한 번 누르면 모든 모니터가 조용해지고, 다시 누르면 모두 다시 켜집니다. 하나씩 따로 꺼 두었던 모니터도 함께 켜집니다.

## 주문 고르기

모든 규칙에는 주문 설정이 있습니다. 거기서 Enter를 누르면 작은 화면이 열립니다.

- "주문 이름"은 입력란을 엽니다. 주문 이름이나 번호를 입력하고 Enter를 누릅니다. WowVision이 주문을 찾지 못하면 "찾을 수 없음"이라고 들립니다. 클래식 버전에서는 보통 내 캐릭터가 배운 주문의 이름이어야 합니다. 그 밖의 주문은 번호를 사용하십시오.
- 그 아래에 빠른 선택 목록이 있고, 각 항목은 "주문 이름 (번호)"로 읽힙니다. 원하는 주문에서 Enter를 누릅니다. 오라, 재사용 대기, 주문 재사용 대기 규칙에서는 이 캐릭터로 시전했거나 오라로 확인한 주문이 목록에 나옵니다. 재사용 대기시간 관리자 오라 규칙과 주문 재사용 대기 규칙은 앞에서 설명한 대로 이 목록 대신 재사용 대기시간 관리자의 항목을 보여 줍니다.

주문을 정하면 주문 설정이 "달빛섬광 (8921)"처럼 읽힙니다.

## 예시

### 대상에 건 달빛섬광 (Classic Era, TBC, 판다리아의 안개)

대상에 건 달빛섬광이 곧 사라질 때와 사라졌을 때를 듣고 싶다고 합시다.

1. WowVision 메뉴(Shift+F1)를 열고 모니터, 모니터 (0), 추가를 차례로 고른 뒤 Aura를 고릅니다.
2. 표시 이름을 "달빛섬광"으로 정합니다. 유닛은 `target` 그대로 둡니다.
3. 규칙을 열고 추가를 누른 뒤 오라 상태 규칙을 고릅니다.
4. 주문을 정합니다. Enter를 누르고 주문 이름을 고른 뒤 달빛섬광(영어 게임에서는 `Moonfire`)을 입력하고 Enter를 누릅니다. 주문이 번호와 함께 들립니다.
5. "내가 적용함"은 켠 채로 둡니다.
6. "만료 임박"을 열고 "TTS 알림"을 엽니다. "사용함"을 켭니다. "메시지"를 "달빛섬광 만료 임박"으로 정합니다.
7. 이전 화면으로 돌아가서 "없음"을 열고 "TTS 알림"을 엽니다. "사용함"을 켭니다. "메시지"를 "달빛섬광 사라짐"으로 정합니다.
8. 원하면 "효과 적용"을 열고 "소리 알림"을 열어 켠 뒤 "소리"에서 짧은 소리를 고릅니다. 걸 때마다 딸깍 소리가 납니다.

이제 대상에 달빛섬광을 겁니다. "효과 적용"이 딸깍 소리를 냅니다. "확산" 상태는 조용합니다. 자기 출력이 없어서 "효과 적용"으로 대체되므로 새로 재생되는 것이 없습니다. 오라가 곧 만료되면 "달빛섬광 만료 임박"이, 사라지면 "달빛섬광 사라짐"이 들립니다. 달빛섬광이 걸려 있는 동안 달빛섬광이 없는 대상으로 전환해도 "달빛섬광 사라짐"이 들립니다. 규칙이 "효과 적용"에서 "없음"으로 변경되었기 때문입니다.

### 재사용 대기 준비 알림 (Classic Era, TBC, 판다리아의 안개)

1. 모니터, 모니터 (0), 추가, Cooldown을 고릅니다. 표시 이름은 "재사용 대기"로 정합니다.
2. 규칙, 추가, 재사용 대기 상태 규칙을 고릅니다. 주문을 별빛섬광(영어 게임에서는 `Starfire`) 또는 재사용 대기가 있는 아무 주문으로 정합니다.
3. 준비 완료를 열고 TTS 알림을 열어 켠 뒤 메시지를 "별빛섬광 준비"로 정합니다.

주문을 시전합니다. 재사용 대기가 끝나면 "별빛섬광 준비"가 들립니다. 로그인할 때 주문이 그냥 준비된 상태라면 아무 말도 하지 않습니다.

### 재사용 대기 준비 알림 (Retail과 WoW: Forever)

1. 모니터, 모니터 (0), 추가, 주문 재사용 대기를 고릅니다.
2. 규칙, 추가, 주문 재사용 대기 규칙을 고릅니다. 주문을 엽니다. 빠른 선택에 재사용 대기시간 관리자의 핵심 능력과 보조 능력 주문 가운데 재사용 대기가 있는 주문이 나옵니다. 나무껍질을 고릅니다.
3. 준비 완료, TTS 알림을 열고 사용함을 켭니다.

나무껍질을 다시 사용할 수 있게 되면 전투 중에도 "나무껍질 준비 완료"가 들립니다. 사용할 때 "나무껍질 대기 중"도 듣고 싶으면 대기 중의 TTS 알림을 추가하십시오. 상태와 남은 시간을 원할 때 들으려면 추적 중인 재사용 대기 읽기를 키에 지정하십시오.

### Retail 전투 중 약화 효과

1. 재사용 대기시간 관리자 설정(`/cdm`)에서 원하는 오라가 추적 중인 강화 효과나 추적 중인 막대에 있는지 확인합니다.
2. 모니터, 추가, 재사용 대기시간 관리자 오라를 고릅니다. 유닛은 대상으로 둡니다.
3. 규칙, 추가, 재사용 대기시간 관리자 오라 규칙을 고릅니다. 주문을 엽니다. 빠른 선택에 추적 중인 오라가 나옵니다. 약화 효과를 고릅니다.
4. "없음"과 "확산"의 "TTS 알림"을 켭니다.

재사용 대기시간 관리자가 약화 효과를 갱신할 때가 되었다고 표시하면 "달빛섬광 확산"이, 사라지면 "달빛섬광 없음"이 들립니다.

## 팁

- 모니터 하나와 규칙 하나로 시작해 제대로 작동하는지 확인한 뒤에 더 추가하십시오.
- 필요한 알림만 켜십시오. "효과 적용"에 소리, "없음"에 음성 메시지를 두는 것으로 시작하면 좋습니다.
- 파티나 공격대에서는 오라 규칙의 "내가 적용함"을 켜서 다른 플레이어가 건 오라를 세지 않게 하십시오. 시전자가 없는 효과(많은 장신구 발동 효과 등)에는 끄십시오.
- 모니터와 규칙에 알아보기 쉬운 표시 이름을 붙이십시오. 목록에는 표시 이름만 나옵니다.
- 모니터와 버퍼는 서로를 보완합니다. 달빛섬광이 사라질 때는 모니터가 알려 주게 하고, 다른 타이머는 [버퍼](buffers.md)나 읽기 키로 원할 때 읽으십시오.
- 알림이 전혀 울리지 않으면 다음 순서로 확인하십시오. 모니터의 사용함이 켜져 있는지, 규칙의 사용함이 켜져 있는지, 주문이 정해져 있는지, 상태의 소리 알림이나 TTS 알림의 사용함이 켜져 있는지(기본값은 꺼짐입니다), 그리고 소리라면 소리를 골랐는지 확인합니다.
- Retail에서 알림이 이상한 때 울리면 `/wv cdmlog`를 사용하십시오. [문제 보고](../getting-started/troubleshooting.md)를 보십시오.
