# WowVision과 Sku 함께 쓰기

WowVision과 Sku는 나란히 설치할 수 있고, 둘 다 쓰는 플레이어도 많습니다. 두 애드온은 같은 창을 두고 다투지 않습니다. Sku가 로드되어 있으면 WowVision은 아래 목록의 창, 키, 명령을 일부러 처리하지 않고 Sku에게 맡깁니다. 목록에 없는 것은 모두 계속 WowVision이 처리합니다.

## 동작 방식

게임이 WowVision을 로드하면 WowVision은 이미 로드된 애드온을 확인합니다. 그중에 Sku가 있으면 "Sku 담당"으로 표시된 창, 키 바인딩, 명령을 그 세션 동안 모두 끕니다. 창은 WowVision에서 아예 열리지 않고, 키는 WowVision이 넘겨받지 않으며, 명령은 등록되지 않습니다. 이 판단은 로그인할 때 한 번만 하므로 Sku를 켜거나 끈 것을 반영하려면 UI를 재시작(/reload)하거나 다시 로그인해야 합니다. 지워지는 것은 없습니다. 이 기능들의 WowVision 설정과 키 바인딩은 그대로 남아 있다가 Sku를 끄면 바로 돌아옵니다.

Sku를 로드한 상태에서 WowVision이 어떤 창을 읽지 않는다면 거의 틀림없이 이 때문입니다. 한 세션 동안 Sku를 끄려면 게임의 애드온 목록에서 끄거나 /disableaddon sku를 입력합니다(Sku와 Sku의 보조 애드온을 끄고 UI를 재시작합니다. /enableaddon sku를 입력하면 다시 켜집니다). BlindSlash 애드온이 로드되어 있으면 WowVision은 이 두 명령 자체를 등록하지 않습니다.

## 둘 다 로드했을 때 Sku가 맡는 것

모든 게임 버전의 창:

- 가방.
- NPC 대화와 그 밖의 NPC 대화 창.
- 상인.
- 우체통.
- 팝업(게임의 확인 대화상자).
- 퀘스트 NPC 창(퀘스트 수락과 완료 보고).
- 비행 조련사(비행 지도).
- 거래 창.
- 상급자.
- 전투 준비 확인과 던전 준비 팝업.
- 역할 투표(역할 확인 팝업).
- 길드 초대.

Classic Era, 불타는 성전(TBC), 판다리아의 안개(Mists)에서 추가로 맡는 창:

- 친구, 차단, 누구, 길드 페이지가 있는 친구 및 소셜 창.
- 클래식 길드 창의 구성원 카드, 길드 정보, 길드 이벤트 기록, 길드 권한 창.

불타는 성전(TBC)에서만 추가로 맡는 창:

- 캐릭터 창.
- 마법책.
- 특성.
- 전문 기술 창과 제작 창.
- 야수 우리.
- 퀘스트 목록.

판다리아의 안개(Mists)에서만 추가로 맡는 창:

- 캐릭터 창.
- 특성.
- 퀘스트 목록.
- 아이템 강화.
- 재연마.

Retail과 WoW: Forever에서 추가로 맡는 창:

- 길드 및 커뮤니티 창과 이 창에 딸린 구성원 카드, 텍스트 편집기, 이벤트 기록, 새 소식 필터.
- 길드 권한.
- 소셜 창과 이 창에 딸린 보조 창(차단 목록, 단체 알림 메시지, 블리자드 서비스 사용 불가 안내, 공격대 정보, 친구 추가).
- 재사용 대기시간 관리자 창과 이 창의 알림 편집기.
- 퀘스트 목록.
- WoW: Forever에서만: 캐릭터 창과 장비 구성 팝업.

Sku가 맡는 키(Sku가 로드되어 있는 동안 WowVision은 이 키를 넘겨받지 않습니다):

- 툴팁 줄 키: 툴팁 이전 줄과 툴팁 다음 줄(Shift+Up과 Shift+Down), 툴팁 왼쪽 읽기와 툴팁 오른쪽 읽기(Shift+Left와 Shift+Right).
- 소프트 대상을 켜고 끄는 키: 적 소프트 대상, 아군 소프트 대상, 상호작용 소프트 대상(Shift+I, Shift+P, Shift+O).
- 주시 대상 선택 1부터 주시 대상 선택 5까지.

Sku가 맡는 명령: /focus1부터 /focus5까지, /pquit(파티 떠나기), /dquit(던전 파티나 전장 떠나기).

## WowVision이 계속 해 주는 것

나머지는 모두 평소대로 동작합니다. 음성과 알림, 버퍼와 모니터, 대상 알림, 이동과 길 안내, 미니맵 스캔, 스캐너, 대화 창과 대화 알림, 대화 채널 창, 행동 단축바 창, 전리품 창, 경매장, Sku에는 같은 기능이 없는 수집품 창과 전문 기술 창, 게임 메뉴와 설정, WowVision 메뉴가 여기에 해당합니다.
