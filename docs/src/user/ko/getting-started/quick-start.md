# 빠른 시작

WowVision과 함께하는 첫 15분입니다. 제대로 실행되는지 확인하고, 음성을 설정하고, 가장 중요한 키를 써 봅니다. 여기 나오는 내용은 모두 각 단계에 연결된 페이지에서 더 자세히 설명합니다.

이 페이지는 WowVision이 설치되어 있고 캐릭터가 게임 세계 안에 있다고 가정합니다. 그렇지 않다면 [설치](installation.md)부터 시작하십시오.

## 1단계: WowVision이 실행 중인지 확인하기

Shift+F1을 누릅니다. WowVision 메뉴가 열리고 WowVision이 첫 항목을 읽습니다. Escape를 누르면 다시 닫힙니다.

아무 일도 일어나지 않으면 대화 입력창에 /wv를 입력하고 Enter를 누릅니다. 그래도 아무 반응이 없으면 WowVision이 불러와지지 않은 것입니다. [문제 해결](troubleshooting.md#wowvision이-불러와지지-않음)을 보십시오.

## 2단계: 음성을 편하게 맞추기

대부분의 플레이어는 기본값보다 빠른 음성을 원합니다.

1. Shift+F1을 눌러 WowVision 메뉴를 엽니다.
2. Down Arrow로 음성을 찾아 Enter를 누릅니다.
3. 음성 속도로 이동해 몇 단계 올립니다(0이 보통이며, 게임 음성은 -10부터 10까지 설정할 수 있습니다). 새 속도는 그때부터 WowVision이 말하는 모든 것에 적용됩니다.
4. 원하면 음성 종류와 음성 음량도 같은 방법으로 바꿉니다.
5. 메뉴가 닫힐 때까지 Escape를 누릅니다.

접속할 때 실행되는 매크로에 넣어 두기 좋은 더 빠른 방법도 있습니다. 음성 1, 속도 8, 음량 100으로 하려면 `/wv speech 1 8 100`을 입력합니다. `/wv speech`만 입력하면 현재 값과 음성 목록을 번호와 함께 대화창에 출력합니다(첫 음성은 보통 번호가 0입니다). 자세한 내용은 [음성 및 소리](../basics/speech.md)에 있습니다.

## 3단계: 창 키 익히기

게임의 가방 키(기본값 B)로 가방을 엽니다. WowVision이 가방 창을 읽습니다. 이제 다음 키를 써 봅니다.

| 키 | 하는 일 |
|---|---|
| Up / Down Arrow | 칸 사이를 이동 |
| Tab / Shift+Tab | 창의 다음 또는 이전 부분으로 이동 |
| Space | 아이템의 툴팁 읽기 |
| Shift+Down / Shift+Up | 툴팁을 한 줄씩 읽기 |
| Enter | 왼쪽 클릭(아이템 집기) |
| Backspace | 오른쪽 클릭(아이템 사용 또는 착용) |
| Shift+F10 | 더 많은 동작이 있는 상황별 메뉴 |
| Escape | 창 닫기 |

같은 키가 모든 게임 창과 WowVision 자체 창에서 작동합니다. 열린 창이 없을 때는 이 키들이 다시 게임 키가 되므로 평소처럼 걷고 싸울 수 있습니다. 자세한 내용은 [인터페이스 사용하기](../basics/interface.md)에 있습니다.

## 4단계: 버퍼로 상태 확인하기

아무것도 열지 않은 상태에서 Alt+Down을 몇 번 누릅니다. WowVision이 일반 버퍼에서 생명력, 마나 또는 다른 자원, 경험치, 돈, 빈 가방 칸, 내구도, 우편, 귀환석, 시간, PvP 상태를 한 줄씩 읽습니다. Alt+Up을 누르면 이전 줄로 돌아갑니다.

Alt+Left와 Alt+Right는 다른 버퍼로 전환합니다. 직접 버퍼 그룹을 만든 뒤에는 Alt+Ctrl+Left와 Alt+Ctrl+Right를 눌러 다른 버퍼 그룹으로 전환합니다. [버퍼](../information/buffers.md)를 보십시오.

## 5단계: 세상에 귀 기울이기

잠시 그냥 플레이하면서 들어 봅니다. 따로 설정하지 않아도 WowVision은 다음을 알려 줍니다.

- 대상을 바꿀 때 새 대상, 그리고 5퍼센트 단위로 알리는 그 대상의 생명력
- 몸을 돌릴 때 나침반 방향
- 지역과 하위 지역 변경, 실내와 실외, 수영과 비행
- 떨어질 때 올라가는 음, 벽에 부딪힐 때 쿵 소리
- "전투 시작", 나와 싸우는 적의 수, "전투 종료"
- "목표가 사정거리를 벗어났습니다" 같은 게임 오류 메시지
- 읽고 있는 탭의 대화 메시지

이 안내는 모두 WowVision 메뉴에서 바꾸거나 끌 수 있는 알림입니다. [알림](../basics/alerts.md)를 보십시오.

## 6단계: 길 찾기

- F9를 누르면 주변에 있는 퀘스트 NPC, 퀘스트, 그 밖의 대상을 보여 주는 스캐너가 열립니다. 항목에서 Enter를 누르면 그곳으로 안내가 시작됩니다.
- 지도 데이터가 있는 버전에서는 F10을 누르면 길 안내 창이 열리고 경로의 목적지를 고를 수 있습니다.
- 경로가 진행 중일 때 I를 누르면 현재 경유지 쪽으로 돌아서고, Alt Gr(또는 Ctrl+Alt)를 누르면 거리를 듣습니다. Shift+F12는 경로를 멈춥니다.

[스캐너](../world/scanner.md)와 [길 안내와 경로](../world/navigation.md)를 보십시오.

## 7단계: 지금 알아 두면 좋은 다른 키

| 키 | 하는 일 |
|---|---|
| Shift+F3 | 대화 창: 대화 기록 읽기 |
| Shift+F4 | 행동 단축바 창 |
| Alt+T | 대상 메뉴(귓속말, 초대 등) |
| Shift+I / Shift+O / Shift+P | 적, 상호작용, 아군 소프트 대상 지정을 켜거나 끄기 |
| Ctrl+Shift+F | 미니맵에서 약초, 광석과 그 밖에 추적 중인 것 찾기(가능한 경우) |

모든 키는 [단축키 목록](../reference/keybindings.md)에 나와 있으며, 어느 키든 바꿀 수 있습니다. [단축키](../basics/keybindings.md)를 보십시오.
