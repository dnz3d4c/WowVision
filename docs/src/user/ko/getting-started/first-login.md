# 처음 로그인하기

## 로그인 화면 통과하기

WowVision은 캐릭터가 월드에 서 있을 때부터 작동합니다. 그 전에 로그인 화면, 서버 목록, 캐릭터 선택 화면을 거치는데, 게임은 캐릭터가 월드에 들어간 뒤에야 애드온을 불러오므로 어떤 애드온도 이 화면들을 읽을 수 없습니다. 이 화면들을 접근 가능하게 만들 수 있는 것은 게임 자체뿐입니다. WoW: Forever는 로그인 화면을 소리 내어 읽어 주지만, 여전히 마우스가 필요합니다.

Sku 프로젝트의 WoW Login Tool을 쓰면 이 화면들을 통과할 수 있습니다. 게임 옆에서 실행되는 작은 Windows 프로그램으로, 이 화면들에 음성 메뉴를 붙여 줍니다. Classic Era, The Burning Crusade 기념 서버, WoW: Forever를 지원합니다. Mists of Pandaria Classic과 Retail에서는 작동하지 않으므로, 이 두 버전에서는 비장애인에게 도움을 받으십시오. Battle.net 로그인은 Battle.net 앱으로 합니다. 이 앱은 Windows와 Mac 모두에서 스크린리더로 쓸 수 있습니다. "keep me logged in"을 한 번 체크해 두면, 앱에서 게임을 시작할 때 게임이 알아서 로그인합니다.

요약하면 다음과 같습니다.

1. 도구를 설치합니다. [설치 프로그램](./installer.md)이 대신 설치해 주고(WoW Login Tool 설치(권장) 항목이 기본으로 체크되어 있습니다) 바탕 화면에 WoW Login Tool 바로 가기를 만듭니다. 직접 설치하려면 [받아서 설치하기](./sku-login.md#받아서-설치하기)를 참고하십시오.
2. 도구를 시작합니다. WoW: Forever에서는 게임보다 먼저 시작합니다. 맨 처음 실행할 때 음성, 언어, 지역, 게임 종류를 묻습니다. Right로 들어가고, Up과 Down으로 고른 다음 Enter로 확정합니다. "Setup completed. Start the game now."라는 말이 들립니다.
3. 게임을 시작합니다. 도구가 "Login mode for"와 함께 게임 버전을 말하고, 이어서 "Main menu"라고 말합니다.
4. Classic Era와 The Burning Crusade에서는 Select character로 가서 Right를 누르고, Up과 Down으로 캐릭터를 고른 뒤 Enter를 누르고, Login with selected character에서 Enter를 누릅니다. 도구가 "Play mode"라고 말합니다. WoW: Forever에서는 도구가 각 항목으로 이동할 때 게임이 그 항목을 읽어 줍니다. [WoW: Forever에서 도구 쓰기](./sku-login.md#wow-forever에서-도구-쓰기)를 참고하십시오.

도구가 자체 메뉴와 게임 사이를 저절로 전환하지 않으면 Alt+F1을 누르십시오. 캐릭터 만들기, 서버 바꾸기, 전체 키 목록, 도구 자체의 문제 해결은 [Sku Login Tool로 로그인하기](./sku-login.md)에 있습니다.

## 월드에 들어간 뒤

캐릭터가 월드에 들어가면 WowVision이 저절로 시작됩니다. "불러왔다"는 음성 안내는 없습니다.

다음 두 방법 중 하나로 실행 중인지 확인하십시오.

- Shift+F1을 누릅니다. WowVision 메뉴가 열리고 첫 항목을 읽어 줍니다. 가장 빠른 확인 방법입니다.
- 대화창에 /wv를 입력하고 Enter를 누릅니다. 이것도 메뉴를 엽니다. /wv version은 설치된 버전을 대화창에 출력합니다.

그다음 몇 분을 들여 [빠른 시작](./quick-start.md)을 읽어 보십시오. 먼저 살펴볼 설정, 특히 음성 설정을 다룹니다.

### 캐릭터의 첫 로그인 때 WowVision이 바꾸는 것

게임 설정 몇 가지가 WowVision의 작동 방식에 방해가 되므로, WowVision은 새 캐릭터마다 이 설정을 한 번 바꿉니다. 딱 한 번만 바꾸므로, 나중에 설정을 되돌리면 WowVision은 그 선택을 건드리지 않습니다.

| 바뀌는 것 | 이유 | 되돌리는 방법 |
|---|---|---|
| 행동 단축바 잠그기가 꺼집니다 | 단축바가 잠겨 있으면 행동 단축바 수정 키를 누르고 있지 않는 한 행동 단축바에서 주문이나 아이템을 끌어내도 아무 일도 일어나지 않고, 그렇다는 사실도 알려 주지 않습니다. WowVision은 처음 한 번 대화창에 안내를 출력합니다. | 게임 설정의 행동 단축바에서 행동 단축바 잠그기를 다시 체크합니다. |
| 카메라가 항상 캐릭터 뒤를 따라가도록 설정되고(시점 전환 방식 항상 전환) 시점 변경이 즉시 이루어집니다 | 경유지 쪽으로 돌 때는 먼저 카메라를 돌린 다음, 캐릭터를 카메라와 같은 방향으로 돌립니다. 이 동작은 시점 전환 방식이 항상 전환일 때만 안정적으로 작동합니다. WowVision은 대화창에 안내를 출력합니다. | 게임 설정의 조작 설정에서 시점 전환 방식을 바꿉니다. 그러면 경유지 쪽으로 돌아서기가 불안정해집니다. |
| 게임의 대화 메시지 사이 소리가 꺼집니다 | 게임은 대화를 소리 내어 읽을 때 두 줄 사이에 짧은 소리를 내는데, 그 소리가 WowVision의 모든 안내 사이에서도 나게 됩니다. | WowVision 음성 메뉴의 대화 메시지 사이 소리 설정으로 바꾸거나, 게임 자체 명령어 /tts playline을 입력합니다. |

다음 두 가지는 한 번만 일어나는 것이 아니라 WowVision 설정을 따릅니다.

- 게임의 마우스 이동 옵션은 WowVision 길 안내 메뉴의 상호작용 대상으로 자동 이동 설정(기본으로 켜짐)을 따릅니다. 이 설정은 멀리 있는 대상과 상호작용하면 그 대상에게 걸어가게 합니다. WowVision은 로그인할 때마다 게임 설정을 이 설정에 맞추므로, 끄려면 게임 설정이 아니라 WowVision 설정을 쓰십시오.
- 소프트 대상 종류를 켜면 WowVision이 그 종류의 각도를 가장 넓게, 거리를 가장 길게 설정합니다. 꺼 둔 종류는 게임 값을 그대로 유지합니다. [대상 지정](../world/targeting.md)을 참고하십시오.

또 새 줄을 추가하는 업데이트 이후 기존 캐릭터로 처음 로그인하면, 일반 버퍼에 새 줄 몇 개(빈 가방 칸, 내구도, 우편, 귀환석, 게임 시계)가 생깁니다. [버퍼](../information/buffers.md)를 참고하십시오.
