# 처음 로그인하기

## 로그인 화면 통과하기

WowVision은 캐릭터가 월드에 들어간 뒤부터 작동합니다. 그 전에 로그인 화면, 서버 목록, 캐릭터 선택 화면을 거치는데, 게임은 캐릭터가 월드에 들어간 뒤에야 애드온을 불러오므로 어떤 애드온도 이 화면들을 읽을 수 없습니다. 이 화면들의 접근성은 게임 자체만 고칠 수 있습니다. WoW: Forever는 로그인 화면을 소리 내어 읽어 주지만, 여전히 마우스가 필요합니다.

Sku 프로젝트의 WoW Login Tool을 사용하면 이 화면들을 통과할 수 있습니다. 게임과 함께 실행되는 작은 Windows 프로그램으로, 이 화면들에 음성 메뉴를 붙여 줍니다. Classic Era, 불타는 성전 기념 서버, WoW: Forever를 지원합니다. 판다리아의 안개 클래식과 Retail에서는 작동하지 않으므로, 이 두 버전에서는 비장애인에게 도움을 받으십시오. Battle.net 로그인은 Battle.net 앱으로 합니다. 이 앱은 Windows와 Mac 모두에서 스크린리더로 사용할 수 있습니다. "keep me logged in"을 한 번 체크해 두면, 앱에서 게임을 시작할 때 게임이 알아서 로그인합니다.

요약하면 다음과 같습니다.

1. 도구를 설치합니다. [설치 프로그램](./installer.md)이 도구를 설치하고 바탕 화면에 WoW Login Tool 바로 가기를 만듭니다. WoW Login Tool 설치(권장) 항목은 기본으로 체크되어 있습니다. 직접 설치하려면 [받아서 설치하기](./sku-login.md#받아서-설치하기)를 참고하십시오.
2. 도구를 시작합니다. WoW: Forever에서는 게임보다 먼저 시작합니다. 맨 처음 실행할 때 음성, 언어, 지역, 게임 종류를 묻습니다. 각 질문에서 Right를 눌러 선택지로 들어가고, Up과 Down을 눌러 고른 다음 Enter를 눌러 선택을 확정합니다. "Setup completed. Start the game now."라는 말이 들립니다.
3. 게임을 시작합니다. 도구가 "Login mode for"와 함께 게임 버전을 말하고, 이어서 "Main menu"라고 말합니다.
4. Classic Era와 불타는 성전에서는 Select character로 가서 Right를 누르고, Up과 Down으로 캐릭터를 고른 뒤 Enter를 누르고, Login with selected character에서 Enter를 누릅니다. 도구가 "Play mode"라고 말합니다. WoW: Forever에서는 도구가 각 항목으로 이동할 때 게임이 그 항목을 읽어 줍니다. [WoW: Forever에서 도구 사용하기](./sku-login.md#wow-forever에서-도구-사용하기)를 참고하십시오.

도구가 자체 메뉴와 게임 사이를 저절로 전환하지 않으면 Alt+F1을 누르십시오. 캐릭터 만들기, 서버 변경하기, 전체 키 목록, 도구 자체의 문제 해결은 [Sku Login Tool로 로그인하기](./sku-login.md)에 있습니다.

## 월드에 들어간 뒤

캐릭터가 월드에 들어가면 WowVision이 저절로 시작됩니다. "불러왔다"는 음성 안내는 없습니다.

다음 두 방법 중 하나로 실행 중인지 확인하십시오.

- Shift+F1을 누릅니다. WowVision 메뉴가 열리고 첫 항목을 읽어 줍니다. 가장 빠른 확인 방법입니다.
- 대화 입력창에 /wv를 입력하고 Enter를 누릅니다. 이것도 메뉴를 엽니다. /wv version은 설치된 버전을 대화창에 출력합니다.

그다음 몇 분을 들여 [빠른 시작](./quick-start.md)을 읽어 보십시오. 먼저 살펴볼 설정, 특히 음성 설정을 다룹니다.

### 캐릭터의 첫 로그인 때 WowVision이 변경하는 것

게임 설정 몇 가지가 WowVision의 작동 방식에 방해가 되므로, WowVision은 새 캐릭터마다 이 설정을 한 번 변경합니다. 딱 한 번만 변경하므로, 나중에 설정을 되돌리면 WowVision은 사용자가 고른 값을 건드리지 않습니다.

| 변경되는 것 | 이유 | 되돌리는 방법 |
|---|---|---|
| 행동 단축바 잠그기가 꺼집니다 | 단축바가 잠겨 있으면 행동 단축바 수정 키를 누른 채로 끌어내야 합니다. 이 키를 누르지 않고 행동 단축바에서 주문이나 아이템을 끌어내면 아무것도 끌려 나오지 않고, 끌려 나오지 않았다는 안내도 없습니다. WowVision은 처음 한 번 대화창에 안내를 출력합니다. | 게임 설정의 행동 단축바에서 행동 단축바 잠그기를 다시 체크합니다. |
| 시점 전환 방식이 항상 전환으로 설정되어 카메라가 항상 캐릭터 뒤를 따라가고, 시점 변경이 즉시 이루어집니다 | 경유지 쪽으로 돌아서기는 먼저 카메라를 돌린 다음, 캐릭터를 카메라와 같은 방향으로 돌립니다. 이 동작은 시점 전환 방식이 항상 전환일 때만 안정적으로 작동합니다. WowVision은 대화창에 안내를 출력합니다. | 게임 설정의 조작 설정에서 시점 전환 방식을 변경합니다. 그러면 경유지 쪽으로 돌아서기가 불안정해집니다. |
| 게임의 대화 메시지 사이 소리가 꺼집니다 | 게임은 대화를 소리 내어 읽을 때 두 줄 사이에 짧은 소리를 내는데, 그 소리가 WowVision의 모든 안내 사이에서도 나게 됩니다. | WowVision 음성 메뉴의 대화 메시지 사이 소리 설정에서 다시 켜거나, 게임 자체 명령어 /tts playline을 입력합니다. |

다음 두 가지는 한 번만 일어나는 것이 아니라 WowVision 설정을 따릅니다.

- 게임의 마우스 이동 옵션은 WowVision 길 안내 메뉴의 상호작용 대상으로 자동 이동 설정(기본으로 켜짐)을 따릅니다. 이 설정이 켜져 있으면 멀리 있는 대상과 상호작용할 때 캐릭터가 그 대상까지 걸어갑니다. WowVision은 로그인할 때마다 게임의 마우스 이동 옵션을 상호작용 대상으로 자동 이동 설정에 맞추므로, 끄려면 게임의 마우스 이동 옵션이 아니라 WowVision 설정을 사용하십시오.
- 소프트 대상 종류를 켜면 WowVision이 그 종류를 잡는 각도를 가장 넓게, 잡는 거리를 가장 길게 설정합니다. 꺼 둔 종류는 게임 값을 그대로 유지합니다. [목표 선택](../world/targeting.md)을 참고하십시오.

또 일반 버퍼에 줄을 추가하는 업데이트가 나온 뒤 기존 캐릭터로 처음 로그인하면, 일반 버퍼에 새 줄 몇 개(빈 가방 칸, 내구도, 우편, 귀환석, 게임 시계)가 생깁니다. [버퍼](../information/buffers.md)를 참고하십시오.

### 권장 게임 설정(선택)

인터페이스 메뉴에 권장 게임 설정 적용 버튼이 있습니다. 권장 게임 설정은 제안일 뿐입니다. 이 버튼을 누르지 않으면 아무것도 변경되지 않고, 모든 설정은 나중에 게임 설정에서 언제든 직접 변경할 수 있습니다. 이 버튼은 다음을 설정합니다.

- 자동 전리품 획득을 켜고, 모든 행동 단축바를 표시합니다.
- 화면 밖 이름표를 켭니다. 게임이 적 이름표를 표시하는 동안에는 내 뒤쪽이나 옆에 있는 적에게도 곧바로 이름표가 생기므로, 적 수 알림이 뒤쪽이나 옆에 있는 적도 바로 셀 수 있습니다. 이 버튼은 적 이름표 자체는 켜지 않습니다. 적 이름표를 켜는 방법은 [이름표가 필요합니다](../world/combat.md#이름표가-필요합니다)를 참고하십시오.
- 아군 NPC 이름표를 켭니다. 그래야 대상 쪽으로 돌아서기와 주시 대상 쪽으로 돌아서기로 NPC 쪽으로도 돌아설 수 있습니다([길 안내](../world/navigation.md#대상과-주시-대상-쪽으로-돌아서기-ctrli-ctrlu) 참고).
- 게임의 음성 지원을 켜서, 내 생명력, 대상의 생명력, 내 자원을 20퍼센트마다 알리고(생명력은 숫자로만 알림), 누군가 나를 대상으로 지정하면 알리게 합니다("대상 지정 시 알림", 공격자 이름은 알리지 않음). 전투 시작과 종료, 대상 이름, 내 약화 효과 알림은 끕니다.

단축키, 카메라, 소프트 대상, 소리 크기는 건드리지 않습니다. 전투 중에는 이 버튼을 눌러도 아무 변화가 없습니다. 설정이 변경되면 인터페이스가 자동으로 다시 불러와집니다. 그다음 WowVision이 무엇이 변경되었는지 말하고 같은 내용을 대화창에 출력합니다. 자원 알림과 "대상 지정 시 알림"은 게임이 전문화마다 따로 저장하므로, 전문화를 전환한 뒤에는 버튼을 다시 누르십시오.
