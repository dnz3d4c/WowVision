# 음성 및 소리

WowVision은 게임에 내장된 TTS(텍스트 음성 변환)로 모든 것을 말하며, 컴퓨터에 설치된 음성을 사용합니다. 이 페이지에서는 음성 고르기, 속도와 음량 설정, 음성 멈추기, 게임 자체의 TTS 소리, 녹음된 음성 팩, 빠른 /wv speech 명령을 다룹니다.

## 설정이 있는 곳

Shift+F1을 누르거나 /wv를 입력해 [WowVision 메뉴](./menu-and-settings.md)를 열고, 음성 항목이 들릴 때까지 Down을 누른 다음 Enter를 누릅니다. /wv gsettings speech를 입력해 음성 설정으로 바로 갈 수도 있습니다.

음성 모듈은 항상 켜져 있으며, 사용함 체크 상자가 없습니다.

## 음성 설정

| 설정 | 기본값 | 하는 일 |
|---|---|---|
| 음성 종류 | 설치된 음성 중 첫 번째 | 어떤 TTS 음성이 말할지 정합니다. Enter를 누르면 컴퓨터에 설치된 음성 목록이 열립니다. WowVision은 음성을 이름으로 기억하므로, 나중에 Windows 음성을 설치하거나 제거해도 모르는 사이에 다른 음성으로 전환되지 않습니다. |
| 음성 음량 | 100 | TTS 음성의 크기로, 0부터 100까지입니다. |
| 음성 속도 | 0 | 음성의 빠르기입니다. 0이 보통이고, 음수는 더 느리고 양수는 더 빠릅니다. -10부터 10까지이며, 이 범위를 벗어난 값은 가까운 끝값으로 맞춰집니다. |
| 음성 대기열 | 켬 | (The Burning Crusade, Mists of Pandaria, Retail, WoW: Forever) WowVision이 한 번에 한 줄씩 말하고, 게임과 다른 애드온에서 오는 음성까지 포함해 나머지 줄은 차례로 대기열에 넣습니다. 음성을 사용하는 다른 애드온이 제대로 동작하지 않을 때만 끄십시오. 끄면 WowVision이 대기열을 거치지 않고 게임 TTS에 바로 말을 보냅니다. |
| 음성 방식 | 직접 | (Classic Era 전용) 직접 방식은 각 줄을 바로 말합니다. 모아 말하기 방식은 말할 줄을 차례로 모아 두고, 음성이 중간에 끊길 때마다 잠시 기다린 뒤 다음 줄을 말합니다. 음성이 끊긴 뒤 다음 줄의 첫 단어들이 들리지 않으면 모아 말하기 방식을 사용해 보십시오. |
| 대화 메시지 사이 소리 | 첫 접속 뒤 꺼짐 | 대화 메시지 줄 사이를 구분하는 게임 자체 소리입니다. [음성과 함께 나는 게임 소리](#음성과-함께-나는-게임-소리)를 보십시오. |
| 대화창이 비활성일 때 활동 소리 | 게임 설정을 따름 | 대화창이 숨겨진 동안 메시지를 말할 때 나는 게임 자체 소리입니다. |

예: 음성 속도 올리기.

1. Shift+F1을 눌러 WowVision 메뉴를 엽니다.
2. "음성, 버튼"이 들릴 때까지 Down을 누른 다음 Enter를 누릅니다.
3. Down을 눌러 음성 속도, 숫자, 0이 들리는 곳으로 갑니다.
4. Right를 몇 번 누릅니다. 변경된 숫자가 하나씩 들리고, 다음 줄부터 음성이 더 빠르게 말합니다. 또는 Enter를 누르고 5를 입력한 뒤 Enter를 누릅니다.

예: 음성 변경하기.

1. 음성 메뉴에서 음성 종류로 이동해 Enter를 누릅니다.
2. 음성 목록 안에서 차례로 이동합니다. 현재 음성은 "선택됨"으로 읽힙니다. 원하는 음성에서 Enter를 누릅니다.

Classic Era, TBC, Mists에서는 WowVision이 말하는 내용의 빗금 앞뒤에 공백을 넣으므로, "250/500"이 "250 / 500"처럼 두 숫자로 읽힙니다. Retail과 WoW: Forever에서는 WowVision이 말할 글자를 변경하지 않고 그대로 게임 TTS에 전달합니다.

음성 종류, 음성 음량, 음성 속도 설정과 음성 대기열 또는 음성 방식 설정은 기본적으로 계정 전체에 적용됩니다. 설정 위에서 상황별 메뉴(Shift+F10)를 열고 범위 항목을 사용하면 한 캐릭터에만 따로 값을 설정할 수 있습니다. [캐릭터별 설정과 계정 전체 설정](./menu-and-settings.md#캐릭터별-설정과-계정-전체-설정)을 보십시오. 게임 소리 체크 상자 두 개는 게임 자체 설정이므로 범위 항목이 없습니다.

## /wv speech로 빠르게 설정하기

/wv speech는 음성, 속도, 음량을 한 줄로 설정합니다. 바로 적용되고 확인 안내를 말하므로 접속 매크로에 사용하기 좋게 만들어졌습니다.

| 입력 | 결과 |
|---|---|
| /wv speech | 현재 음성 번호, 속도, 음량을 대화창에 출력하고, 이어서 모든 음성을 번호와 함께 나열합니다. 이 출력은 보통 대화 메시지처럼 음성으로 들립니다. |
| /wv speech 1 8 100 | 음성 번호 1, 속도 8, 음량 100. |
| /wv speech 1 8 | 음성 1, 속도 8. 음량은 그대로입니다. |
| /wv speech 2 | 음성 2번만. 속도와 음량은 그대로입니다. |

음성 번호는 0부터 시작합니다. 첫 음성이 0번입니다. 속도는 -10부터 10까지, 음량은 0부터 100까지로 제한되며, 소수는 반올림됩니다. 없는 음성 번호를 넣거나 값이 숫자가 아니면 WowVision은 대화창에 메시지를 출력하고 아무것도 변경하지 않습니다. 제대로 되면 예를 들어 "Speech voice Microsoft Zira Desktop, rate 8, volume 100"이 들립니다.

## 음성 멈추기

- 언제든 Ctrl만 누르면 지금 나오는 음성이 끊깁니다. 창이 열려 있든 아니든 동작하고, Ctrl을 보조 키로 사용할 때(Ctrl+Tab, Ctrl+D)도 동작합니다. 키가 눌리는 순간 음성이 멈추기 때문입니다.
- 탐색 키(화살표, Tab, Home, End 등)는 어느 것을 누르든 WowVision이 하던 말을 먼저 멈추고 새 컨트롤을 읽으므로, 화살표를 빠르게 눌러도 말이 밀리지 않습니다.
- 창을 닫을 때 음성 중단 설정(인터페이스 메뉴, 기본 꺼짐)을 켜면 창이 닫힐 때도 음성이 끊깁니다. 창을 벗어난 뒤에도 이전 창의 내용이 계속 읽히면 이 설정을 켜십시오.
- 알림도 말을 끊을 수 있습니다. 우선 메시지 (현재 음성 중단)가 켜진 TTS 알림은 말하기 전에 현재 음성을 멈춥니다. 대상 변경 알림이 그 예입니다. [알림](./alerts.md)을 보십시오.

## 음성과 함께 나는 게임 소리

게임의 TTS는 자체적으로 작은 소리 두 가지를 내며, WowVision은 음성 메뉴에 각각의 체크 상자를 둡니다.

- 대화 메시지 사이 소리는 게임이 대화 메시지 줄 사이에 내는 짧은 소리입니다. 이 소리가 WowVision의 모든 안내 사이에서도 나게 되므로, WowVision을 켠 채 각 캐릭터로 처음 접속하면 WowVision이 이 소리를 꺼 둡니다. 그 뒤로는 선택한 대로 유지됩니다. 다시 켜면 켜진 채로 있습니다.
- 대화창이 비활성일 때 활동 소리는 대화창이 숨겨진 동안 메시지를 말할 때 나는 게임 소리입니다.

이 두 체크 상자는 WowVision이 저장하지 않습니다. 게임 자체 설정이므로 게임의 /tts playline, /tts playactivity 명령과 음성 메뉴는 항상 일치합니다.

## 녹음된 음성 팩

일부 알림은 TTS 대신 녹음을 재생합니다. 나침반 방향("north", "northeast"), 1부터 100까지의 숫자(대상 생명력, 대상까지 거리, 적의 수) 등입니다. 이 녹음은 음성 팩으로 제공됩니다. WowVision에는 두 가지가 들어 있습니다.

- Matthew
- Joanna

음성 팩 알림 유형의 알림 출력마다 팩을 고르는 설정이 있습니다. 이름은 음성 팩이고, 출력 화면의 사용함 체크 상자 바로 아래에 있습니다. 녹음은 즉시 재생되며 음성 대기열, TTS 음성, TTS 속도의 영향을 받지 않습니다. 출력을 고르는 방법은 [알림](./alerts.md)을 보십시오.

## 알림마다 다른 음성

TTS 알림 출력마다 따로 음성 설정이 있습니다. 이 음성 설정은 다른 음성을 고르기 전까지 음성 종류를 그대로 따르며, 음성 종류에서 고른 음성을 값으로 보여 줍니다. 여기서 다른 음성을 고르면 해당 알림은 항상 새로 고른 음성을 사용합니다. 예를 들어 대상 변경은 한 음성으로, 대화는 다른 음성으로 들을 수 있습니다.

걷는 동안 나오는 안내(미니맵의 새 점)는 음성 종류 대신 게임의 0번 음성으로, 음성 속도와 음성 음량에 맞춰 나옵니다. 음성 종류로 스크린리더 음성을 쓰면 키를 누를 때마다 스크린리더가 걷기 안내를 끊기 때문입니다. 이 알림의 음성 설정도 변경할 수 있습니다. 이 알림에는 우선 메시지 (현재 음성 중단) 설정이 없습니다.

## 스크린리더 음성 사용하기

음성 종류로 고른 TTS 음성이 텍스트를 스크린리더에 전달해 읽게 하는 경우에도(SAPI2SR 음성으로 NVDA가 읽는 경우 등), WowVision은 일반 음성과 마찬가지로 반복되는 줄을 매번 말하고 새 줄이 이전 줄을 끊도록 합니다.

따로 켤 것은 없습니다.

## 게임 버전별 차이

| | Classic Era | TBC, Mists | Retail, WoW: Forever |
|---|---|---|---|
| 음성 대기열 | 사용 불가 | 있음 | 있음 |
| 음성 방식(직접 또는 모아 말하기) | 있음 | 사용 불가 | 사용 불가 |
| 빗금 앞뒤 공백 | 있음 | 있음 | 없음 |
| 음성, 음량, 속도, 게임 소리 체크 상자 | 있음 | 있음 | 있음 |
