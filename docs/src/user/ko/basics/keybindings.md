# 단축키

WowVision이 쓰는 키는 모두 변경할 수 있습니다. 단축키 화면은 각 동작과 그 동작에 지정된 키를 보여 주고, 키를 추가하거나 제거하거나 한 동작에서 다른 동작으로 옮길 수 있게 합니다. 이 페이지는 단축키 화면을 쓰는 방법과 안내 문구의 뜻을 설명합니다. 전체 동작 목록과 기본 키는 [단축키 목록](../reference/keybindings.md)에 있습니다.

## 단축키 화면 열기

1. Shift+F1을 누르거나 /wv를 입력해 [WowVision 메뉴](./menu-and-settings.md)를 엽니다.
2. Down으로 인터페이스까지 내려가 Enter를 누릅니다.
3. Down으로 단축키까지 내려가 Enter를 누릅니다.

초점이 첫 단축키에 놓이고, 예를 들어 "단축키, 목록, 위, 막대, 위 화살표, 버튼, 1 of 2"라고 들립니다. Escape를 누르면 인터페이스 메뉴로 돌아갑니다.

더 빠른 방법: /wv bind를 입력합니다. 같은 화면이 별도 창으로 바로 열리며, 이때는 Escape를 누르면 닫힙니다.

## 화면 구성

동작마다 한 줄이 있습니다. 한 줄에는 왼쪽부터 다음이 들어 있습니다.

- 그 동작에 현재 지정된 키마다 버튼 하나. 버튼 이름은 키 이름입니다("Enter", "위 화살표", "Ctrl-Tab").
- 추가 버튼 하나.
- 게임의 게임패드 인터페이스가 켜져 있으면 컨트롤러 버튼마다 버튼 하나와 컨트롤러 버튼 추가 버튼([컨트롤러 버튼](#컨트롤러-버튼-retail-wow-forever) 참고).

줄은 동작 이름, "막대", 초점이 놓인 버튼 순서로 읽힙니다. 예를 들어 "왼쪽 클릭, 막대, Enter, 버튼, 1 of 2"입니다. 키가 하나도 없는(그리고 표시되는 컨트롤러 버튼도 없는) 동작은 줄에 추가만 있고, "막대" 대신 "목록"으로 읽힙니다.

| 키 | 이 화면에서 하는 일 |
|---|---|
| Down / Up | 다음 또는 이전 동작으로 이동합니다. |
| Right / Left | 키, 추가 등이 있는 줄을 따라 이동합니다. |
| Home / End | 첫 동작 또는 마지막 동작으로 이동합니다. |
| 글자 키 | 이름이 그 글자로 시작하는 다음 동작으로 이동합니다. |
| 키 버튼에서 Enter | 그 키를 동작에서 제거합니다. |
| 추가 버튼에서 Enter | 새 키 입력 받기를 시작합니다. |
| Escape | 화면에서 나갑니다. |

동작은 애드온이 불러온 순서로 나열됩니다. 창 이동 키가 먼저 나오고 그다음에 다른 모듈이 나옵니다. 동작을 찾으려면 이름의 첫 부분을 입력합니다. S를 누르면 이름이 S로 시작하는 다음 동작으로, S를 한 번 더 누르면 그다음 동작으로 이동하고, 여러 글자를 빠르게 이어 누르면 그 글자들로 시작하는 동작을 찾습니다. 다만 동작 이름이 한국어로 표시되므로 S에 이어 C를 눌러도 "스캐너"를 찾을 수 없습니다. 영문 글자 키로는 이름이 영문으로 시작하는 동작만 찾을 수 있습니다. 초점은 그 동작의 첫 키에 놓이고, 키가 없으면 추가에 놓입니다. [메뉴에서 글자로 이동](./interface.md#메뉴에서-글자로-이동)을 참고하십시오.

키가 없는 동작에는 추가만 표시됩니다. 이것이 "기본으로 지정되지 않은" 동작입니다. 동작 자체는 있지만 키는 직접 지정해야 합니다. 예로 모든 모니터 켜고 끄기, 대상까지 경로 안내, 거리 알림이 있습니다.

## 키 추가하기

1. 동작의 추가 버튼으로 가서 Enter를 누릅니다. WowVision이 동작 이름을 말하고 키보드 입력을 받기 시작합니다. 입력을 받는 동안에는 어떤 키도 게임이나 WowVision 자체 동작에 전달되지 않습니다.
2. 원하는 키 조합을 누릅니다. 예를 들어 Alt를 누른 채 D를 누릅니다. 누르는 대로 WowVision이 "ALT-D"처럼 조합을 읽습니다.
3. 주 키에서 손을 뗍니다. 조합이 동작에 추가됩니다. 보조 키는 항상 Alt, Ctrl, Shift 순서로 적히므로 "ALT-CTRL-SHIFT-K"처럼 됩니다.

입력을 받는 동안 알아 둘 점:

- Escape는 입력 받기를 취소합니다. 그래서 여기서는 Escape 자체를 동작에 지정할 수 없습니다.
- 보조 키 하나만(Shift만, Ctrl만) 지정할 수는 없습니다. 보조 키는 다른 키와 함께 누른 조합의 일부로만 인정됩니다.
- 조합은 주 키를 누른 순간 누르고 있던 보조 키로 정해집니다. 글자 키보다 Alt를 조금 먼저 떼어도 괜찮습니다.
- 키가 추가된 뒤에는 아무 소리도 나지 않습니다. 추가에서 Left를 누르면 새 키의 버튼을 들을 수 있습니다.

예: 거리 알림에 Alt+D 키를 지정하기.

1. 위에서처럼 단축키 화면을 엽니다.
2. "거리 알림, 목록, 추가, 버튼"이 들릴 때까지 Down을 누릅니다.
3. Enter를 누릅니다. "거리 알림"이 들립니다.
4. Alt를 누른 채 D를 누르고 둘 다 뗍니다. 키를 누르는 순간 "ALT-D"가 들립니다.
5. Left를 누르면 "Alt-D, 버튼"이 들립니다. 키는 즉시 저장되고 바로 작동합니다.

한 동작에 키를 여러 개 둘 수 있습니다. 예를 들어 끌기에는 처음부터 \\와 Ctrl+D가 지정되어 있습니다. 원하는 만큼 추가하십시오.

## 키 제거하기

키 버튼에서 Enter를 누르면 묻지 않고 즉시 제거되고, 초점이 옮겨 간 곳을 읽어 줍니다. 키를 변경하려면 새 키를 추가한 뒤 이전 키를 제거하거나, 반대 순서로 합니다.

대부분의 동작은 키를 모두 제거할 수 있습니다. 그러면 그 동작은 키를 추가할 때까지 키가 없는 상태가 됩니다. 예외는 아래의 필수 동작입니다.

## 충돌

두 동작이 한 키를 함께 쓸 수는 없습니다. 입력한 키가 이미 다른 동작에 지정되어 있으면 다음 중 하나가 들립니다.

| 들리는 말 | 뜻 | 할 일 |
|---|---|---|
| "이 입력은 이미 이 단축키에 있음." | 이 동작에 이미 이 키가 있습니다. | 변경된 것은 없습니다. |
| "이 입력과 충돌하는 단축키 (동작 이름). 바꾸시겠습니까?" 다음에 예와 아니요 | 다른 동작에 이 키가 있습니다. | 예를 고르면 다른 동작에서 키를 빼서 지금 키를 추가하려는 동작에 줍니다. 아니요나 Escape는 아무것도 변경하지 않습니다. |
| "이 단축키는 입력이 하나 이상 필요해서 바꿀 수 없음." | 다른 동작이 필수 동작이고 이 키가 그 동작의 유일한 키입니다. | 먼저 그 동작에 다른 키를 지정한 뒤 다시 시도합니다. |

예: Space도 왼쪽 클릭으로 쓰고 싶다고 합시다. 왼쪽 클릭 줄의 추가에서 Enter를 누르고 Space를 누릅니다. "이 입력과 충돌하는 단축키 툴팁 읽기. 바꾸시겠습니까?"가 들립니다. Down으로 예까지 가서 Enter를 누릅니다. 이제 Space를 누르면 클릭이 되고, 툴팁 읽기에는 키가 없어졌습니다. 툴팁 읽기를 계속 쓰려면 Shift+Space 같은 다른 키를 지정하십시오.

WowVision은 자체 동작끼리만 키를 확인합니다. 게임 자체 단축키는 확인하지 않으며, WowVision 키가 작동하는 동안에는 그 키가 게임 단축키보다 우선합니다. 다른 용도로 필요하지 않은 키를 고르십시오.

## 필수 동작

필수 동작에는 항상 키가 하나 이상 남아 있으므로 인터페이스를 쓸 수 없게 되는 일은 없습니다. 필수 동작의 마지막 키를 제거하려 하면 "제거 불가; 단축키에는 입력이 하나 이상 있어야 함."이 들립니다. 그래도 다른 키를 추가한 뒤 이전 키를 제거할 수는 있습니다.

| 동작 | 기본 키 |
|---|---|
| 위 | Up |
| 아래 | Down |
| 왼쪽 | Left |
| 오른쪽 | Right |
| 다음 | Tab |
| 이전 | Shift+Tab |
| 다음 창 | Ctrl+Tab |
| 이전 창 | Ctrl+Shift+Tab |
| 닫기 | Escape |
| 왼쪽 클릭 | Enter |
| 오른쪽 클릭 | Backspace |
| 끌기 | \\와 Ctrl+D |
| 위로 스크롤 | Page Up |
| 아래로 스크롤 | Page Down |
| 상황별 메뉴 | Shift+F10 |

처음으로 이동, 끝으로 이동, 툴팁 읽기, WowVision 메뉴, 커서에 든 아이템 파괴 같은 다른 동작은 키를 모두 제거해도 됩니다. WowVision 메뉴의 키를 모두 제거했더라도 /wv를 입력하면 메뉴를 열 수 있습니다.

위의 이동 키는 WowVision 창이 열려 있을 때만 작동합니다. 열린 창이 없으면 평소처럼 게임이 이 키를 씁니다. 버퍼 키, 스캐너 키(F9), 길 안내 창 키(F10) 같은 다른 동작은 항상 작동합니다. [인터페이스 사용하기](./interface.md)를 참고하십시오.

## 변경 내용이 저장되는 곳

단축키는 계정 전체에 적용되므로, 한 캐릭터에서 변경한 키는 모든 캐릭터에서 변경됩니다. 한 캐릭터에만 따로 키를 주려면 인터페이스 메뉴의 단축키로 가서 Shift+F10을 누르고 범위를 고른 뒤 캐릭터 이름을 고릅니다. 선택한 캐릭터에 현재 단축키 전체가 한꺼번에 복사됩니다. 공유 단축키로 돌아가려면 전역을 고릅니다. "기본값으로 초기화" 버튼은 없습니다. 기본 키를 되돌리려면 [단축키 목록](../reference/keybindings.md)을 보고 다시 추가합니다.

## Sku를 불러왔을 때 꺼지는 키

Sku 애드온도 함께 쓰면, WowVision은 두 애드온이 부딪치지 않도록 Sku도 쓰는 몇몇 키를 차지하지 않습니다. 툴팁 줄 키 네 개(Shift+Up, Shift+Down, Shift+Left, Shift+Right), 소프트 대상 지정 키(Shift+I, Shift+P, Shift+O), 주시 대상 선택 키 다섯 개입니다. /pquit, /dquit, /focus1부터 /focus5처럼 Sku에도 있는 다른 명령도 마찬가지로 Sku에 맡깁니다. 이 키들은 단축키 화면에 계속 표시되지만 Sku를 불러온 동안에는 아무 일도 하지 않습니다. 같은 방식으로 WowVision은 여러 게임 창(가방, 상인, 대화, 우편, 거래, 퀘스트 등)을 Sku에 맡깁니다.

## 컨트롤러 버튼 (Retail, WoW: Forever)

게임의 게임패드 옵션이 켜져 있으면 단축키 화면의 각 줄에 그 줄의 동작에 지정된 컨트롤러 버튼도 표시되고, 그 뒤에 컨트롤러 버튼 추가가 표시됩니다. 컨트롤러 버튼은 키와 같은 방식으로 작동합니다.

- 컨트롤러 버튼에서 Enter를 누르면 그 버튼이 제거됩니다.
- 컨트롤러 버튼 추가에서 Enter를 누르면 동작 이름에 이어 "컨트롤러 버튼을 누르십시오"라고 말합니다. 원하는 버튼을 누릅니다. 어깨 버튼, 트리거, 오른쪽 스틱 누르기는 보조 키처럼 누른 채로 쓸 수 있으므로 "오른쪽 트리거 + A 버튼"은 그 자체로 하나의 조합입니다. 보조 키처럼 쓰는 버튼을 단독으로 눌렀다 떼면 그 버튼 자체로 인정됩니다.
- 충돌 안내 문구도 같습니다. 키보드에서 Escape를 누르거나, 10초 동안 버튼을 누르지 않거나, 전투가 시작되면 "취소됨"이 들리고 입력 받기가 취소됩니다. 전투 중에는 입력을 받을 수 없으며 "전투 중에는 불가"가 들립니다.

닫기 (컨트롤러) 동작에는 기본 키보드 키가 없습니다. 이 동작은 Escape를 게임에 맡기는 창에서 컨트롤러의 닫기 버튼으로 게임 자체의 Escape를 실행하게 합니다.

자세한 내용은 모두 [컨트롤러 페이지](../controller.md)에 있습니다.
