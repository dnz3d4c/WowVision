# WowVision 메뉴와 설정

WowVision 메뉴는 음성, 알림, 길 안내, 버퍼, 모니터, 창 등 애드온의 여러 기능을 설정하는 곳입니다. 다른 WowVision 창과 똑같이 작동하므로 [인터페이스 사용하기](./interface.md)의 내용이 모두 적용됩니다. 이 페이지에서는 메뉴의 구성, 설정 종류별 편집 방법, 설정을 캐릭터별 또는 계정 전체로 저장하는 방법을 설명합니다.

## 메뉴 열고 닫기

| 방법 | 동작 |
|---|---|
| Shift+F1 | 메뉴를 엽니다(WowVision 메뉴 단축키). |
| /wv | 메뉴를 엽니다. /wv 뒤에 WowVision 명령이 아닌 내용을 붙여 입력해도 메뉴가 열립니다. |
| Right Arrow | 항목에 다음 단계가 있으면 다음 단계를 엽니다. |
| Left Arrow | 이전 단계로 돌아갑니다. 첫 단계에서는 아무 일도 일어나지 않고 메뉴가 열린 채로 있습니다. |
| Escape | 이전 단계로 돌아갑니다. 첫 단계에서는 메뉴를 닫습니다. |
| /wv close | 모든 WowVision 창을 강제로 닫습니다. |

메뉴가 열리면 음성이 멈추고 메뉴 이름과 첫 항목이 들립니다. 예를 들면 "WowVision, 목록, 길 안내, 버튼, 1 of 13"입니다. 정확한 항목 수는 게임 버전에 따라 다릅니다.

전투 중에는 WowVision이 키 처리를 멈추므로 메뉴는 전투 전이나 전투 후에 여십시오. [전투](./interface.md#전투)를 보십시오.

자체 설정이 있는 모듈의 화면은 /wv gsettings 뒤에 짧은 이름을 붙여 바로 열 수 있습니다. 예를 들면 /wv gsettings speech입니다. 이름은 모듈의 영어 이름을 소문자로 쓴 것이며, 하위 모듈은 점으로 잇습니다.

| 명령 | 열리는 화면 |
|---|---|
| /wv gsettings speech | 음성 |
| /wv gsettings ui | 인터페이스 |
| /wv gsettings ui.tooltip.quality | 인터페이스, 툴팁, 등급 |
| /wv gsettings ui.combat | 인터페이스, 전투 |
| /wv gsettings navigation.compass | 길 안내, 나침반 |
| /wv gsettings navigation.maps | 길 안내, 비컨과 경로 |
| /wv gsettings chat | 대화 |
| /wv gsettings targeting | 목표 선택 |
| /wv gsettings errors | 오류 |
| /wv gsettings navigation.falling | 길 안내, 낙하 감지 |

이름이 자체 설정이 있는 모듈과 맞지 않으면(예: ui.tooltip이나 게임 창 중 하나) WowVision이 대화창에 "No settings found for"와 그 이름을 출력합니다. 이 명령은 테스터를 위한 지름길이며, 메뉴로도 언제나 같은 화면에 갈 수 있습니다.

## 메뉴 구성

메뉴는 트리 구조입니다. 첫 화면에는 모듈이 이름의 가나다순으로 나열됩니다. 모듈에서 Enter를 누르면 그 모듈의 화면이 열리고, 그 화면에 다시 하위 모듈이 나열될 수 있습니다. 각 화면은 목록이며, Escape를 누르면 위로 돌아갑니다.

모듈 화면에는 위에서 아래로 다음이 있습니다.

1. 사용함 체크 상자. 음성과 인터페이스를 뺀 모든 모듈에 있습니다. 모듈을 끄면 키, 알림, 창을 포함한 그 모듈의 기능이 바로 멈추며, 이 선택은 현재 캐릭터의 설정으로 저장됩니다.
2. 하위 모듈. 이름의 가나다순으로 나열된 버튼입니다.
3. 일부 모듈에만 있는 특별 항목. 예를 들어 인터페이스 모듈에는 단축키 버튼이, 버퍼 모듈에는 버퍼 그룹 목록이, 오류 모듈에는 오류별 필터 버튼이 있습니다.
4. 모듈 자체의 설정.
5. 모듈의 알림. 각각 버튼입니다. [알림](./alerts.md)을 보십시오.

예: 대화를 열면 "대화, 목록, 사용함, 체크 상자, 체크됨"이 들립니다. Down을 눌러 대화 탭 알림과 다른 항목 사이를 차례로 이동합니다.

키보드 입력을 받는 목록이므로 글자를 눌러 그 글자로 시작하는 항목으로 건너뛸 수 있습니다. 다만 한국어 메뉴는 항목 이름이 한글로 시작하므로 영문 글자 키로는 음성이나 목표 선택을 찾지 못하고 "결과 없음"이 들립니다. 이때는 Down으로 이동하십시오. [글자로 이동](./interface.md#메뉴에서-글자로-이동)을 보십시오.

### 인터페이스 모듈

WowVision 메뉴 첫 화면에서 Down으로 인터페이스까지 간 뒤 Enter를 누릅니다. 다음 항목이 있습니다.

| 항목 | 기본값 | 하는 일 |
|---|---|---|
| 전투 | | 적 수, 전투 시작 알림과 전투 종료 알림. [전투](../world/combat.md)를 보십시오. |
| 커서 | | 사용함 체크 상자만 있습니다. 끄면 커서에 든 아이템 파괴 키가 없어집니다. |
| 툴팁 아래의 등급 | | 어떤 아이템 등급 색을 읽을지 정합니다. [툴팁](./tooltips.md#이름에-붙는-아이템-등급)을 보십시오. |
| 단축키 | | 단축키 화면. [단축키](./keybindings.md)를 보십시오. |
| 창을 닫을 때 음성 중단 | 끔 | 창이 닫힐 때마다 음성을 끊습니다. |
| WowVision 메뉴를 열고 닫을 때 소리 | 켬 | WowVision 창이 열릴 때 짧은 소리를, 닫힐 때 다른 소리를 재생합니다. WowVision 메뉴, 스캐너, 길 안내 창, 행동 단축바, 대화가 해당합니다. 게임 기본 창은 게임이 내는 소리가 나고 WowVision 소리는 나지 않습니다. |
| 메뉴에서 글자로 이동 | 켬 | 메뉴에서 글자 키를 눌러 항목으로 건너뜁니다. 메뉴가 열려 있는 동안에도 글자 키가 계속 원래대로 작동해야 하면 끄십시오. |
| WowVision 소리 채널 | 효과 | WowVision의 모든 소리가 재생되는 게임 소리 채널입니다. 알림 소리, 음성 팩, 비컨, 소리 탐색기의 미리 듣기가 모두 여기에 해당합니다. 항목 이름은 게임 소리 설정의 음량 슬라이더 이름과 같으므로, 고른 채널의 슬라이더가 곧 WowVision의 음량이 됩니다. 다른 용도로 거의 사용하지 않는 채널을 고르면 WowVision만의 음량을 따로 둘 수 있습니다. Retail과 WoW: Forever에서는 게임 플레이 효과음도 고를 수 있습니다. |

### 창 모듈

WowVision이 다루는 게임 창은 모두 여기에 자기 항목이 있습니다. 예를 들어 게임 메뉴, 상인, 우편, 전리품이 있고, 각각 사용함 체크 상자가 있으며 자체 설정이 있는 것도 있습니다. 창의 모듈을 끄면 WowVision이 그 창을 완전히 무시하므로 게임 창은 게임이 만든 그대로 남습니다. 특정 창 하나만 다른 애드온의 방식으로 사용하고 싶을 때 유용합니다.

## 설정 종류별 편집 방법

| 종류 | 들리는 말 | 변경하는 방법 |
|---|---|---|
| 체크 상자 | "사용함, 체크 상자, 체크됨" | Enter를 누르면 상태가 변경되고 WowVision이 새 상태를 읽습니다. |
| 숫자 | "지연 (밀리초), 숫자, 200" | Left와 Right로 1씩 변경할 수 있으며, 변경할 때마다 새 값을 말합니다. Enter를 누르면 입력 상자가 열립니다. 숫자를 입력하고 Enter를 누르십시오. 허용 범위를 벗어난 값은 가장 가까운 허용 값으로 맞춰집니다. |
| 선택 | "적 수 세기, 드롭다운, 나 또는 내 파티나 공격대를 공격 중" | Enter를 누르면 선택지 목록이 열리고 초점이 현재 선택지에 놓입니다. 다른 선택지에서 Enter를 누르면 그것을 고르고 돌아가며, Escape를 누르면 변경하지 않고 목록을 닫습니다. |
| 텍스트 | "메시지, 편집, hello" | Enter를 누르면 입력 상자가 열리고 지금 들어 있는 텍스트가 선택되어 있습니다. 입력한 뒤 Enter로 입력한 내용을 확정하거나 Escape로 취소합니다. Tab으로 이 항목에 오면 상자가 바로 열립니다. |
| 기간 | "(이름), 숫자, 1 분 5 초" | 숫자와 같습니다. Left와 Right를 누르면 값이 1초씩 변경되고, 입력할 때는 초 단위로 입력합니다. |
| 음성 | "음성, 드롭다운, Microsoft Zira Desktop" | 설치된 TTS 음성 중에서 고르는 선택 설정입니다. |
| 음성 팩 | "음성 팩, 드롭다운, Matthew" | 녹음된 음성 팩 중에서 고르는 선택 설정입니다. [음성](./speech.md#녹음된-음성-팩)을 보십시오. |
| 소리 또는 비컨 선택 목록 | "소리, 버튼, chat.mp3" | [소리 고르기](#소리-고르기)를 보십시오. |
| 주문 | "주문, 버튼, 별빛쇄도 (78674)" | [주문 고르기](#주문-고르기)를 보십시오. |
| 템플릿 | "템플릿, 버튼, 기본" | [템플릿 편집하기](#템플릿-편집하기)를 보십시오. |
| 알림 | 버튼으로 읽는 알림 이름 | 알림 화면을 엽니다. [알림](./alerts.md)을 보십시오. |
| 설정 묶음 | 버튼 | 안에 든 설정이 있는 화면을 엽니다. 예를 들어 목표 선택 아래의 하드 대상입니다. |
| 항목 목록 | "모니터 (3), 버튼" | [항목 목록](#항목-목록)을 보십시오. |
| 그 밖의 것 | 일반 텍스트로 "이름, 값" | 읽기 전용입니다. |

### 소리 고르기

알림 소리 출력의 소리 설정과 비컨의 비컨 소리 설정은 오디오 파일 탐색기를 엽니다.

1. 소리에서 Enter를 누릅니다. 초점이 폴더 목록에 놓입니다.
2. Sound 폴더로 들어간 뒤, WowVision에 들어 있는 소리를 사용하려면 WowVision 폴더로, 다른 애드온이 등록한 소리를 사용하려면 LibSharedMedia 폴더로 들어갑니다. WowVision 폴더 안에는 alerts, errors, notes, falling 폴더가 있습니다.
3. 파일로 이동하면 그 파일이 재생되므로 고르기 전에 들어 볼 수 있습니다. 다음 파일로 이동하면 앞의 소리가 멈춥니다.
4. 원하는 파일에서 Enter를 누릅니다. WowVision이 설정으로 돌아가 새 값을 읽습니다.

Escape를 누르면 아무것도 고르지 않고 상위 폴더로 돌아갑니다. 탐색기 맨 위에는 Voice 폴더와 Beacon 폴더도 있는데, 다른 종류의 출력에 사용하는 파일이 들어 있습니다.

비컨 선택 목록도 같은 방식으로 작동하지만 비컨 소리(Notification, Probe (Deep), Probe (Mid), Steel Gong, Beacon 6) 중 하나를 고르며, 각 비컨 소리로 이동하면 그 소리가 미리 재생됩니다.

### 주문 고르기

모니터 규칙과 다른 일부 기능에는 주문 설정이 있습니다.

1. 주문에서 Enter를 누릅니다. 맨 위에 주문 이름이 있고 그 아래에 목록이 있는 화면이 열립니다.
2. 이름이나 ID를 아는 주문이면 주문 이름에서 Enter를 누르고 이름이나 숫자를 입력합니다. Enter로 입력한 내용을 확정합니다. 게임에 없는 주문이면 "찾을 수 없음"이 들리며 다시 시도할 수 있습니다.
3. 이름이나 ID를 모르면 아래 목록에서 고릅니다. 이 목록에는 WowVision이 이 캐릭터에서 본 주문(내가 시전했거나 오라로 나타난 주문)이 이름순으로 있으며, 각각 "이름 (ID)"로 읽습니다. Enter를 누르면 고릅니다.
4. 고르고 나면 WowVision이 설정으로 돌아가 "이름 (ID)"를 읽습니다.

### 템플릿 편집하기

버퍼 항목은 템플릿으로 텍스트를 읽는 방식을 정합니다. 예를 들면 "{percent}% ({current} [of] {maximum})"입니다. 템플릿 설정에는 다음이 있습니다.

- 템플릿에서 Enter를 누르면 그 종류의 대상에 사용할 수 있는 템플릿 목록이 열립니다. 원하는 템플릿에서 Enter를 누르면 그 템플릿을 사용합니다. 기본은 표준 문구입니다.
- 템플릿 목록에서 사용자 설정을 고르면 형식을 직접 입력할 수 있습니다. WowVision이 "형식"이라고 읽고 입력 상자를 엽니다. 아무것도 입력하지 않고 Enter를 누르면 기본으로 돌아갑니다.

직접 만드는 형식에서 값을 넣으려면 값 이름을 중괄호로 감싸 씁니다. 예를 들면 {percent}입니다. 낱말을 대괄호로 감싸면 게임 언어로 번역된 낱말이 들어갑니다. 예를 들어 [of]는 영어 게임에서 "of"로 읽습니다. 형식의 고정 텍스트에 있는 빗금은 앞뒤에 공백을 두고 읽습니다. 중괄호나 대괄호를 글자 그대로 쓰려면 {{ 또는 [[를 입력합니다. 사용할 수 있는 값은 대상에 따라 다르며, [버퍼](../information/buffers.md)에 대상별로 나와 있습니다.

### 항목 목록

버퍼, 버퍼 그룹, 모니터, 규칙은 추가하고 제거할 수 있는 항목 목록입니다. 이런 목록의 설정은 이름과 개수로 읽습니다. 예: "모니터 (3)".

1. Enter를 누르면 목록이 열립니다. 이미 있는 항목은 각각 버튼입니다.
2. 항목에서 Enter를 누르면 편집기가 열립니다. 항목의 설정이 있고, 맨 아래에는 확인 없이 삭제하는 제거 버튼이 있습니다.
3. 목록 끝의 추가를 누르면 종류 선택이 열립니다. 종류를 고르면 "신규"와 종류 이름으로 된 새 항목이 만들어지고 그 편집기가 바로 열립니다.
4. 항목에서 Shift+F10을 누르면 상황별 메뉴에 범위가 나옵니다. 아래 범위 변경하기를 보십시오.

어떤 설정에는 단순한 값 목록(예: 숫자 목록)이 들어 있습니다. 이 설정은 "이름 (개수)"로 읽으며, 값마다 한 줄씩 있는 화면을 엽니다. 각 줄에는 값 자체의 컨트롤과 그 뒤의 제거 버튼이 있고, 끝에 추가가 있습니다.

## 캐릭터별 설정과 계정 전체 설정

WowVision은 설정 저장소를 두 개 둡니다.

- 계정 저장소. 계정의 모든 캐릭터가 함께 씁니다.
- 캐릭터 저장소. 현재 캐릭터만 사용합니다.

대부분의 설정은 처음에 계정 전체 설정이므로, 한 캐릭터에서 정한 음성이나 알림 소리가 모든 캐릭터에 적용됩니다. 계정 저장소가 도입된 뒤 처음 로그인한 캐릭터의 설정이 계정 저장소에 복사되었습니다. 그 캐릭터도 자기 설정 사본을 그대로 가지고 있습니다. 그 뒤에 로그인하는 캐릭터는 계정 저장소에 있는 설정을 그대로 사용합니다.

범위를 어떻게 고르든 모듈 사용 여부는 항상 캐릭터별로 저장됩니다. 오류 모듈의 오류별 필터는 그 반대로, 항상 계정의 모든 캐릭터가 함께 쓰므로 한 캐릭터에서 음소거한 오류는 모든 캐릭터에서 음소거된 채로 있습니다. 음성 모듈의 게임 소리 체크 상자 두 개는 게임 자체의 설정이라 WowVision이 전혀 저장하지 않습니다.

### 범위 변경하기

저장되는 설정에서 Shift+F10을 누르면 상황별 메뉴가 열리고, 그 안에 범위가 있습니다. Enter를 눌러 엽니다. 라디오 항목이 두 개 있습니다. 전역, 그리고 캐릭터 이름입니다. 체크된 항목이 이 설정의 저장 위치입니다.

- 전역을 고르면 이 설정이 계정 저장소를 따르게 되어, 계정에 저장된 값이 이 설정에 적용됩니다. 계정에 아직 값이 없으면 이 캐릭터의 값이 계정의 값이 됩니다.
- 캐릭터 이름을 고르면 현재 값을 복사한 이 캐릭터만의 사본이 생깁니다. 그 뒤로는 다른 캐릭터에 영향을 주지 않고 값을 변경할 수 있습니다.

범위를 전환할 때 아무것도 삭제되지 않으므로 나중에 다시 변경해도 안전합니다.

같은 범위 항목은 다른 곳에도 나옵니다.

- 메뉴의 모듈 버튼에서 범위를 전환하면 그 모듈의 모든 설정과 알림의 범위가 한 번에 전환됩니다. 버퍼와 모니터에서는 모든 그룹이나 모니터의 범위도 함께 전환됩니다.
- 알림 버튼에서는 그 알림을 모든 출력과 함께 옮깁니다.
- 인터페이스 메뉴의 단축키 버튼에서는 모든 단축키를 한 번에 옮깁니다.
- 버퍼 그룹 목록이나 모니터 목록의 항목 하나에서는 그 항목만 옮깁니다.

모듈의 설정이 두 저장소에 나뉘어 있으면 전역도 캐릭터 이름도 체크되지 않습니다.

예: 부캐릭터에서만 음성 속도를 더 빠르게 하려는 경우입니다.

1. Shift+F1로 메뉴를 열고, Down으로 음성까지 간 뒤 Enter를 누릅니다.
2. Down으로 음성 속도까지 간 뒤 Shift+F10을 누릅니다.
3. Down으로 범위까지 가서 Enter, Down으로 캐릭터 이름까지 가서 Enter를 누릅니다.
4. 상황별 메뉴가 닫히고 음성 속도로 돌아옵니다. 속도를 변경하십시오. 본캐릭터의 속도는 그대로입니다.

## 설정이 저장되는 때

게임은 설정을 변경하는 순간이 아니라 로그아웃하거나 UI를 재시작하거나 게임을 끝낼 때 WowVision 설정을 디스크에 씁니다. 게임이 비정상 종료되면 현재 세션의 변경 사항을 잃을 수 있습니다. 중요한 설정을 변경하고 있다면 마지막에 /reload를 입력하십시오.

세션 사이에 설정이 사라지는 것 같으면 /wv dbcheck를 입력하십시오. 이 명령은 저장된 설정을 어떻게 불러왔는지 출력하므로 버그 신고에 유용합니다. [문제 해결](../getting-started/troubleshooting.md)을 보십시오.

## 초기화

메뉴에는 초기화 버튼이 없습니다. 설정 하나를 되돌리려면 이 설명서에 나온 기본값으로 설정하십시오(설정마다 기본값을 함께 적어 두었습니다). 완전히 새로 시작하려면 [문제 해결](../getting-started/troubleshooting.md)을 보십시오.
