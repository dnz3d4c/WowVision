# 단축키 목록

이 페이지는 WowVision의 모든 단축키와 기본 키를 나열합니다. 어느 것이든 단축키 화면에서 변경할 수 있습니다. WowVision 메뉴(Shift+F1)를 열고 인터페이스로 가서 단축키를 고르십시오. 단축키 화면을 쓰는 법은 [단축키](../basics/keybindings.md)에서 설명합니다.

"지정 안 됨"은 동작은 있지만 직접 키를 정해 주기 전까지는 지정된 키가 없다는 뜻입니다.

## 두 종류의 키

- 창 키는 WowVision 창(가방, 상인, WowVision 메뉴 등)이 열려 있을 때만 동작합니다. 창이 열려 있지 않으면 같은 키는 게임에서 그 키에 지정해 둔 동작을 합니다. 화살표 키, Tab, Enter, Backspace, Escape, Space, Home, End, Page Up, Page Down과 상황별 메뉴 키가 창 키입니다. 게임 창에서는 Escape를 게임이 그대로 처리해 게임 창을 닫습니다. WowVision 자체 화면에서는 WowVision이 Escape를 처리합니다([인터페이스 사용하기](../basics/interface.md) 참고).
- 전역 키는 창이 있든 없든 언제나 동작합니다. 버퍼, 길 안내, 목표 선택, 주사위 키, 커서에 든 아이템 파괴, WowVision 창을 여는 키가 여기에 속합니다.

전투 중에는 WowVision이 창 키를 게임에 돌려줍니다([전투](../world/combat.md) 참고). 전역 키는 계속 동작합니다.

## 창 안에서 이동하기

| 동작 | 기본 키 | 참고 |
|---|---|---|
| 위 | Up Arrow | 목록이나 열의 이전 요소 |
| 아래 | Down Arrow | 다음 요소 |
| 왼쪽 | Left Arrow | 왼쪽 요소, 또는 슬라이더나 선택 항목의 이전 값 |
| 오른쪽 | Right Arrow | 오른쪽 요소, 또는 다음 값 |
| 다음 | Tab | 다음 탭 위치. 목록이나 버튼 줄처럼 창의 다음 구역 |
| 이전 | Shift+Tab | 이전 탭 위치 |
| 처음으로 이동 | Home | 첫 요소 |
| 끝으로 이동 | End | 마지막 요소 |
| 위로 스크롤 | Page Up | 긴 목록을 한 페이지 위로 스크롤 |
| 아래로 스크롤 | Page Down | 긴 목록을 한 페이지 아래로 스크롤 |
| 다음 창 | Ctrl+Tab | 열려 있는 다음 창으로 전환 |
| 이전 창 | Ctrl+Shift+Tab | 열려 있는 이전 창으로 전환 |
| 닫기 | Escape | 한 단계 뒤로 가거나 WowVision 자체 화면과 메뉴를 닫습니다. 게임 창에서는 게임 자체의 Escape가 창을 닫습니다 |

## 요소 조작하기

| 동작 | 기본 키 | 참고 |
|---|---|---|
| 왼쪽 클릭 | Enter | 초점이 있는 요소를 실행합니다. 조합 키와 함께 쓸 수 있습니다. Shift+Enter는 Shift 클릭, Ctrl+Enter는 Ctrl 클릭 같은 식입니다 |
| 오른쪽 클릭 | Backspace | 오른쪽 클릭. 조합 키와 함께 쓸 수도 있습니다(Ctrl+Backspace 등) |
| 끌기 | \\ 또는 Ctrl+D | 초점이 있는 아이템, 주문, 행동 단축바 칸을 커서에 집어 듭니다 |
| 툴팁 읽기 | Space | 초점이 있는 요소의 툴팁 전체를 읽습니다 |
| 상황별 메뉴 | Shift+F10 | 초점이 있는 요소에 상황별 메뉴가 있으면 엽니다 |
| 커서에 든 아이템 파괴 | Delete 또는 Alt+Ctrl+\\ | 커서에 있는 것을 비우거나 파괴합니다(실제 아이템이면 먼저 묻습니다). 커서가 비어 있으면 아무 일도 하지 않습니다 |

## 길 안내와 경로

| 동작 | 기본 키 | 참고 |
|---|---|---|
| 경유지 쪽으로 돌아서기 | I | 경로의 현재 경유지를 바라봅니다 |
| 다음 경유지 | Ctrl+W | 다음 경유지로 건너뜁니다. 남은 경유지 수를 "12 남음"처럼 들려줍니다 |
| 이전 경유지 | Ctrl+S | 이전 경유지로 돌아갑니다. 남은 경유지 수도 같은 방식으로 들려줍니다 |
| 여기서 경로 다시 시작 | Ctrl+Shift+N | 마지막 목적지까지의 경로를 지금 서 있는 곳에서 출발하도록 다시 짭니다. 아직 목적지를 고르지 않았으면 "다시 시작할 경로 없음"이 들립니다 |
| 경로 거꾸로 돌아가기 | Ctrl+Shift+R | 진행 중인 경로의 방향을 뒤집어, 지금 비컨이 이끄는 경유지부터 경로를 시작한 곳까지 이어지게 합니다 |
| 길 안내 취소 | Shift+F12 | 진행 중인 경로나 비컨을 멈춥니다 |
| 도착 거리 전환 | Alt+P | 얼마나 가까이 가야 경유지에 도착한 것으로 칠지 변경합니다 |
| 거리 알림 | 지정 안 됨 | 경유지까지의 거리를 말합니다. 기본 상태에서는 Alt Gr(또는 Ctrl+Alt)이 같은 일을 합니다 |
| 대상까지 경로 안내 | 지정 안 됨 | 현재 대상까지 경로를 시작합니다 |
| 같은 이름의 가장 가까운 미방문 지점까지 경로 안내 | 지정 안 됨 | 아직 가 보지 않은 같은 이름의 가장 가까운 장소로 경로를 안내합니다 |
| 같은 이름의 가장 가까운 미방문 지점까지 직선 안내 | 지정 안 됨 | 위와 같지만 경로 대신 직선 비컨으로 안내합니다 |
| WowNav 경로 상태 | 지정 안 됨 | (WoW: Forever) WowNav 경로의 상태를 말합니다 |
| 막힌 지점을 피하는 새 WowNav 경로 | 지정 안 됨 | (WoW: Forever) 내가 막혀 있는 지점을 피하는 새 경로를 짭니다 |

Alt Gr은 지정된 단축키가 아닙니다. WowVision이 Alt Gr 키를 직접 감지하며, 입력창에 글을 쓰는 동안에는 아무 말도 하지 않습니다. 지도 모듈의 Alt Gr로 거리 알림 설정에서 이 기능을 끌 수 있습니다. [길 안내와 경로](../world/navigation.md)와 [WowNav](../world/wownav.md)를 참고하십시오.

## 특정 창 안의 키

이 키들은 별도의 단축키가 아닙니다. 앞부분에서 설명한 창 키가 특정 창에서 그 창에 맞는 일을 하는 것입니다. 키 지정을 변경하면 모든 곳에서 키가 변경됩니다.

| 위치 | 키 | 하는 일 |
|---|---|---|
| 대화 창(Shift+F3), 메시지 목록 | Up, Down, Home, End | 메시지 사이를 이동합니다 |
| 대화 창, 메시지 목록 | Left, Right | 이전 또는 다음 대화 탭으로 전환합니다 |
| 대화 창, 메시지 목록 | Ctrl+Left, Ctrl+Right | 메시지의 클릭 가능한 부분(채널, 보낸 사람, 링크) 사이를 이동합니다 |
| 대화 창, 메시지 목록 | Enter, Backspace, Shift+Enter, Space | 선택한 부분을 왼쪽 클릭, 오른쪽 클릭, Shift 클릭하거나 툴팁을 읽습니다 |
| 길 안내 창(F10), 목적지 목록 | Up, Down, Home, End | 긴 목적지 목록을 훑습니다. Enter를 누르면 경로를 시작합니다 |
| 길 안내 창, 검색 상자 | Enter, Tab, Escape | Enter와 Tab은 입력한 내용을 검색에 적용하고, Escape는 검색을 변경하지 않고 상자를 닫습니다 |
| 스캐너(F9) | Right, Left, Enter | Right는 그룹을 열거나 안으로 들어가고, Left는 그룹을 닫거나 밖으로 나오며, Enter는 선택한 항목까지 길을 안내합니다 |
| 스캐너 | Backspace | 퀘스트 목표처럼 항목에 딸린 추가 글을 엽니다 |
| 스캐너 | Tab | 목록과 새로고침 버튼 사이를 오갑니다 |
| 행동 단축바(Shift+F4), 가방과 그 밖의 칸 창 | \\ 또는 Ctrl+D, 다음에 Delete | 칸을 커서에 집어 든 다음 비우거나 파괴합니다 |
| 친구, 차단, 누구, 길드 목록(Classic Era, TBC, Mists) | Page Up, Page Down | 목록을 한 페이지씩 스크롤합니다. 여기서는 Home과 End가 아무 일도 하지 않습니다 |
| WowVision 메뉴, 상황별 메뉴, 드롭다운 메뉴 | 글자 | 그 글자로 시작하는 다음 항목으로 건너뜁니다. 메뉴에서 글자로 이동 설정으로 끌 수 있습니다 |
| 입력창 | Enter, Tab, Escape | Enter는 게임 입력창에 커서를 넣고 WowVision 입력창에서는 입력을 확정합니다. Tab은 다음으로 넘어가고, Escape는 WowVision 입력창을 취소합니다 |

[대화](../windows/chat.md), [길 안내와 경로](../world/navigation.md), [스캐너](../world/scanner.md), [행동 단축바](../windows/action-bars.md), [인터페이스 사용하기](../basics/interface.md)를 참고하십시오.

## Sku가 설치되어 있을 때

일부 WowVision 단축키는 예전부터 있던 접근성 애드온 Sku의 키와 같은 일을 합니다. Sku가 로드되어 있는 동안 WowVision은 이 단축키를 아예 활성화하지 않고 키를 Sku에 맡깁니다.

- 툴팁 줄 키 네 개(Shift+Up, Shift+Down, Shift+Left, Shift+Right)
- 소프트 대상 지정 전환 키(Shift+I, Shift+P, Shift+O)
- 주시 대상 선택 1부터 주시 대상 선택 5까지(그리고 `/focus1`부터 `/focus5`까지의 명령)

WowVision은 일부 창과 `/pquit`, `/dquit` 명령도 Sku에 맡깁니다. 이 판단은 로그인할 때 한 번만 하므로 Sku를 켜거나 끈 것을 반영하려면 UI를 재시작해야 합니다. 목록에 없는 키, 창, 명령은 계속 WowVision이 처리합니다. 두 애드온을 함께 쓰는 방법은 [설치](../getting-started/sku.md)에 더 자세히 나와 있습니다.
