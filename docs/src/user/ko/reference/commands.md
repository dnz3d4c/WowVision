# 슬래시 명령

WowVision은 게임의 대화 입력창에 입력하는 슬래시 명령을 추가합니다. 이 페이지는 그 명령을 모두 나열합니다. 명령마다 하는 일, 입력하는 법, 사용 예, 그리고 어느 게임 버전에 있는지를 적습니다.

## 명령이 작동하는 방식

두 종류가 있습니다.

- /wv 명령은 /wv로 시작하고 그 뒤에 낱말 하나가 붙습니다. 예: /wv speech 1 9 100. 낱말은 대소문자를 구분하지 않습니다. /wv만 입력하면 WowVision 메뉴가 열리고, /wv 뒤에 명령이 아닌 낱말을 붙여도 마찬가지입니다.
- 전역 명령은 /wv 없이 자기 이름으로 바로 입력하는 슬래시 명령입니다. 예: /beacon, /pquit.

대화 입력창(Enter나 게임의 대화 키로 엽니다)에 명령을 입력하고 Enter를 누릅니다. 명령의 결과는 여러 방식으로 나옵니다.

- WowVision이 말로 읽습니다.
- 대화 창에 출력됩니다. 출력된 줄을 읽으려면 Shift+F3으로 WowVision 대화 창을 엽니다.
- 텍스트가 모두 선택된 상태로 창에 표시됩니다. Ctrl+C를 누르면 텍스트를 복사할 수 있고(예: 버그 신고에 붙여 넣기), Escape를 누르면 창이 닫힙니다.

명령 설명에 따로 적혀 있지 않으면 그 명령은 모든 게임 버전, 곧 Classic Era, 불타는 성전(TBC), 판다리아의 안개(Mists), Retail, WoW: Forever에 있습니다.

## 일상 명령

### /wv

WowVision 메뉴를 엽니다. Shift+F1과 같습니다. [WowVision 메뉴와 설정](../basics/menu-and-settings.md)을 참고하십시오.

### /wv speech

음성 종류, 음성 속도, 음성 음량을 한 번에 설정합니다. 로그인하거나 /reload한 뒤에 누르는 매크로에 넣어 두면 편리합니다.

문법: /wv speech voice rate volume

| 인수 | 뜻 |
|---|---|
| voice | 음성 번호입니다. 첫 번째 음성이 0번입니다. |
| rate | 음성 속도로, -10부터 10까지입니다. 범위를 벗어난 값은 이 범위 안으로 맞춰집니다. 생략할 수 있습니다. |
| volume | 음량으로, 0부터 100까지입니다. 생략할 수 있습니다. |

속도와 음량을 생략하면 현재 값을 유지합니다.

뒤에 아무것도 붙이지 않으면 /wv speech는 현재 음성, 속도, 음량을 출력하고, "Voice 0: Microsoft David Desktop"처럼 설치된 모든 음성을 번호와 함께 나열합니다.

예: /wv speech 1 9 100은 음성 1, 속도 9, 음량 100을 고르고 "Speech voice ... rate 9, volume 100"이라고 말합니다. 없는 음성 번호를 입력하면 "No voice with id 5. Type /wv speech to list the voices"를 출력합니다. 숫자가 아닌 것을 입력하면 "Usage: /wv speech voiceID rate volume, for example /wv speech 1 9 100"을 출력합니다.

버전: 전체. [음성](../basics/speech.md)을 참고하십시오.

### /wv bind

단축키 창을 바로 엽니다. WowVision 메뉴(Shift+F1)에서 인터페이스, 단축키 순서로 들어가는 화면과 같습니다. Escape로 닫습니다. [단축키](../basics/keybindings.md)를 참고하십시오.

### /wv close

열린 WowVision 창을 모두 한 번에 닫습니다. 창이 멈춘 것 같을 때 사용합니다. 게임 자체의 창은 닫지 않습니다. 버전: 전체.

### /wv version

설치된 WowVision 버전을 대화 창에 출력합니다. 예: V0.9.0, 또는 베타 시험판이면 "beta". 버전: 전체.

### /wv accept

표시된 파티 초대를 수락하고 "파티 초대 수락함"이라고 말합니다. WowVision이 초대 팝업을 열 수 없는 전투 중에도 작동합니다. 초대가 없으면 "파티 초대 없음"이라고 말합니다. 역할을 묻는 초대를 수락하려면 먼저 역할을 선택해 두어야 합니다. 선택하지 않았으면 "먼저 역할을 선택하십시오"라고 말합니다. 파티 초대 수락 단축키도 같은 일을 하며, 기본으로는 키가 지정되어 있지 않습니다. 버전: 전체. [파티 찾기](../windows/group-finder.md)를 참고하십시오.

### /beacon

직선 비컨을 설정하거나, 이름으로 지정한 장소까지 경로를 안내하거나, 현재 위치를 알려 줍니다. 그러면 걸어가는 동안 비컨이 소리를 내고 말합니다. 길 안내 창이 사용하는 것과 같은 비컨입니다. [길 안내](../world/navigation.md)를 참고하십시오.

| 입력 | 하는 일 |
|---|---|
| /beacon | 지역 지도에서의 현재 위치(예: "50.5 30.4")를 말하고, 비컨이 켜져 있으면 비컨까지의 거리와 돌아야 할 각도도 말합니다 |
| /beacon x y | 현재 지역 지도의 좌표에 비컨을 설정합니다. 퀘스트 공략에 나오는 50.5 30.4 같은 백분율 좌표입니다 |
| /beacon world x y | 가공하지 않은 월드 좌표에 비컨을 설정합니다 |
| /beacon to name | 지도 데이터를 사용해, 이름에 입력한 텍스트가 포함된 가장 가까운 알려진 장소까지 경로를 안내합니다. "mailbox"처럼 이름의 일부를 입력합니다. |
| /beacon stop | 비컨이나 경로 안내를 멈춥니다. Shift+F12와 같습니다 |

예: /beacon 50.5 30.4는 "비컨 설정됨 245 야드"라고 말하고 그 지점까지 직선 비컨을 시작합니다. 길 안내 창은 열지 않습니다. /beacon to innkeeper는 찾은 장소를 말하고 그곳까지 경로 안내를 시작하거나, "경로 없음 innkeeper"라고 말합니다. 숫자를 하나만 넣은 /beacon 12는 "Usage beacon x y"라고 말합니다.

버전: 전체. /beacon to는 현재 대륙의 지도 데이터가 있어야 합니다. [길 안내](../world/navigation.md)를 참고하십시오.

### /focus1부터 /focus5까지

WoW는 주시 대상을 하나만 지원합니다. WowVision은 가상 주시 대상 다섯 개를 추가합니다. 이 다섯 대상은 주시 대상 선택 1부터 주시 대상 선택 5까지의 단축키(기본값은 지정 안 됨)로 선택할 수 있습니다.

문법: /focus1(또는 2부터 5), 뒤에 유닛을 붙일 수 있습니다.

- 뒤에 아무것도 붙이지 않은 /focus1은 현재 대상을 주시 대상 1로 설정합니다. 대상이 없으면 이전 주시 대상을 유지하고 "대상 없음. /focus1 <이름>을 사용하거나 유닛을 대상으로 지정하십시오."를 출력합니다(입력 형식은 `/focus1 <name>`).
- /focus1 party1은 주시 대상 1을 입력한 유닛이나 이름으로 설정합니다. 게임의 /target 명령이 인식하는 것이면 무엇이든 됩니다.

대상이 있을 때 WowVision은 대상의 이름을 기억하므로, 이름이 같은 두 생물은 구별할 수 없습니다. "주시 대상 1에 Name 설정."을 출력합니다. 전투 중에는 작동하지 않고 "전투 중에는 가상 주시 대상 설정 불가."를 출력합니다. 버전: 전체. Sku를 불러온 상태이면 이 명령은 등록되지 않습니다. [목표 선택](../world/targeting.md)을 참고하십시오.

### /pquit

현재 파티를 떠납니다. 버전: 전체. Sku를 불러온 상태이면 등록되지 않습니다.

### /dquit

던전 파티나 던전 찾기 파티를 떠나고, 전장이나 투기장에서는 전장을 떠납니다. 인스턴스 밖이면서 던전 찾기 파티에도 속해 있지 않으면 아무 일도 하지 않습니다. 버전: 전체. Sku를 불러온 상태이면 등록되지 않습니다.

### /enableaddon과 /disableaddon

애드온을 켜거나 끄고 바로 인터페이스를 다시 불러옵니다.

문법: /enableaddon name과 /disableaddon name. 이름은 애드온의 폴더 이름이며 대소문자를 구분하지 않습니다. 이름을 붙이지 않고 입력하면 "Syntax: `/enableaddon <name>`"을 출력합니다. 그 이름의 애드온이 없어도 인터페이스는 다시 불러와집니다.

예: /disableaddon sku. sku라는 이름은 특별합니다. Sku 애드온과 그 오디오 데이터 애드온, 비컨 애드온을 함께 끄거나 켜서, 절반만 불러와진 상태가 남지 않게 합니다. /enableaddon sku는 이 애드온을 모두 다시 켭니다.

/disableaddon wowvision은 사용하지 마십시오. WowVision 자체가 꺼집니다. BlindSlash 애드온을 불러온 상태이면 이 명령들은 등록되지 않습니다. 버전: 전체.

## 유틸리티 명령

### /wv soft

소프트 대상 지정 모드와 게임에 설정된 모든 소프트 대상 지정 값을 한 줄씩 읽습니다. 먼저 고정 모드(하드 대상이 있을 때 소프트 대상 지정)를 읽고, 이어서 "SoftTargetEnemy 3 (기본 0)" 같은 줄을 읽습니다. 전투가 끝나기를 기다리는 값에는 "전투 후" 표시와 함께 그때 적용될 값이 나오고, 게임 버전에 없는 값은 "사용 불가"로 표시됩니다. 이 줄들은 대화 창에 출력되고 말로도 읽힙니다. [목표 선택](../world/targeting.md)을 참고하십시오.

### /wv targetinfo

현재 대상에 대해 대상 알림이 말할 수 있는 모든 것을 나열합니다. 먼저 유닛의 종류와, 지금 전투 중과 비전투 가운데 어느 쪽이 적용되는지를 보여 줍니다. 다음으로 그 종류의 항목을 모두 보여 주며, 항목마다 이 대상에 대해 무엇을 말하는지, 체크 상자가 켜져 있는지, 게임 버전에서 제공하는지가 함께 나옵니다. 이어서 대상 툴팁의 줄들을 보여 주고, 마지막으로 알림을 실제로 들리는 그대로 보여 줍니다. 목록은 결과 창에 열리고 대화 창에도 출력되며, 알림은 말로 읽힙니다. 게임이 그 순간 숨기는 항목은 <secret>으로 표시됩니다. 버그 신고에 도움이 됩니다. [목표 선택](../world/targeting.md#알림이-말하는-내용-이름)을 참고하십시오.

### /wv mscan

미니맵 스캐너입니다. 단독으로 입력하면 바로 스캔합니다. Ctrl+Shift+F와 같습니다. [미니맵](../world/minimap.md)을 참고하십시오.

| 입력 | 하는 일 |
|---|---|
| /wv mscan | 지금 미니맵을 스캔합니다 |
| /wv mscan list | 이번 세션에 스캐너가 발견한 항목을 모두 보여 줍니다 |
| /wv mscan clear | 발견한 항목과 걷기 기억을 모두 지우고 "발견 항목 지움"이라고 말합니다 |
| /wv mscan log | 마지막 스캔과 걷기 확인이 어떻게 진행되었는지 보여 줍니다(버그 신고용) |
| /wv mscan walk | 걷기 확인이 기억하는 내용을 보여 줍니다 |
| /wv mscan raw | 미니맵을 한 번 읽은 내용을 해석하지 않고 그대로 보여 줍니다. 이 내용은 /reload 뒤에 보낼 수 있도록 저장도 됩니다(버그 신고용) |
| /wv mscan sku | 지금 서 있는 곳에서 스캐너가 미니맵을 검색하는 동작을 측정합니다(버그 신고용) |

버전: 명령은 모든 버전에 있지만, 스캔하려면 미니맵을 읽을 수 있는 게임 버전이어야 합니다. 그렇지 않으면 "이 클라이언트에서는 미니맵 스캐너 사용 불가"가 들립니다.

### /wv quests

퀘스트 데이터 점검입니다. WowVision이 퀘스트에 대해 아는 내용을 대화 창에 출력합니다. 퀘스트 데이터 원본이 있어야 합니다. Questie가 설치되어 있으면 Questie를, 없으면 게임 자체의 퀘스트 데이터를 사용합니다. 원본이 없으면 "퀘스트 데이터 원본 없음"이라고 말하고, Questie가 시작되는 중이면 "Questie 불러오는 중"이라고 말합니다.

| 입력 | 하는 일 |
|---|---|
| /wv quests near(또는 그냥 /wv quests) | 근처 퀘스트를 최대 10개까지 레벨, 퀘스트 NPC, 거리와 함께 나열합니다 |
| /wv quests log | 진행 중인 퀘스트를 목표와 함께 나열합니다 |
| /wv quests go questId [start, objectives 또는 finish] | 그 퀘스트 단계의 대상을 나열합니다(기본값 objectives) |
| /wv quests raw [mapId] | 퀘스트 데이터 원본의 원시 데이터를 덤프합니다(원본에 원시 데이터가 있을 때) |
| /wv quests probe | 게임이 제공하는 모든 퀘스트·지도 지점 원본을 하나의 보고서로 만들어 창에 보여 주고 요약을 말합니다. WowVisionDump 저장 변수에도 저장합니다. 퀘스트 데이터 원본이 없어도 작동합니다. |

버전: 전체. [퀘스트](../world/quests.md)를 참고하십시오.

## 진단 명령

이 명령들은 문제를 찾고 신고하는 데 사용합니다. 각 명령을 언제 사용하는지는 [문제 해결](../getting-started/troubleshooting.md)에 나옵니다.

### /wv errors

이번 세션의 Lua 오류를 보여 줍니다. 가장 최근 오류를 말하고, 전체 목록과 스택 추적을 담은 창을 엽니다. BugGrabber나 BugSack 애드온이 설치되어 있으면 그 목록을 먼저 읽습니다.

| 입력 | 하는 일 |
|---|---|
| /wv errors | 이번 세션의 오류 |
| /wv errors all | BugGrabber가 보관한 이전 오류까지 |
| /wv errors clear | WowVision의 목록을 비우고, BugGrabber가 설치되어 있으면 그 목록도 비웁니다 |

오류가 없으면 "No Lua errors recorded"를 출력합니다. WowVision은 자체 목록의 최근 20개를 /reload 뒤에도 보관합니다.

### /wv taint

taint(애드온 코드에서 보호된 동작을 시도한 것) 때문에 게임이 차단한 호출을 보여 줍니다. 시각, 이벤트, 애드온, 함수, 그리고 그때 인터페이스에서 초점이 있던 요소가 함께 나옵니다. WowVision은 최근 30개를 보관합니다. 기록이 없으면 "No blocked calls recorded"라고 말합니다.

/wv taint clear는 목록을 비웁니다. /reload를 입력하면 이 기록이 WowVisionDump 저장 변수에 저장됩니다. WowVision 자체가 차단되면 "Blocked: ..."도 들립니다.

### /wv dbcheck

저장된 설정에 대한 짧은 보고서를 대화 창에 출력합니다. 내용을 이해할 필요는 없습니다. 설정이 사라졌을 때 버그 신고에 첨부하십시오. [설정이 사라짐](../getting-started/troubleshooting.md#설정이-사라짐)을 참고하십시오.

### /wv turnlog

경유지 쪽으로 돌아서기 기능으로 최근에 방향을 돌린 기록을 한 줄에 하나씩, 각도 오차와 함께 창과 대화 창에 나열합니다. "12 turns, mean error 2.4 degrees" 같은 요약을 말하거나, "No turns yet"이라고 말합니다.

### /wv unitturnlog

"대상 쪽으로 돌아서기"와 "주시 대상 쪽으로 돌아서기" 단축키를 누른 최근 기록을 최대 40개까지 창과 대화 창에 나열합니다. 한 줄에 기록 하나씩, 누른 시각, 유닛, 눌렀을 때 찾은 결과, 캐릭터가 돌아선 각도가 나옵니다. 기록이 몇 개인지 말합니다. 이 기록은 설정과 함께 저장되므로 인터페이스를 다시 불러온 뒤에도 남아 있습니다.

### /wv keylog

키 기록을 켜거나 끄고, "WowVision key log on" 또는 "off"를 출력합니다. 켜져 있는 동안 대화 창에는 각 창이 탐색 키 입력을 처리하기 시작하는 시점, 처리하려고 기다리는 시점, 게임의 원래 기능으로 되돌리는 시점과 누르고 있는 키를 점검한 결과가 나옵니다. 캐릭터가 저절로 돌거나 달릴 때 사용합니다.

### /wv padlog

컨트롤러 기록을 새로 시작합니다. "WowVision pad log started afresh" 또는 "WowVision pad log: only with the gamepad interface on"을 출력합니다. 명령은 모든 게임 버전에 등록되지만, 게임패드 인터페이스가 켜져 있을 때만, 곧 Retail이나 WoW: Forever에서만 기록합니다. [컨트롤러](../controller.md)를 참고하십시오.

### /wv cdmlog

재사용 대기시간 관리자 오라 규칙이 본 내용을 보여 줍니다.

| 입력 | 하는 일 |
|---|---|
| /wv cdmlog | 규칙이 본 내용의 기록(가장 새로운 줄도 말합니다) |
| /wv cdmlog clear | 기록을 비웁니다 |
| /wv cdmlog spells | 재사용 대기시간 관리자의 추적 중인 강화 효과와 추적 중인 막대 항목을 나열합니다 |
| /wv cdmlog cooldowns | 핵심 능력과 보조 능력 항목을 나열합니다 |

버전: Retail, WoW: Forever. [모니터](../information/monitors.md)를 참고하십시오.

## WowVision이 사용하는 게임 명령

이 명령들은 WowVision이 아니라 게임의 명령입니다.

- /reload는 인터페이스를 다시 불러오고 설정을 디스크에 저장합니다.
- /tts playline과 /tts playactivity는 음성 합성 전후에 나는 게임 소리를 켜고 끕니다. WowVision은 둘 다 음성 모듈의 설정(대화 메시지 사이 소리, 대화창이 비활성일 때 활동 소리)으로 보여 줍니다.
- /cdm은 게임의 재사용 대기시간 관리자 설정을 엽니다. WowVision은 이 설정을 창으로 읽습니다(Retail, WoW: Forever).

## 개발자용, 버그 신고용

이 명령들은 WowVision을 만드는 사람들을 위한 것입니다. 보통은 사용할 일이 없지만, 개발자가 실행해 달라고 요청할 수 있습니다.

| 명령 | 하는 일 |
|---|---|
| /wv dev | 게임의 스크립트 입력줄에서 개발자용 도우미 함수 몇 개를 사용할 수 있게 합니다 |
| /wv tests [suite] [--verbose] | 내장 테스트를 실행하고 결과를 창에 보여 줍니다 |
| /wv gmenu | WowVision 메뉴를 엽니다(/wv와 같습니다) |
| /wv gsettings module | 모듈 하나의 설정 화면을 엽니다. 예: /wv gsettings speech |
| /wv gnode | 초점이 있는 요소의 구조를 덤프합니다 |
| /wv glive | 초점이 있는 요소의 실시간 감시 상태를 덤프합니다 |
| /wv gdump expression | Lua 식을 평가하고 결과를 설명합니다 |
| /wv gperf | 인터페이스 업데이트 루프를 120프레임 동안 측정해 최소, 평균, 최대 밀리초를 보고합니다 |
| /wv gdrop | 열린 드롭다운 메뉴를 덤프합니다 |
| /wv bigmenu [number] | 지정한 수만큼 항목이 있는 긴 스크롤 테스트 메뉴를 엽니다(생략하면 60개). 체크 상자, 라디오 버튼, 레벨 범위, 컨트롤 한 줄, 슬라이더가 들어 있으며, 고른 항목은 대화 창에 출력됩니다 |
| /wv bigmenu dump | 같은 테스트 메뉴를 열고, 1초 뒤에 /wv gdrop처럼 덤프합니다 |
| /wv cctest [unit] | 유닛(생략하면 현재 대상)이 군중 제어 상태인지 검사하고, 이어지는 프레임 동안 결과가 어떻게 변경되는지 출력합니다 |
| /wv cctest watch | 대상이 변경될 때마다 군중 제어 결과를 프레임별로 보여 주는 줄을 출력하는 점검을 켜거나 끕니다 |
| /wv gtooltip | 툴팁 판독기 상태를 덤프합니다 |
| /wv profile | 프로파일러입니다. 단독으로 입력하면 시작하고, report, reset, stop을 붙여 각 동작을 실행할 수 있습니다 |
| /wv testcd | 테스트용 재사용 대기 모니터를 만듭니다 |
| /wv dump waypoints 또는 /wv dump links | Sku의 경유지 데이터를 WowVisionDump 저장 변수에 기록합니다. Sku를 불러온 상태여야 하며, 그 뒤 /reload합니다 |
| /uiinsp | 누르는 모든 키의 이름을 출력하는 작은 키 검사기를 엽니다. Escape로 닫습니다 |

이 표의 모든 내용은 예고 없이 변경되거나 사라질 수 있습니다.
