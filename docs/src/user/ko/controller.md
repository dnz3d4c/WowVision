# 게임패드로 플레이하기

Retail과 WoW: Forever에서는 키보드와 함께 게임패드로도 WowVision을 쓸 수 있습니다. 둘은 동시에 작동하며, WowVision의 모든 단축키에 키와 함께 컨트롤러 버튼도 지정할 수 있습니다. 이 페이지에서는 게임패드를 켜는 방법, 각 버튼이 하는 일, 버튼을 바꾸는 방법을 설명합니다.

(Retail과 WoW: Forever. 게임패드 주 메뉴와 게임패드 단축바는 WoW: Forever에만 있습니다. 클래식 클라이언트에는 게임패드 인터페이스가 없습니다.)

## 켜기

게임 설정의 게임패드 항목에서 다음 두 가지를 모두 켭니다.

- 게임패드 사용 설정
- 게임패드 UI 사용 설정

그러면 WowVision이 자체 창과 월드에서 컨트롤러 입력에 반응합니다. 몇 가지는 게임패드 UI 사용 설정이 켜져 있을 때만 나타납니다. 단축키 창의 컨트롤러 버튼, 행동 단축바 창의 게임패드 단축바 네 개, 컨트롤러 기록이 그렇습니다.

## 조합 키: 어깨 버튼과 트리거

게임패드는 게임에 Shift, Ctrl, Alt를 보내지 않습니다. 그래서 WowVision이 누르고 있는 버튼을 직접 읽어 그 키처럼 다룹니다.

| 누르고 있는 버튼 | 같은 역할 |
|---|---|
| 왼쪽 어깨 | Alt |
| 왼쪽 트리거 | Shift |
| 오른쪽 트리거 | Ctrl |
| 양쪽 어깨 | 게임의 바로 가기 층(아래 참고) |

버튼 하나만 누르면 조합 키 역할을 하지 않습니다. 왼쪽 어깨만 누르면 그냥 왼쪽 어깨입니다. 그래서 키보드 키 대부분은 짝이 되는 컨트롤러 버튼을 쉽게 짐작할 수 있습니다. 키보드의 Ctrl+Tab(다음 창)은 오른쪽 트리거 + 오른쪽 어깨가 되고, 키보드의 Shift+Up(툴팁 이전 줄)은 왼쪽 트리거 + 방향 패드 위가 됩니다.

## WowVision 창에서

WowVision 창이 열려 있는 동안에는 WowVision이 방향 패드와 앞면 버튼을 맡습니다. 아래는 기본값입니다. 첫째 열의 이름은 단축키 창에 표시되는 단축키 이름입니다.

| 기능 | 컨트롤러 |
|---|---|
| 위, 아래, 왼쪽, 오른쪽 | 방향 패드 |
| 왼쪽 클릭(Enter) | A |
| 오른쪽 클릭(Backspace) | X |
| 닫기(Escape) | B. Escape를 게임이 맡는 곳에서는 B가 대신 게임 자체의 Escape를 실행합니다. 이것이 닫기 (컨트롤러) 단축키입니다. |
| 툴팁 읽기(Space) | Y |
| 이전(Shift+Tab) | 왼쪽 어깨 |
| 다음(Tab) | 오른쪽 어깨 |
| 이전 창, 다음 창 | 오른쪽 트리거 + 왼쪽 어깨, 오른쪽 트리거 + 오른쪽 어깨 |
| 처음으로 이동, 끝으로 이동 | 오른쪽 트리거 + 방향 패드 위, 오른쪽 트리거 + 방향 패드 아래 |
| 툴팁 이전 줄, 툴팁 다음 줄 | 왼쪽 트리거 + 방향 패드 위, 왼쪽 트리거 + 방향 패드 아래 |
| 툴팁 왼쪽 읽기, 툴팁 오른쪽 읽기 | 왼쪽 트리거 + 방향 패드 왼쪽, 왼쪽 트리거 + 방향 패드 오른쪽(현재 툴팁 줄의 왼쪽 글과 오른쪽 글) |
| 상황별 메뉴(Shift+F10) | 메뉴 버튼(Start 버튼). 게임패드 주 메뉴 휠이 열려 있는 동안에는 Start가 대신 휠을 닫습니다. |
| 끌기 | 왼쪽 스틱 누르기 |
| Shift 클릭(대화 링크) | 왼쪽 트리거 + A |
| 메시지의 이전 링크, 메시지의 다음 링크 | 오른쪽 트리거 + 방향 패드 왼쪽, 오른쪽 트리거 + 방향 패드 오른쪽(대화 줄의 각 부분) |

예: 메뉴를 열고 둘러본 뒤 닫기.

1. 양쪽 어깨를 누른 채 A를 누릅니다. WowVision 메뉴가 열립니다.
2. 방향 패드 아래를 눌러 항목 사이를 이동합니다. A를 누르면 항목이 열립니다.
3. B를 누르면 뒤로 갑니다. B를 한 번 더 누르면 메뉴가 닫힙니다.

## 월드에서

다음은 창이 열려 있지 않을 때를 포함해 언제나 작동하며, 전투 중에도 작동합니다.

| 기능 | 컨트롤러 |
|---|---|
| 경유지 쪽으로 돌아서기 | 오른쪽 스틱을 누릅니다. |
| 이전 버퍼 항목, 다음 버퍼 항목 | 오른쪽 스틱을 누른 채 방향 패드 위, 방향 패드 아래 |
| 이전 버퍼, 다음 버퍼 | 오른쪽 스틱을 누른 채 방향 패드 왼쪽, 방향 패드 오른쪽 |
| 이전 버퍼 그룹, 다음 버퍼 그룹 | 오른쪽 스틱과 왼쪽 트리거를 누른 채 방향 패드 왼쪽, 방향 패드 오른쪽 |

오른쪽 스틱 누르기는 두 가지 일을 합니다. 누르고 있으면 방향 패드가 버퍼 키로 바뀝니다. 방향 패드를 건드리지 않고 떼면 그 자체로 한 번 누른 것이 되어 경유지 쪽으로 돌아섭니다. [버퍼](./information/buffers.md)와 [이동](./world/movement.md)을 참고하십시오.

예: 컨트롤러에서 손을 떼지 않고 현재 버퍼의 줄 읽기. 오른쪽 스틱을 누른 채 방향 패드 아래를 톡 눌러 다음 줄을 듣고, 방향 패드 오른쪽을 톡 눌러 다음 버퍼로 간 뒤 오른쪽 스틱에서 손을 뗍니다. 방향 패드를 썼기 때문에 경유지 쪽으로 돌아서기는 일어나지 않습니다.

## 바로 가기 층

전투 중이 아닐 때 양쪽 어깨를 함께 누르고 있으면, 버튼들이 WowVision 창을 엽니다. 이 창들에 해당하는 게임 버튼은 화면에 무언가를 띄울 뿐이라 비장애인 플레이어에게만 쓸모가 있습니다.

| 양쪽 어깨를 누른 채 누를 버튼 | 열리는 것 |
|---|---|
| 방향 패드 위 | 길 안내 창([길 안내](./world/navigation.md)) |
| 방향 패드 아래 | 대화 창([대화](./windows/chat.md)) |
| X | 스캐너([스캐너](./world/scanner.md)) |
| A | WowVision 메뉴 |
| 왼쪽 스틱 누르기 | 행동 단축바 창. 게임패드 단축바 네 개도 여기에 나옵니다. |

## 게임패드 주 메뉴(WoW: Forever)

Start 버튼을 누르면 게임의 게임패드 주 메뉴가 열립니다. 비장애인 플레이어가 오른쪽 스틱으로 고르는 여덟 칸짜리 휠입니다. WowVision은 이것을 네 칸씩 두 줄로 된 창으로 보여 줍니다.

- 윗줄은 휠의 오른쪽 절반으로, 맨 위에서 시계 방향으로 북, 북동, 동, 남동입니다.
- 아랫줄은 왼쪽 절반으로, 남, 남서, 서, 북서입니다.

창 제목은 예를 들어 "주 메뉴, 페이지 2 of 3"입니다. 주 메뉴 휠은 세 페이지이고 감정 표현 휠은 페이지가 없습니다. 게임에서 흐리게 표시된 칸은 ", 사용 안 함"을 붙여 읽고, 현재 열려 있는 칸은 ", 열림"을 붙여 읽습니다. 빈 칸은 "비어 있음"으로 읽습니다. 강화 효과 칸은 아직 지원하지 않으며, 누르면 "아직 지원하지 않음"이라고 말합니다.

| 버튼 | 기능 |
|---|---|
| 왼쪽 스틱 | 격자 안에서 한 칸씩 이동합니다. 휠이 열려 있는 동안에는 스틱으로 캐릭터가 걷지 않습니다. |
| A 또는 Enter | 휠을 닫고 그 칸을 실행합니다. 그 칸이 여는 창에 초점이 갑니다. |
| 어깨 | 휠의 페이지를 넘깁니다. |
| 방향 패드와 나머지 버튼 | 게임의 휠에 그대로 남아 비장애인 플레이어가 쓸 때와 똑같이 작동합니다(방향 패드로 앉기와 감정 표현 페이지를 고를 수 있습니다). |
| B 또는 Start | 휠을 닫습니다. |

추적은 WowVision 스캐너를 열고, 대화는 WowVision 대화 창을 엽니다. 나머지 칸(소셜, 가방, 시계, PvP, 감정 표현)은 게임 자체의 동작을 실행합니다.

왼쪽 스틱은 전투 중이 아닐 때만 격자 안에서 이동합니다.

## 게임패드 단축바(WoW: Forever)

Forever의 게임패드 인터페이스에서는 주문이 키보드 단축바가 아니라 게임패드 단축바에 놓입니다. Shift+F4나 양쪽 어깨 + 왼쪽 스틱 누르기로 행동 단축바 창을 엽니다. 게임패드 인터페이스가 켜져 있는 동안에는 창에 단축바 네 개가 더 나옵니다.

- 게임패드 단축바: 트리거를 누르지 않았을 때 씁니다.
- 왼쪽 트리거 단축바: 왼쪽 트리거를 누르고 있을 때 씁니다.
- 오른쪽 트리거 단축바: 오른쪽 트리거를 누르고 있을 때 씁니다.
- 양쪽 트리거 단축바: 두 트리거를 모두 누르고 있을 때 씁니다.

단축바마다 칸이 여덟 개 있으며, 차례대로 방향 패드 왼쪽, 방향 패드 위, 방향 패드 오른쪽, 방향 패드 아래, X, Y, B, A에 하나씩 대응합니다. 각 칸은 버튼과 함께 읽습니다. 예: "화염구, 방향 패드 왼쪽". 단축바 이름에는 "게임패드 단축바, 페이지 1"처럼 페이지가 들어 있습니다. 바로 가기 층의 방향 패드 왼쪽과 오른쪽은 비장애인 플레이어가 쓸 때와 마찬가지로 페이지를 넘깁니다. [행동 단축바](./windows/action-bars.md)를 참고하십시오.

## 전투 중

전투가 시작되면 WowVision 창의 키와 마찬가지로 WowVision 창에서 쓰는 버튼과 바로 가기 층이 게임으로 돌아갑니다. 오른쪽 스틱 누르기와 그 조합(경유지 쪽으로 돌아서기, 버퍼)은 언제나 WowVision이 맡습니다. 전투가 끝나면 WowVision이 버튼을 다시 가져옵니다.

게임에서 대상을 지정하려고 어깨 버튼을 누르고 있는 동안 WowVision이 쓰는 버튼을 누르면, 그 어깨 버튼은 이미 쓴 것으로 칩니다. 그래서 나중에 어깨 버튼을 떼도 대상이 바뀌지 않습니다.

## 버튼 바꾸기

단축키 창에는 게임패드 인터페이스가 켜져 있을 때만 단축키마다 지정된 컨트롤러 버튼이 표시됩니다.

1. WowVision 메뉴(Shift+F1, 또는 양쪽 어깨 + A)를 열고 인터페이스, 단축키로 갑니다.
2. 원하는 단축키로 이동합니다. 그 줄에는 키가 먼저 있고, 다음에 추가(키를 추가하는 항목), 그다음 컨트롤러 버튼, 마지막으로 컨트롤러 버튼 추가가 있습니다.
3. 컨트롤러 버튼을 지우려면 그 버튼을 실행합니다(A 또는 Enter). 묻지 않고 바로 지워집니다.
4. 버튼을 추가하려면 컨트롤러 버튼 추가를 실행합니다. 단축키 이름과 "컨트롤러 버튼을 누르십시오"가 들립니다. 조합할 어깨 버튼, 트리거, 오른쪽 스틱 누르기를 누른 채 버튼을 누릅니다. 누르는 동안 WowVision이 "왼쪽 트리거 + A 버튼"처럼 조합을 말합니다. 버튼에서 손을 떼면 그 버튼이 지정됩니다.
5. 어깨 버튼, 트리거, 오른쪽 스틱 누르기를 단독으로 눌렀다 떼면 그것 자체가 버튼으로 지정됩니다.
6. 그 버튼이 이미 다른 단축키에 지정되어 있으면 "이 입력과 충돌하는 단축키 ...  바꾸시겠습니까?"라고 묻습니다. 확인하면 다른 단축키에서 그 버튼을 가져옵니다.

키보드에서 Escape를 누르거나, 10초 동안 아무것도 누르지 않거나, 전투가 시작되면 버튼 입력 대기를 그만두고 "취소됨"이라고 말합니다. 전투 중에는 아예 열리지 않고 "전투 중에는 불가"라고 말합니다. 단축키 창의 나머지 내용은 [단축키](./basics/keybindings.md)를 참고하십시오.

버튼은 다음과 같이 읽습니다: A 버튼, B 버튼, X 버튼, Y 버튼, 방향 패드 위, 방향 패드 아래, 방향 패드 왼쪽, 방향 패드 오른쪽, 왼쪽 어깨, 오른쪽 어깨, 왼쪽 트리거, 오른쪽 트리거, 왼쪽 스틱 누르기, 오른쪽 스틱 누르기, 보기 버튼, 메뉴 버튼, 공유 버튼. 조합은 " + "로 이어 읽고, 바로 가기 층은 "양쪽 어깨", 누르고 있는 오른쪽 스틱은 "오른쪽 스틱 누르고 있기"로 읽습니다.

## 문제 신고하기

게임패드 인터페이스가 켜져 있는 동안 WowVision은 컨트롤러 입력과 그 전후의 음성을 기록합니다. 이 기록은 로그아웃하거나 /reload를 입력할 때 WowVision 데이터에 저장되며, 그 이전 세션의 기록도 함께 남습니다. 문제를 재현하기 바로 전에 /wv padlog를 입력하면 기록을 새로 시작합니다. 인터페이스가 켜져 있으면 "WowVision pad log started afresh"라고 답하고, 꺼져 있으면 "WowVision pad log: only with the gamepad interface on"이라고 답합니다. 그다음 [버그 신고 방법](./getting-started/troubleshooting.md#버그-신고하기)을 따르십시오.
