# 시스템 창

이 페이지는 게임 세계가 아니라 게임 자체에 속한 창을 다룹니다. 게임 메뉴, 게임 설정, 팝업과 확인 대화 상자, 매크로 창, 색 지정 창입니다. 대상이 얼마나 멀리 있는지 알려 주는 작은 보조 기능인 거리 안내도 설명합니다.

WowVision 자체 설정이 들어 있는 WowVision 메뉴가 필요하면 [WowVision 메뉴와 설정](../basics/menu-and-settings.md)을 참고하십시오.

## 게임 메뉴

열린 창이 없을 때 Escape를 누르면 게임이 게임 메뉴를 엽니다. WowVision은 이 메뉴를 메뉴라는 창으로 읽습니다.

- 위에서 아래로 각 버튼이 하나의 정지점입니다. Tab과 Shift+Tab으로 버튼 사이를 이동합니다. 여기서는 화살표 키로 버튼 사이를 이동할 수 없습니다.
- Enter를 누르면 지금 있는 버튼을 사용합니다.
- Escape를 다시 누르면 메뉴를 닫고 게임으로 돌아갑니다.

버튼은 게임 자체의 버튼이며 버전에 따라 다릅니다. 보통 설정, 매크로 설정, 접속 종료, 게임 종료, 게임으로 돌아가기가 있고, 일부 버전에는 고객지원, 블리자드 샵, 인터페이스 설정, 편집 모드도 있습니다. 각 버튼은 게임의 이름표대로 읽힙니다.

다른 WowVision 창이 열려 있으면 Escape는 그 창부터 닫습니다. 게임 메뉴는 그다음에 누를 때 열립니다.

## 게임 설정 창

게임 메뉴의 설정은 게임의 설정 창을 엽니다. WowVision 읽기 기능은 이 창의 거의 전부를 다룹니다. 탭, 범주 목록, 검색 상자, 그리고 거의 모든 종류의 설정 줄입니다. 게임 메뉴에서 여십시오.

### 창의 구성

정지점은 다음 순서입니다.

1. 탭: 게임과 애드온이 한 줄로 있습니다. 탭은 게임이 탭을 표시할 때만 있습니다. WoW: Forever를 새로 설치하면 애드온이 설정을 등록하기 전까지 탭이 없습니다.
2. 검색: 텍스트 상자입니다. Tab으로 들어가면 바로 입력할 수 있는 상태가 됩니다. 설정 이름의 일부를 입력하면 모든 범주에서 일치하는 설정이 목록에 나옵니다. Tab을 누르면 상자를 벗어납니다.
3. 범주: 게임 플레이, 조작 설정, 그래픽, 음성, 인터페이스 설정, 소셜, 단축키 설정 같은 범주 목록입니다. 그룹 머리글은 "이름, 구분선"으로 읽힙니다. 범주에서 Enter를 누르면 그 범주의 설정이 나옵니다.
4. 설정: 고른 범주의 설정입니다. 이 정지점의 이름은 범주 이름을 따릅니다. 예: "음성".
5. 기본 설정: 현재 범주를 기본값으로 되돌리는 게임의 버튼입니다. 게임이 팝업으로 확인을 요청합니다.

다른 범주를 고르면 설정 정지점은 다시 맨 위에서 시작합니다.

### 설정

줄 종류별로 들리는 내용과 작동 방식은 다음과 같습니다.

| 설정 | 들리는 내용 | 바꾸는 방법 |
|---------|---------------|------------------|
| 체크 상자 | 이름과 "체크됨" 또는 "체크되지 않음". | Enter를 누르면 전환됩니다. 바뀐 상태를 말합니다. |
| 슬라이더 | 이름과 값. | Left와 Right로 값을 한 단계씩 바꿉니다. Enter를 누르면 정확한 숫자를 입력할 수 있는 상자가 열립니다. |
| 드롭다운 | 이름과 현재 선택값. | Enter를 누르면 게임의 드롭다운 메뉴가 WowVision 메뉴로 열립니다. Enter로 고르십시오. 표시할 대화 종류처럼 여러 개를 체크할 수 있는 드롭다운은 선택한 항목을 나열하거나 "없음"이라고 말합니다. |
| 버튼 | 이름과 버튼의 글자. 예: "재사용 대기시간 관리자, 편집 모드 열기". | Enter를 누르면 버튼이 눌립니다. |
| 색 견본 | 이름과 현재 색상. | Enter를 누르면 색 지정 창이 열립니다. [색 지정 창](#색-지정-창)을 참고하십시오. |
| 구역 머리글 | 이름과 "구분선". | 누를 것이 없습니다. |

어떤 줄에는 체크 상자와 슬라이더, 또는 체크 상자와 색 견본처럼 조작 요소가 두 개 있습니다. 이런 줄은 한 쌍으로 읽힙니다. 이름을 말한 뒤 첫 번째 조작 요소와 그 위치를 말합니다. 예: "1 of 2". Down(또는 Right)으로 두 번째 조작 요소로 가고 Up(또는 Left)으로 돌아옵니다. 체크 상자가 꺼져 있는 동안에는 게임이 두 번째 조작 요소를 회색으로 비활성화하므로 이 요소는 비활성화라고 읽힙니다.

게임이 회색으로 비활성화한 조작 요소는 "비활성화"라고 말하며, 거기서 Enter를 눌러도 아무 일도 일어나지 않습니다. 설정 줄에는 툴팁도 있습니다. Space를 누르면 게임이 그 설정에 붙인 설명을 읽습니다.

특별한 줄:

- 그래픽 품질에는 기본 게임 품질 탭과 공격대 그래픽 품질 탭, 두 탭이 있습니다. 각 탭에는 1부터 10까지의 품질 슬라이더가 있고, 그 뒤에 세부 드롭다운 목록(그림자, 액체, 입자, 텍스처 등)이 이어집니다. 공격대 탭에는 자체 사용함 체크 상자가 있습니다. 가시 거리, 원거리 사물 표현, 지면 사물도 1부터 10까지의 슬라이더입니다.
- 아이템 등급 색상(색각 보정 모드 범주): 아이템 등급마다 색 견본이 하나씩 있으며, 하급, 일반, 희귀처럼 등급 이름이 붙어 있습니다.
- 공격대창 미리보기와 이름표 미리보기는 미리보기가 그림이므로 글자로만 읽힙니다.
- 어떤 줄은 체크 상자 옆에 설명을 둡니다. 이 설명은 체크 상자의 일부로 읽힙니다.
- 게임 자체의 음성 합성 목소리 줄은 옆에 샘플 버튼이 있는 드롭다운이며, 위의 조작 요소 두 개짜리 줄처럼 한 쌍으로 읽힙니다.
- WowVision이 아직 모르는 종류의 줄은 "Setting type", 그 줄 종류의 게임 내부 이름, "not implemented"로 읽힙니다. 이런 줄은 알려 주십시오. [문제 해결](../getting-started/troubleshooting.md)을 참고하십시오.

### 단축키 설정

단축키 설정 범주에는 게임 자체의 단축키가 구역별로 나열됩니다.

- 구역 머리글은 "펼쳐짐" 또는 "접힘"이라고 말합니다. Enter를 누르면 접거나 펼칩니다.
- 어떤 구역은 짧은 설명 줄로 시작하며, 다른 글처럼 읽힙니다.
- 각 단축키는 동작 이름이 붙은 버튼 한 쌍입니다. 예: "위로 뛰기". 각 버튼은 지정된 키를 읽거나 "지정 안 됨"이라고 말합니다. Left와 Right로 두 버튼 중 하나를 고릅니다.
- 버튼에서 Enter를 누르면 키 지정을 시작합니다. 원하는 키(또는 키 조합)를 누르십시오. 지정되면 WowVision이 "Rebinding successful"이라고 말합니다.
- Backspace를 누르면 그 버튼의 키를 지웁니다.

여기서는 게임의 단축키가 바뀝니다. WowVision 자체의 키(창 안을 이동하는 키)는 WowVision의 단축키 창에서 바꿉니다. [단축키](../basics/keybindings.md)를 참고하십시오.

예: 자동 전리품 획득 켜기.

1. Escape를 누르고 Tab으로 설정까지 간 뒤 Enter를 누르십시오.
2. Tab으로 검색까지 가서 "자동 전리품"을 입력하십시오.
3. 설정 목록이 나올 때까지 Tab을 누르고 아래로 읽어 자동 전리품 획득까지 가십시오.
4. Enter를 눌러 설정을 켜거나 선택지를 여십시오. 게임 버전에 따라 다릅니다. 바뀐 상태가 들립니다.
5. Escape를 눌러 창을 닫으십시오.

## 팝업과 확인 대화 상자

게임의 많은 질문은 화면 가운데에 작은 상자로 나타납니다. 파티 초대, 부활 제안, 소환, "이 아이템을 귀속하시겠습니까?" 확인, "이 아이템을 완전히 파괴하시겠습니까?" 확인 같은 것입니다. WowVision은 상자마다 팝업이라는 창을 열어 읽습니다. 동시에 열려 있는 상자는 모두 한 창에 차례로 나열되며, 상자마다 팝업이라는 제목이 붙습니다.

상자에는 최대 세 부분이 있으며, 각 부분이 하나의 정지점입니다.

1. 질문 내용. 내용이 바뀌면 다시 읽습니다. 예를 들어 "30초 후에 순간이동됩니다" 같은 카운트다운이 그렇습니다. 게임이 Enter로 수락하게 해 주는 상자라면, 질문 내용에서 Enter를 누르면 첫 번째 버튼이 대신 눌립니다.
2. 텍스트 상자. 대화 상자가 이름이나 단어 지금파괴 같은 입력을 요구할 때만 있습니다. 상자의 힌트를 읽은 뒤 입력한 내용을 읽습니다. Enter를 누르면 게임의 키보드 초점이 상자 안으로 들어가므로 글을 입력하십시오. 그다음 Enter를 다시 누르면 대화 상자를 수락하고(게임 자체의 동작입니다), Escape를 누르면 취소합니다.
3. 버튼. 버튼마다 하나의 정지점이며, 게임의 이름표대로 수락, 거절, 확인, 취소, 예, 아니요 등이 있습니다. Enter를 눌러 사용하십시오.

Escape는 게임과 같은 방식으로 상자를 취소합니다.

예: 파티 초대 수락하기.

1. 팝업을 읽어 줍니다. 플레이어 이름과 "님이 당신을 파티에 초대했습니다"가 들립니다.
2. Tab으로 수락까지 가서 Enter를 누르십시오.

Sku 애드온을 불러온 상태라면 WowVision은 팝업을 Sku에 맡깁니다.

## 매크로

게임 메뉴(매크로 설정)나 슬래시 명령 `/macro`로 매크로 창을 엽니다. 이 창은 두 가지 방식으로 읽힙니다.

### 기본 창

정지점은 다음 순서입니다.

1. 탭: 공통 매크로와 캐릭터 전용 매크로, 두 탭입니다. 현재 탭은 "선택됨"이라고 말합니다.
2. 매크로: 매크로가 이름별 목록으로 나옵니다. Enter를 누르면 매크로를 선택하며, 선택된 매크로는 "선택됨"이라고 말합니다. 탭에 매크로가 없으면 목록은 "비어 있음"이라고 말합니다.
3. 매크로를 끌어서 집기: 선택한 매크로의 아이콘을 나타내는 버튼입니다. 여기서 \\(끌기 키)를 누르면 매크로를 커서에 집어 듭니다.
4. 편집: 이름과 아이콘 상자를 여는 버튼입니다. 게임 자체의 글자로 읽히며, 보통 이름/아이콘 변경입니다.
5. 매크로 내용: 매크로 명령이 들어 있는 텍스트 상자입니다. Tab으로 들어가서 입력합니다. 다시 Tab을 누르면 벗어납니다.
6. 게임이 지금 표시하는 버튼: 취소, 저장, 삭제, 만들기. 버튼마다 하나의 정지점입니다.

### 이름 상자

만들기나 편집을 누르면 창에 더 작은 상자가 나타납니다. 이름 텍스트 상자, 확인, 취소가 있습니다. WowVision은 아이콘 목록을 읽지 않으므로 아이콘을 고를 수 없습니다. 새 매크로에는 게임이 처음 정해 주는 아이콘이 붙습니다.

예: 매크로를 만들어 행동 단축바에 놓기.

1. 대화창에 `/macro`를 입력하고 Enter를 누르십시오.
2. Tab으로 만들기 버튼까지 가서(맨 위에서 Shift+Tab을 누르면 끝으로 돌아가 그 버튼에 닿습니다) Enter를 누르십시오.
3. 이름 상자에 "Heal"을 입력하고 Tab으로 확인까지 가서 Enter를 누르십시오.
4. Tab으로 매크로 내용까지 가십시오. `/cast Healing Touch`를 입력하고 Tab을 누르십시오.
5. Tab으로 저장까지 가서 Enter를 누르십시오.
6. Shift+Tab으로 매크로를 끌어서 집기까지 돌아가 \\를 누르십시오. 매크로가 커서에 있습니다.
7. Shift+F4로 단축바 창을 열고 빈 칸까지 가서 \\를 누르십시오. 이제 그 칸은 "Heal"이라고 읽힙니다. [행동 단축바](./action-bars.md)를 참고하십시오.

## 색 지정 창

설정과 일부 애드온 창의 색 견본은 게임의 색 지정 창을 엽니다. 색상환 자체는 마우스가 있어야 쓸 수 있으므로, WowVision은 같은 색을 대신 숫자로 읽습니다.

정지점은 다음 순서입니다.

1. 현재 색상: 색을 말로 설명합니다. 예: "현재 색상: 어두운 회색빛 파란색, Slate Gray". 슬라이더를 바꾸면 갱신됩니다.
2. 원래 색상: 처음 색입니다(게임이 그 색을 알 때만).
3. 빨간색, 녹색, 파란색: 각각 0부터 255까지의 숫자이며, 뒤에 색 전체의 설명이 이어지므로 색이 어떻게 바뀌었는지 들을 수 있습니다. Left와 Right로 1씩 바꿉니다. Enter를 누르면 정확한 값을 입력할 수 있습니다.
4. 투명도: 색에 투명도가 있을 때만 있으며, 백분율로 나옵니다. Left와 Right로 5퍼센트씩 바꾸고, Enter를 누르면 값을 입력할 수 있습니다.
5. 16진수 색상: 색을 16진수로 보여 주는 텍스트 상자입니다. 게임에 이 상자가 있을 때만 나옵니다. 코드를 입력하면 슬라이더가 따라 바뀝니다.
6. 확인과 취소가 한 줄로 있습니다.

예: 색을 순수한 빨간색으로 정하기.

1. 설정의 색 견본에서 Enter를 누르십시오. 색 지정 창이 열립니다.
2. Tab으로 빨간색까지 가십시오. Enter를 누르고 255를 입력한 뒤 Enter를 누르십시오.
3. Tab으로 녹색까지 가서 0을 입력하십시오. Tab으로 파란색까지 가서 0을 입력하십시오.
4. Tab으로 현재 색상까지 가서 설명을 듣고, Tab으로 확인까지 가서 Enter를 누르십시오.

## 거리 안내

(모든 버전에서 사용 가능합니다.) 대상이 있는 동안 WowVision은 대상까지의 거리를 야드 단위로 알려 주므로 주문 사거리 안에 있는지 알 수 있습니다. 숫자를 말하는 녹음된 음성을 재생합니다. 예: "thirty". 무언가를 대상으로 잡을 때와 거리가 다른 단계로 바뀔 때마다 말합니다. 대상이 없는 동안에는 아무 말도 하지 않습니다.

거리는 게임 자체의 주문과 아이템이 쓰는 것과 같은 사거리 검사에서 나오므로 5, 8, 10, 20, 30, 35, 40 같은 단계가 들립니다. 이 숫자는 정확한 측정값이 아니라 상한입니다. "thirty"는 대상이 30야드 안에 있다는 뜻입니다. 게임이 검사를 제공하지 않아서 일부 버전에서는 몇몇 단계가 빠집니다. 전투 중에는 우호적 대상까지의 거리를 알 수 없습니다.

게임이 검사할 수 있는 가장 먼 거리보다 대상이 멀리 있으면 아무 말도 하지 않으며, 다시 사거리 안으로 들어오면 거리를 다시 알려 줍니다.

바꾸려면 WowVision 메뉴에서 대상 지정, 하드 대상을 차례로 열고 거리 변경을 고르십시오.

| 설정 | 기본값 | 하는 일 |
|---------|---------|--------------|
| 거리 변경, 사용함 | 켜기 | 거리 안내 전체를 켜거나 끕니다. |
| 그 안의 음성 팩 경보, 사용함 | 켜기 | 녹음된 음성입니다. |
| 그 안의 음성 팩 경보, 음성 팩 | Matthew | 누구의 녹음된 음성으로 숫자를 읽을지 정합니다. |

거리 경보에는 음성 합성과 소리 출력이 없고 녹음된 음성만 있습니다. 경보와 음성 팩의 작동 방식은 [경보](../basics/alerts.md)와 [음성 및 소리](../basics/speech.md)를 참고하십시오.

## 설정과 경보

| 창 | 설정 | 경보 |
|--------|----------|--------|
| 게임 메뉴 | 없음 | 없음 |
| 설정 | 없음 | 없음 |
| 팝업 | 없음 | 없음 |
| 매크로 설정 | 없음 | 없음 |
| 색 지정 | 없음 | 없음 |
| 거리 | 대상 지정, 하드 대상의 거리 변경(위 참고) | 거리 변경 |

이 창들은 각각 WowVision 메뉴의 창 항목 아래에 있는 모듈이며, 각 모듈에는 WowVision이 그 창을 읽지 않게 하는 사용함 스위치가 있습니다. 거리에는 자체 항목이 없습니다. 거리의 사용함 스위치는 거리 변경 경보에 있습니다. [WowVision 메뉴와 설정](../basics/menu-and-settings.md)을 참고하십시오.

## 문제 해결

- Escape를 누르면 창이 닫히지 않고 게임 메뉴가 열립니다. 창은 이미 닫혔습니다. Escape를 다시 누르면 게임 메뉴에서 나갑니다.
- 팝업이 없는 것 같습니다. Ctrl+Tab을 눌러 팝업이 나올 때까지 창을 차례로 넘기십시오. 팝업과 다른 창이 함께 열려 있을 수 있습니다.
- 색 이름으로 색을 정할 수 없습니다. 색 지정 창은 숫자나 16진수 코드만 받습니다.
