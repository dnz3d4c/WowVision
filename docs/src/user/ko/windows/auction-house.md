# 경매장

경매장 창에서는 아이템을 검색하고, 아이템에 입찰하거나 즉시 구입하고, 자기 물건을 판매에 올리고, 진행 중인 경매와 입찰을 확인할 수 있습니다. WowVision은 창 전체를 읽어 주며, 불타는 성전(TBC)에서는 물건 가격을 기억하는 가격 데이터베이스를 더합니다.

## 사기 전에 가격 확인하기

사기 전에는 항상 총 가격을 확인하십시오. 창은 사용하는 도중에도 변경될 수 있고, 누군가 실수로 사 주기를 바라며 아이템을 아주 비싼 가격에 올리는 판매자도 있습니다.

이런 일은 상품의 수량을 입력할 때 가장 일어나기 쉽습니다. 싼 가격에 몇 개가 있고 그 뒤로 훨씬 비싼 가격에 많은 수가 있는 경우가 흔한데, 그 비싼 것들도 자동으로 포함됩니다. 판다리아의 안개, Retail, WoW: Forever에서는 총 가격이 낼 금액을 알려 주고 구매 버튼을 누르면 확인을 요청하므로, 그때라도 구매를 취소할 수 있습니다.

## 버전별로 쓸 수 있는 기능

| 버전 | 경매장 읽기 |
|---|---|
| Classic Era | 사용할 수 없음 |
| 불타는 성전(TBC) | 가능: 탭 세 개짜리 기존 창(검색, 입찰건, 경매), 추가 스캔 도구와 가격 데이터베이스 포함 |
| 판다리아의 안개(Mists) | 가능: 최신 창(구매, 판매, 경매) |
| Retail | 가능: 판다리아의 안개와 같은 최신 창(같은 읽기 기능을 불러옴) |
| WoW: Forever | 가능: 판다리아의 안개와 같은 최신 창 |

두 창은 작동 방식이 꽤 다르므로 아래에 따로 설명합니다: [불타는 성전](#불타는-성전-경매장), [판다리아의 안개, Retail, WoW: Forever](#최신-경매장-판다리아의-안개-retail-wow-forever).

## 열기와 닫기

경매인에게 다가가 말을 겁니다. WowVision은 경매장 창이 열리자마자 읽기 시작하고, 게임은 가방도 함께 엽니다. Ctrl+Tab으로 경매장 창과 가방 사이를 오갑니다([가방과 은행](./bags-and-bank.md) 참고). Escape를 누르면 경매장이 닫힙니다.

창 안의 일반 키([인터페이스 기본](../basics/interface.md) 참고):

| 키 | 동작 |
|---|---|
| Tab / Shift+Tab | 다음 또는 이전 구역 |
| Up / Down | 목록이나 구역 안에서 이동 |
| Left / Right | 탭 줄이나 정렬 머리글 줄을 따라 이동 |
| Enter | 왼쪽 클릭: 결과 선택, 버튼 누르기, 메뉴 열기 |
| Backspace | 오른쪽 클릭 |
| Space | 초점이 있는 줄의 툴팁 읽기 |
| Shift+F10 | 상황별 메뉴 |
| Page Up / Page Down | 긴 목록 스크롤 |

### 가격 입력하기

가격은 골드, 실버, 코퍼 최대 세 개의 입력 상자에 따로 입력하며, 상자마다 정지점이 하나씩입니다. 이 상자들은 가격 이름("입찰 가격", "즉시 구입가", "경매 시작가")이 붙은 제목 아래에 있습니다. Tab으로 상자에 오면 바로 입력할 수 있습니다. Tab을 다시 누르면 다음 상자로 갑니다. 숫자만 입력합니다. 2골드 50실버로 하려면 골드에 2, 실버에 50을 입력하고 코퍼는 비워 둡니다.

가격은 항상 게임이 쓰는 그대로 읽힙니다: "1 골드 20 실버 5 코퍼".

## 불타는 성전 경매장

### 구성

창에는 탭이 세 개 있으며 첫 줄("탭")에 나옵니다: 검색, 입찰건, 경매(게임에 표시되는 이름). Left와 Right로 탭 사이를 이동합니다. 열린 탭은 "선택됨"으로 읽힙니다. Enter로 탭을 변경합니다.

### 검색 탭

Tab을 누르면 다음 구역을 이 순서로 지나갑니다:

1. 범주: 게임의 범주 버튼(무기, 방어구, 가방류 등). 범주에서 Enter를 누르면 그 범주를 바로 검색합니다. 범주를 고르면 하위 범주가 같은 목록에 새 버튼으로 열립니다. 빈 목록은 "비어 있음"으로 읽힙니다.
2. 검색: 아이템 이름을 넣는 입력 상자. 입력한 뒤 Enter를 눌러 검색합니다.
3. 결과: 현재 페이지의 경매 목록(아래 참고). 여러 페이지 스캔이 진행되는 동안에는 스캔 중단 버튼으로 대체되고, 스캔 결과가 있으면 스캔 결과 목록이 됩니다.
4. 페이지 조작: 이전 페이지와 다음 페이지. 각각 쓸 수 있을 때만 있습니다. 최소 묶음 크기 항목에서 설명하는 상황에서는 더 불러오기 버튼이나 스캔 버튼으로 변경됩니다.
5. 선택한 경매로 할 수 있는 동작(경매를 선택한 동안에만): 즉시 구입가(글자로 읽음)와 즉시 구입 버튼, 그다음 입찰 가격 상자(골드, 실버, 코퍼)와 입찰 버튼.
6. 정렬: 정렬 버튼 줄.
7. 가격 설정: 개당 가격과 총 가격 정렬 선택지. 게임이 보여 줄 때만 있습니다.
8. 필터: 필터 화면을 엽니다(아래에서 설명).
9. 검색: 게임의 검색 버튼.
10. 전체 스캔: 가격 데이터베이스 스캔(아래에서 설명).
11. 새로고침: 모든 필터를 되돌리는 게임의 버튼. 사용할 수 있을 때만 있습니다.

#### 결과

경매 줄마다 아이템, 묶음 크기, 판매자, 즉시 구입가, 현재 입찰가, 남은 시간을 읽습니다. 예:

> 리넨 옷감 x20, 판매자: Bob, 즉시 구입: 1 실버 20 코퍼, 현재 입찰가: 90 코퍼, 마감 시한: 장기

세부 사항:

- "x20"은 묶음 크기이며, 아이템이 하나뿐이면 빠집니다.
- 즉시 구입가가 없는 경매에서는 즉시 구입가가 빠집니다.
- "현재 입찰가"는 지금까지의 최고 입찰가이고, 아무도 입찰하지 않았으면 경매 시작가입니다.
- 남은 시간은 단기, 중기, 장기, 최장기 중 하나입니다. 게임의 네 가지 기간 구분으로, 대략 30분 미만, 2시간 이하, 12시간 이하, 48시간 이하입니다.
- 선택한 줄은 "선택됨"으로 읽힙니다.

Enter를 누르면 줄이 선택되고 "선택됨: 리넨 옷감"이 들립니다(아이템 선택됨 알림입니다). Space를 누르면 아이템의 전체 툴팁을 읽습니다.

#### 입찰과 즉시 구입

1. 원하는 경매에서 Enter를 누릅니다. 결과 뒤에 입찰 구역과 즉시 구입 구역이 나타납니다.
2. 즉시 구입하려면: Tab으로 즉시 구입가 줄(가격이 들립니다)을 지나 즉시 구입 버튼으로 가서 Enter를 누릅니다.
3. 입찰하려면: Tab으로 입찰 가격으로 가서 골드, 실버, 코퍼 상자에 금액을 입력하고 입찰 버튼에서 Enter를 누릅니다.
4. 그러면 게임이 확인 팝업을 띄웁니다. WowVision은 확인 글 끝에 아이템 이름과 묶음 크기를 붙여서("... 리넨 옷감 x20"처럼) 무엇을 확인하는지 알 수 있게 합니다. 다른 팝업과 똑같이 답하면 됩니다([시스템 창](./system.md) 참고).

자기 경매를 취소할 때도 확인 글에 같은 내용이 덧붙습니다.

#### 정렬

정렬 줄에는 품질, 레벨, 마감 시한, 판매자, 현재 입찰가 버튼이 있습니다(게임에 표시되는 이름이며, 게임이 보여 주는 버튼만 있습니다).

- Left와 Right로 버튼 사이를 이동합니다.
- Up과 Down으로 방향을 고릅니다. 누를 때마다 WowVision이 "오름차순"이나 "내림차순"이라고 말합니다.
- Enter로 정렬을 적용합니다. 검색 탭에서는 검색을 다시 실행합니다.
- 버튼마다 이름, 방향, 그리고 지금 목록이 쓰는 정렬이면 "활성"을 읽습니다.

현재 입찰가 오름차순으로 정렬하면 경매 시작가가 가장 싼 것이 맨 앞에 옵니다. 즉시 구입가는 줄마다 읽히므로, Down으로 비교하십시오.

#### 필터 화면

필터에서 Enter를 누르면 별도의 작은 화면이 열립니다. Escape를 누르면 검색 탭으로 돌아갑니다. 화면에는 다음이 있습니다:

- 최소 묶음 크기: 숫자. 아래를 참고하십시오.
- 최소 레벨과 최대 레벨: 입력 상자.
- 품질 드롭다운(게임의 이름표와 현재 선택, 예: "전체").
- 게임의 사용 가능한 아이템 체크 상자(사용할 수 있는 아이템만).
- 게임의 착용 모습 보기 체크 상자(그림만 변경되므로 쓸모 있는 동작은 하지 않습니다).

레벨, 품질, 사용 가능 설정은 게임의 필터이며 다음 검색에 적용됩니다. 최소 묶음 크기는 WowVision 자체 기능이며 이어서 설명합니다.

#### 최소 묶음 크기, 스캔, 더 불러오기

게임은 경매 검색을 묶음 크기로 거를 수 없습니다. WowVision은 거를 수 있습니다: 필터 화면에서 최소 묶음 크기를 정하면 그 수보다 작은 묶음을 숨깁니다. 예를 들어 20이면 20개 이상인 묶음만 보입니다. 0이나 1로 정하면 필터가 꺼집니다. 이 설정은 직접 변경하거나 인터페이스를 다시 불러올 때까지 유지됩니다.

필터가 켜져 있으면:

- 검색 뒤 결과 목록에는 현재 페이지에서 조건에 맞는 경매만 나오며, 줄마다 판매자가 있습니다. 맞는 것이 없으면 "결과 없음"이 읽힙니다.
- 검색에서 경매를 하나라도 찾았으면 페이지 조작 자리에 스캔 버튼이 있습니다. 여기서 Enter를 누르면 결과 페이지를 하나씩 훑습니다. 지금까지 조건에 맞는 경매를 모두 20개 이상 찾았으면 그 페이지의 끝에서, 그러지 못했으면 마지막 페이지에서 멈춥니다.

스캔하는 동안 "스캔 중, 12 페이지"(페이지 수)와, 다섯 페이지마다 "페이지 5 / 12"가 들립니다. 스캔 중단 버튼은 진행 상황을 읽으며(예: "스캔 중단 (3/12)"), Enter를 누르면 스캔이 멈춥니다. 스캔이 끝나면 다음 중 하나가 들립니다:

- "스캔 완료, 23 결과 in 340 개 항목 스캔": 살펴본 경매 340개 중 조건에 맞는 것을 23개 찾았습니다.
- "스캔 중단, 7 결과": 직접 멈췄습니다. 그때까지 찾은 것은 남습니다.
- "스캔 실패": 게임이 10초 안에 다음 페이지 검색을 받아들이지 않았습니다.

경매장을 닫아도 스캔이 멈춥니다.

스캔이 끝나면 스캔 결과 목록이 검색 목록을 대신합니다. 줄은 판매자를 포함해 일반 결과처럼 읽힙니다. 줄에서 Enter를 누르면 게임에 그 페이지를 다시 요청해 정확히 그 경매를 선택한 뒤, 위와 같이 입찰 구역과 즉시 구입 구역을 보여 줍니다. 그다음 스캔 결과 버튼으로 목록에 돌아올 수 있습니다. 그사이 경매가 팔렸거나 변경되었으면 "아이템을 찾을 수 없음"이 들리고 그 경매는 목록에서 빠집니다. 즉시 구입이나 입찰이 이루어지면 "아이템 구입 완료"가 들리고, 그 결과가 빠진 목록으로 돌아옵니다.

스캔 결과 끝에 있는 더 불러오기 버튼은 다음 페이지부터 스캔을 이어 가서 다음 20개 정도의 결과를 목록에 더합니다. 페이지가 더 있을 때만 나옵니다.

직접 새 검색을 시작하면 스캔 결과는 버려집니다.

### 입찰건 탭

1. 정렬 줄(품질, 레벨, 마감 시한, 즉시 구입, 상태, 현재 입찰가). 검색 탭과 같이 쓰지만 검색을 다시 실행하지는 않습니다.
2. 입찰건: 입찰한 경매. 검색 탭의 결과 줄처럼 읽히지만 판매자는 없습니다. 입찰한 것이 없으면 "입찰 없음"이 읽힙니다.
3. 입찰을 선택하면 입찰가를 올리는 입찰 가격 상자와 입찰 버튼, 그리고 즉시 구입 버튼이 나옵니다.

### 경매 탭: 판매와 내 경매

정지점 순서:

1. 여기에 아이템 놓기: 판매 칸. 아이템을 놓으면 그 아이템을 읽습니다. 예: "리넨 옷감 x20".
2. 경매 시작: 판매 양식(아래 참고).
3. 경매: 진행 중인 내 경매(아래 참고).
4. 경매 취소. 경매를 선택했고 그 경매를 취소할 수 있을 때만 있습니다.
5. 정렬: 품질, 마감 시한, 상태, 현재 입찰가.

#### 아이템 놓기

먼저 아이템을 커서에 올립니다: Ctrl+Tab으로 가방을 열고, 묶음에서 Enter를 눌러 집은 뒤([가방과 은행](./bags-and-bank.md) 참고), Ctrl+Tab으로 돌아와 여기에 아이템 놓기로 가서 Enter를 누릅니다. 커서에 아이템이 있으면 Enter로 칸에 놓습니다.

#### 판매 양식

아이템을 놓으면 다음 정지점이 나타납니다:

1. 묶음 크기: 경매 하나당 아이템 수. 뒤에 최대 버튼이 있습니다.
2. 묶음 개수: 만들 경매 수. 여기에도 최대 버튼이 따로 있습니다.
3. 즉시 구입가: 골드, 실버, 코퍼 상자. 즉시 구입가 없는 경매로 하려면 비워 둡니다.
4. 경매 시작가: 버튼. Enter를 누르면 시작 가격을 넣는 골드, 실버, 코퍼 상자가 있는 작은 화면이 열립니다. Escape를 누르면 양식으로 돌아갑니다.
5. 기간: 체크 상자 세 개, 12시간, 24시간, 48시간. 게임은 24시간으로 시작합니다.
6. 보증금: 낼 보증금을 글자로 읽습니다. 아이템을 놓으면 표시됩니다.
7. 경매 시작: 게임의 버튼.

#### 내 경매

내 경매는 각각 다음 순서로 읽힙니다: 팔렸으면 맨 앞에 "판매됨", 그다음 아이템과 묶음 크기, 즉시 구입가, 현재 입찰가, 입찰자가 있으면 입찰자 이름, 남은 시간. Enter로 하나를 선택하면 경매 취소로 취소할 수 있습니다. 게임이 확인을 요청하고, WowVision이 확인 글에 아이템 이름을 붙입니다.

### 예: 리넨 옷감 20개 판매하기(불타는 성전)

1. 경매인에게 말을 겁니다. 탭 줄에서 경매로 이동해 Enter를 누릅니다.
2. Ctrl+Tab을 누르고, 가방에서 리넨 옷감 묶음을 찾아 Enter를 눌러 집습니다. Ctrl+Tab을 눌러 돌아옵니다.
3. Tab으로 여기에 아이템 놓기로 가서 Enter를 누릅니다. 이제 "리넨 옷감 x20"으로 읽힙니다.
4. Tab으로 묶음 크기로 가서 20을 입력합니다. Tab으로 묶음 개수로 가서 1을 입력합니다.
5. Tab으로 즉시 구입가로 갑니다. 골드에 1, 실버에 20을 입력합니다.
6. Tab으로 경매 시작가로 가서 Enter를 누르고, 실버에 90을 입력한 뒤 Escape를 누릅니다.
7. Tab으로 기간으로 가서 24시간에서 Enter를 누릅니다(기본으로 이미 선택되어 있습니다).
8. Tab으로 보증금으로 가서 비용을 듣습니다.
9. Tab으로 경매 시작으로 가서 Enter를 누릅니다. 경매 목록에 내 경매가 나타납니다.

### 예: 가장 싼 구리 광석 찾기(불타는 성전)

1. 검색 탭에서 Tab으로 검색으로 가서 "구리 광석"을 입력합니다. Enter를 누릅니다.
2. Tab으로 결과로 가서 Down을 눌러 첫 줄들을 읽습니다. 아이템, 묶음, 판매자, 즉시 구입가, 현재 입찰가, 남은 시간이 들립니다.
3. 가격순으로 정렬하려면 Tab으로 정렬 줄로 가서 Right로 현재 입찰가로 이동하고, "오름차순"이 들릴 때까지 Up을 누른 뒤 Enter를 누릅니다. 다시 검색되어 입찰가가 가장 싼 것부터 나옵니다.
4. 큰 묶음만 사려면: Tab으로 필터로 가서 Enter를 누르고, 최소 묶음 크기를 20으로 정한 뒤 Escape를 누르고, 다시 검색해서 스캔으로 조건에 맞는 것을 모읍니다.
5. 원하는 묶음에서 Enter를 누르고, Tab으로 즉시 구입으로 가서 Enter를 누릅니다. 팝업에서 확인합니다.

### 가격 데이터베이스와 전체 스캔(불타는 성전 전용)

WowVision은 내 서버에서 아이템이 얼마인지 기억할 수 있습니다. 데이터베이스는 서버와 진영별로 따로 보관되며, 세션이 끝나도 남습니다.

#### 전체 스캔

검색 탭의 전체 스캔 버튼은 서버에 한 번 요청해 경매장 전체 정보를 받아 와 아이템별 최저 즉시 구입가를 기록합니다. 서버는 이것을 15분에 한 번만 허용합니다. 버튼은 상태에 따라 변경됩니다:

| 들리는 말 | 뜻 |
|---|---|
| "전체 스캔" | 스캔을 시작할 수 있습니다. Enter를 누르면 시작합니다 |
| "전체 스캔, 재사용 대기 중" | 스캔한 지 15분이 안 됐습니다. Enter를 누르면 남은 시간을 알려 줍니다. 예: "12 min 30 sec" |
| "스캔 중, 45 sec" | 서버가 데이터를 준비하고 있습니다(지금까지 기다린 시간, 초 단위). Enter를 누르면 중단합니다 |
| "스캔 중, 63%" | 데이터를 처리하고 있습니다. Enter를 누르면 중단합니다 |

진행 안내: 데이터가 도착하면 "전체 스캔 시작, 45000 건의 경매", 끝나면 "전체 스캔 완료, 3200 개 아이템 갱신". 그 밖의 메시지: "전체 스캔 중단"(스캔 중에 Enter를 누름), "재사용 대기 중", "경매장이 열려 있지 않음"(스캔 도중 경매장을 닫음), "전체 스캔 실패". 끝까지 마친 스캔은 인터페이스를 다시 불러와도 재사용 대기시간이 유지됩니다. 중단했거나 실패한 스캔도 다시 불러올 때까지는 재사용 대기시간이 걸려 있습니다.

전체 스캔이 진행되는 동안에는 WowVision이 게임의 목록 업데이트를 넘겨받으므로 검색 목록이 새로 고쳐지지 않습니다. 의도한 동작입니다. 그러지 않으면 게임이 수만 줄을 그리느라 몇 초씩 멈춥니다. 검색하기 전에 스캔이 끝나기를 기다리십시오.

#### 저장하는 내용과 툴팁에 더하는 내용

데이터베이스는 아이템마다 낱개 기준 최저 즉시 구입가, 그 가격을 본 날, 그리고 최근 며칠 동안의 일별 최고가, 최저가, 경매 수를 보관합니다. 툴팁 가격이 켜져 있으면 어디서든(가방, 상인, 경매 줄, 링크) 아이템 툴팁에 줄이 더 붙으며, Space로 읽습니다:

- 경매 가격: 마지막 최저 즉시 구입가. 예: "경매 가격: 2 실버 50 코퍼 (3 일 전)". 오늘 스캔한 가격이면 경과일이 빠집니다.
- 평균 줄. 예: "7-일간 평균: 2 실버 10 코퍼". 정한 일수 동안의 일별 최저가 평균입니다.
- 상인에게 판매: 상인이 사 주는 가격.
- 상인에게서 구입: 상인이 파는 가격. 그 상인이 그 아이템을 파는 것을 본 뒤에만 나옵니다. 상인이 항상 재고로 가진 아이템만, 그리고 방문한 상인의 것만 기억합니다.

#### 경매 가격 설정

WowVision 메뉴에서 경매 가격 모듈을 엽니다(불타는 성전 전용):

| 설정 | 기본값 | 동작 |
|---|---|---|
| 기록 일수 | 21 | 아이템마다 일별 최고가와 최저가를 며칠 치 보관할지 정합니다. 스캔이 아이템을 업데이트할 때마다 기록 일수보다 오래된 날의 기록은 지워집니다 |
| 평균 계산 일수 | 7 | 평균 줄에서 며칠 치를 평균할지 정합니다. 줄 이름도 이 값을 따릅니다("7-일간 평균") |
| 툴팁 가격 | 켬 | 아이템 툴팁에 경매 가격 줄과 상인 가격 줄을 더합니다 |
| 자동 스캔 | 끔 | 15분 재사용 대기시간이 지났으면 경매장을 열 때마다 전체 스캔을 자동으로 시작합니다 |

자동 스캔을 켜면 스캔 중에는 검색 목록이 새로 고쳐지지 않는다는 점을 기억하십시오. 경매장을 열자마자 검색하고 싶다면 꺼 두고, 원할 때 전체 스캔을 누르십시오.

#### 아이템 선택됨 알림

WowVision 메뉴의 창 범주 안 경매장 모듈 아래에 있는 아이템 선택됨 알림은 검색 결과를 선택할 때 들리는 "선택됨: 아이템 이름" 메시지를 설정합니다. 다른 알림과 마찬가지로 TTS 출력을 끄거나 변경할 수 있습니다([알림](../basics/alerts.md) 참고).

## 최신 경매장 (판다리아의 안개, Retail, WoW: Forever)

이 창에는 탭이 세 개 있습니다: 구매, 판매, 경매(게임에 표시되는 이름). 첫 줄에서 Left와 Right로 탭을 따라 이동하고 Enter로 탭을 엽니다. 열린 탭은 "선택됨"으로 읽힙니다. 게임의 구매 확인 창이 열려 있는 동안에는 그 창이 경매장 창 전체를 덮습니다(아래 참고).

옷감과 광석처럼 겹쳐지는 아이템은 "상품"입니다. 개당 가격을 기준으로 수량 단위로 사고팝니다. 방어구와 무기 같은 그 밖의 아이템은 입찰가와 즉시 구입가가 있는 낱개 경매입니다.

### 구매 탭

정지점 순서:

1. 범주: 범주 목록(무기, 방어구, ... 그리고 하위 범주). Enter로 범주를 선택하면 결과가 변경됩니다. 선택한 범주는 "선택됨"으로 읽힙니다.
2. 필터: 게임의 필터 드롭다운(Enter로 메뉴를 엽니다). 레벨 범위 줄에는 최소와 최대로 읽히는 입력 상자 두 개가 있습니다.
3. 검색: 입력 상자. 이름을 입력하고 Enter를 누릅니다.
4. 게임의 검색 버튼.
5. 결과: 찾은 아이템 목록.

결과마다 아이템 이름, 최저가, 판매 중인 수량을 읽습니다. 예:

> 구리 광석, 5 실버, 사용 가능 340

결과에서 Enter를 누르면 구매 화면이 열립니다.

WoW 토큰 범주는 지원하지 않습니다. 이 범주를 열면 본문이 "이 탭은 아직 지원하지 않습니다"로 읽힙니다.

#### 상품 사기

결과가 구매 화면으로 변경됩니다. WowVision은 초점을 뒤로 버튼으로 옮기고 어느 결과에서 왔는지 기억하므로, 뒤로를 누르면 그 결과로 돌아갑니다.

1. 뒤로: 결과로 돌아갑니다.
2. 경매: 판매자들의 묶음. 가장 싼 것부터, 각각 "구리 광석, 개당 가격 5 실버, 사용 가능 200"처럼 읽힙니다.
3. 수량: 사려는 개수. 입력합니다.
4. 총 가격: 총액을 글자로 읽습니다. 예: "총 가격 1 골드".
5. 구매: Enter를 누르면 게임의 확인 창이 열립니다.

#### 낱개 아이템 사기

1. 뒤로.
2. 경매: 경매마다 아이템 이름, 입찰가가 있으면 "입찰 가격", "즉시 구입가", 남은 시간(예: "마감 시한 장기")을 읽습니다. 남은 시간은 단기, 중기, 장기, 최장기 중 하나입니다. Enter로 하나를 선택합니다.
3. 하나를 선택하면: "즉시 구입 창" 제목 아래에 즉시 구입가와 즉시 구입 버튼, 그다음 "입찰 창" 아래에 골드, 실버, 코퍼 상자와 입찰 버튼이 있습니다.

#### 구매 확인 창

상품이나 아이템을 사려고 하면 게임의 구매 대화 상자가 열립니다. WowVision은 이 창만 "경매장" 제목 아래에 보여 줍니다. 아이템, 가격, 지금 구입 버튼, 취소 버튼 순서로 읽습니다. Tab으로 그 사이를 이동하고 Enter로 누릅니다.

### 판매 탭

정지점 순서:

1. 여기에 아이템 놓기: 아이템 칸. 아이템이 들어 있으면 아이템 이름을 읽습니다(장비는 아이템 레벨 포함). 아이템을 커서에 올린 채 Enter를 누르면 놓이며, \\ 또는 Ctrl+D(끌기 명령)를 써도 같습니다. 경매장이 열려 있는 동안 가방 아이템에서 Backspace를 누르면 경매에 올리기가 나옵니다([가방과 은행](./bags-and-bank.md) 참고).
2. 수량: 판매할 개수. 뒤에 최대 버튼이 있습니다.
3. 기간: 드롭다운. Enter로 선택지(12, 24, 48시간)를 엽니다.
4. 경매(비교 대상): 같은 아이템을 올린 다른 판매자의 경매. 상품이면 각각 아이템 이름, "개당 가격", "판매자" 이름을, 낱개 아이템이면 이름, "입찰 가격", "즉시 구입가"를 읽습니다. 가격을 정하는 데 참고하십시오.
5. 가격 상자. 제목은 게임의 것으로, 상품은 대개 "개당 가격", 낱개 아이템은 "입찰 가격"과 "즉시 구입가"입니다. 각각 골드, 실버, 코퍼 상자가 있습니다. 낱개 아이템에는 체크 상자(이름표는 게임의 것)가 있어 즉시 구입가만 받는 양식과 입찰가와 즉시 구입가를 함께 받는 양식 사이를 전환합니다. 함께 받는 양식으로 전환하면 나머지 가격을 넣는 두 번째 가격 입력이 나타납니다.
6. 보증금: 보증금을 글자로 읽습니다.
7. 총 가격: 경매의 총 가격.
8. 경매 시작: 게임의 등록 버튼.

다른 탭과 마찬가지로 WoW 토큰 판매 양식은 "이 탭은 아직 지원하지 않습니다"로 읽힙니다.

### 경매 탭: 내 경매와 입찰

먼저 하위 탭 두 개가 있는 줄이 나옵니다(게임에 표시되는 이름, 예: "경매"와 "입찰건"). Enter로 하나를 엽니다.

경매 하위 탭: 현재 판매 중인 물건이 있는 "경매" 목록, 그다음 경매 취소. 각각 다음을 읽습니다: 팔렸으면 맨 앞에 "판매됨", 아이템 이름, 묶음이면 "x20", "입찰 가격", "즉시 구입가", 그리고 숫자로 적은 남은 시간(예: "마감 시한 1시간 30분"). Enter로 취소할 경매를 선택합니다.

입찰건 하위 탭: 입찰한 경매가 있는 "입찰건" 목록. 각각 아이템 이름, "입찰자"(최고 입찰자), "입찰 금액", "최소 입찰가", 남은 시간 구분을 읽습니다. 하나를 선택하면: 입찰가를 올리는 골드, 실버, 코퍼 상자와 입찰 버튼이 있는 입찰 창, 그리고 가격과 즉시 구입 버튼이 있는 즉시 구입 창이 나옵니다.

이 모든 목록의 아이템 이름은 각 줄이 화면에 들어올 때 게임에서 읽어 옵니다. 이름을 아직 불러오지 못했으면 이름 없이 읽힙니다. 다른 곳으로 갔다가 돌아오거나 Shift+Tab과 Tab을 누르면 이름이 나타납니다.

### 예: 가장 싼 구리 광석을 찾아 20개 사기(판다리아의 안개, Retail, Forever)

1. 경매장을 엽니다. 구매 탭에서 Tab을 눌러 검색으로 가서 "구리 광석"을 입력합니다. Enter를 누릅니다.
2. Tab으로 결과로 갑니다. "구리 광석, 5 실버, 사용 가능 340"이 들립니다. Enter를 누릅니다.
3. 초점이 뒤로에 놓입니다. Tab으로 경매로 가서 묶음을 가장 싼 것부터 듣습니다.
4. Tab으로 수량으로 가서 20을 입력합니다.
5. Tab으로 총 가격으로 가서 총액을 듣습니다. Tab으로 구매로 가서 Enter를 누릅니다.
6. 대화 상자에서 Tab으로 지금 구입으로 가서 Enter를 누릅니다. 생각이 달라지면 취소를 누릅니다.

### 예: 리넨 옷감 20개 판매하기(판다리아의 안개, Retail, Forever)

1. 가방에서 리넨 옷감 묶음을 Enter로 집습니다(Ctrl+Tab으로 가방으로 갔다가 돌아옵니다).
2. 탭 줄에서 판매를 엽니다. Tab으로 여기에 아이템 놓기로 가서, 옷감을 커서에 올린 채 Enter를 누릅니다.
3. Tab으로 수량으로 가서 20을 입력합니다.
4. Tab으로 기간으로 가서 Enter를 눌러 24시간을 고릅니다.
5. Tab으로 경매로 가서 다른 판매자들의 개당 가격을 듣습니다.
6. Tab으로 가격 상자로 가서 개당 가격을 입력합니다. 예: 실버에 90.
7. Tab으로 보증금과 총 가격으로 가서 비용을 듣습니다.
8. Tab으로 경매 시작으로 가서 Enter를 누릅니다.

## 아직 읽지 않는 것

- 최신 창의 구매와 판매에 있는 WoW 토큰.
- 불타는 성전에는 가격 기록 창이 없습니다. 가격 데이터베이스는 위에서 설명한 툴팁 줄만 더합니다.
