# 감사의 말

무엇보다 먼저 Sku 애드온을 만든 Duugu에게 깊이 감사드립니다. Sku는 World of Warcraft 클래식을 시각장애인이 즐길 수 있게 만든 첫 애드온이며, WowVision 기능의 대부분은 Sku의 기능에서 영감을 받았습니다. Sku 덕분에 이만한 규모에서 게임 접근성을 어디까지 구현할 수 있는지 깨달았습니다. Sku가 있었기에 WoW를 즐길 수 있었던 시간에 언제까지나 감사할 것입니다.

WowVision 베타 기간 내내 도와주신 분들, 특히 Fabien, Leo, Duugu에게도 감사드립니다. 여러분의 도움과 지원이 없었다면 이 애드온의 개발은 지금 수준에 한참 못 미쳤을 것입니다. 여러 WoW 클래식 버전에 걸친 UI 작업을 해 주신 Fabien과, WoW 지도 데이터를 사용하는 새 매핑 알고리즘 작업을 해 주신 Leo에게, 그 모든 수고에 깊이 감사드립니다.

베타 기간 내내 영상 안내를 만들어 주신 HolyVirus2068/BlindWarriorGamer에게도 감사드립니다. 아주 좋은 자료이니, 게임의 어느 부분에서 막혔거나 애드온의 작동 방식을 더 알고 싶다면 꼭 활용해 보시기를 권합니다.
